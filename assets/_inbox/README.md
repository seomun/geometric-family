# 여기에 ChatGPT 시트를 그냥 넣으세요

파일 이름만 아래 중 하나로 바꿔서 이 폴더에 넣고, 터미널에서:

```
python tools/ingest.py
```

나머지(배경 제거·6칸 자르기·폴더 배치·원본 보관)는 자동입니다.

## 파일 이름 = 캐릭터 이름
| 넣을 이름 | 캐릭터 | 격자 |
|---|---|---|
| `wife.png` | 세모 아내 | 3×2 |
| `husband.png` | 세모 남편 | 3×2 |
| `nemo_dad.png` | 네모 아빠 | 3×2 |
| `nemo_mom.png` | 네모 엄마 | 3×2 |
| `nemo_grandma.png` | 네모 할머니 | 3×2 |
| `nemo_kids.png` | 네모 아이 4인 | 2×2 |
| `dong_dad.png` | 동그라미 아빠 | 3×2 |
| `dong_mom.png` | 동그라미 엄마 | 3×2 |
| `dong_kids.png` | 동그라미 아이 2인 | 2×2 |
| `lineup.png` | 13인 라인업 | 자르지 않음 |

한글 이름도 됩니다: `세모남편.png`, `네모엄마.png`, `할머니.png`, `동그라미아빠.png`, `라인업.png` …

## 두 번째 시트(표정 추가)는 `_v2`
`wife_v2.png` → 화남·삐침·의기양양·졸림·울음·무표정 6종으로 저장됩니다.
`husband_v2.png` 도 같습니다. (그 외 캐릭터는 v2도 기본 6표정으로 들어갑니다)

## 확인이 필요한 것
- 시트는 **흰 배경**, 글자 없음. 칸마다 같은 크기·위치.
- 표정 순서는 **① 기본 미소 ② 눈웃음 ③ 윙크 ④ 하트 눈 ⑤ 놀람 ⑥ 걱정** (docs/06 SHEET 블록 그대로).
- 순서가 다르면 그대로 잘려서 이름이 어긋납니다 — 다시 뽑는 게 빠릅니다.
