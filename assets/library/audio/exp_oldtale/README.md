# ⑪ 원정대 소리 — 국악풍(옛날이야기 방식) 새 판 (gf-asset, 2026-10-27)

작가 판정(10/27 허브 전달): 옛날이야기 소리 시험판이 더 낫다 → 원정대도 그 느낌으로. 전부 직접 합성(CC0, 외부 녹음 없음). 가야금·대금·장구·북·종·마림바 색, 게임 v2·옛날이야기와 같은 조(C 펜타토닉, 전투·보스·슬픔은 같은 음의 라 단조 펜타토닉)·같은 EQ·같은 잔향. 고역(6kHz 이상)은 0%, 귀 아픈 2~4kHz 는 5% 미만. 기준표 `docs/48_UNITY_STANDARD.md`. 도구 `tools/asset_exp_oldtale.py`. 승인 전 시험판 — 켜기는 작가 A/B 승인 뒤.

## 효과음 `sfx/` — 드롭인 교체(파일 이름·슬롯이 `games/audio/exp/` 와 같다)
`data/exp_sfx.json` 의 슬롯 40개·mp3 59개를 같은 이름으로 다시 만들었다. `games/audio/exp/` 에 덮어쓰면 코드 수정 없이 바뀐다(`tools/exp_sfx_build.py` 는 Kenney 원본으로 다시 만드는 도구라, 교체 후에는 이 도구가 만든 것을 우선하도록 gf-game 이 정한다).
- 음량: 원래 규칙(K-가중 통합 LUFS, 0.4초 미만은 무음 덧댐)으로 −15 LUFS + 슬롯 오프셋(`off`), 피크 −2dBFS, 모노 32kHz mp3. 이전(−13 LUFS)보다 2dB 낮다 — 날카로운 고역 없이 같은 크기를 내려면 거친 포화가 필요해서 포화를 줄였다. 작게 느껴지면 `ExpSnd.loudness.make`(지금 1.55)를 1.9 정도로 올리면 된다.
- 겹겹이 커지기: `xs_pop1`(마림바 한 음 + 반짝) → `xs_pop2`(2음 화음 + 종) → `xs_pop3`(3음 화음 + 펠트 쿵 + 종 + 가야금) → `xs_blob5`(가야금 쓸어내림 4음 + 북 + 장구 + 현악 깔개 + 종 + 반짝) → `xs_blob7`(7음 쓸어내림 + 큰 북 + 징 + 현악 + 종 둘 + 장구) 순으로 층이 늘고 음이 낮고 커진다. `xs_row`(한 줄 폭발)는 음계를 쓸어 올리며 장구 몰아치기, `xs_fusion`은 현악이 부풀며 종이 피어난다.
- 속성: `xs_atk_support`(풀: 나무 + 가야금 + 잎 스치는 소리) · `xs_atk_flash`(불: 장구 + 올라가는 바람 + 낮은 가야금 + 종) · `xs_atk_care`(물·회복: 물방울 + 종 + 마림바 + 반짝) · `xs_clang`(방어: 징·나무) · `xs_hit*`(타격: 장구 + 나무 + 펠트, 큰 타격은 북 + 징) · `xs_hurt`·`xs_down`(낮고 따뜻하게 내려감) · `xs_boss`(큰 북 + 징 + 낮은 현악) · `xs_win`·`xs_fanfare`(가야금 올라가기 + 대금 + 종 + 장구 + 반짝, 잔치풍; 레벨업·성공도 `xs_fanfare`) · `xs_lose`(대금 내려가는 세 음) · `xs_gacha_*`(등급이 오를수록 층이 늘어남).
