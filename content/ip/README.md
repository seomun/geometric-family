## ⚠️ 순서 변경 (2026-10-04 작가 결정): **상표 먼저**, 저작권은 확인 후
- 캐릭터 그림 대부분이 ChatGPT 생성 이미지(D4)·AI 협업 코드다. AI 결과물 자체는 저작권 보호 대상이 아니고, 등록에는 사람의 창작적 기여가 필요하다. 사실과 다른 등록은 허위 등록 문제가 될 수 있다.
