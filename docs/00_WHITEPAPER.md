## 1. 세계관 — 도형이 곧 성격

삶은 수학이 아니지만, 수학만큼 반복적일지도 모른다. 고등학교 동창인 세 남자, 그리고 그 가족들.
**하나의 사건이 주어지면 세 가족이 각자의 방식으로 겪는다.** 그게 전부이고, 그게 이 세계의 규칙이다.

| | 🟦 **네모** | 🔺 **세모** | ⚫ **동그라미** |
|---|---|---|---|
| 뜻 | 평범 · 벅참과 결핍 | 매력 · 삼한사온 | 완벽 · 균형 |
| 가족 | 7인 대가족 (아빠·엄마·할머니·아이 4) | 무자녀 부부 2인 | 4인 (부모 + 아들·딸) |
| 상태 | 뭉치면 직육면체가 된다 | 마주보면 마름모(사랑), 나란히 서면 전투 | 균등한 간격, 닿을 듯 닿지 않는다 |
| 정서 | 따뜻한데 늘 부담스럽다 | 극단 — 완전히 등 돌리거나 너무 행복하거나 | 완벽한데 외롭다 |
| 사업에서의 자리 | **화자** — 블로그 필명, 내레이션 | **얼굴** — 굿즈·이모티콘·썸네일 주역 | **마크** — 로고, 품질, "정답" 자리 |
| 소품 | 믹스커피 | 아메리카노 · 칼과 방패 · 하트 | 안경 · 책 |

**연령**: 어른들은 50 전후. 하지만 **얼굴은 귀엽게 유지한다**(D5). 나이는 소품·대사·배경으로 낸다 — 이유는 §5.
**금기**: 특정 인물·사건 지칭, 한 화에 사건 2개, 설명하는 결말, 피곤함을 앞세우기.

## 2. 무엇을 만드는가 — 하나의 세계, 여섯 개의 창

### 채널 확정 (2026-09-23)
| 채널 | 무엇을 | 누가 |
|---|---|---|
| **쇼츠** | "감동 있는 정보" — 3초에 읽히는 상황 + 세 반응 + 답 없는 질문. 10초 미만도 만든다(2026 알고리즘은 짧을수록 유리, 애니메이션 밈이 상위) | word 세션 대본 → art 세션 컷 |
| **웹툰(짧게, 자주)** | 6컷 + 「네모의 글」 링크. 연재물이되 한 화는 가볍게. 후보 10편은 `content/episodes/EPISODES.md` | toon 세션 |
| **블로그 2개** | ① **개인 「네모의 …」** — 평소 쓰던 글을 네모 필명으로 (사람이 직접) ② **공식 연재 계정** — 화 게시 + **세계관 풀이** + **굿즈 시안 공개** | word 세션 뼈대 → 사람 본문 |
| **게임** | **유아용 시리즈 먼저**. 「도형 놀이터」 1호 도형 맞추기 → 색칠 → 꾸미기 | game 세션 |
| **굿즈** | 공식 블로그에 **시안부터 공개**하고 반응을 본 뒤 POD 판매 | art 세션 아트보드 |


```
                    ┌──────────── 세계관 (캐릭터 13인 + 사건 ) ────────────┐
                    │                                                      │
  [블로그·네모의 글] ←─ 검색·공감 ─→ [웹툰] ←─ 몰입 ─→ [쇼츠] ─ 도달 ─→ (재유입)
            │                          │                  │
            │                          ▼                  ▼
            │                   [굿즈·세모]  ←─ 첫 수익 ─  [이모티콘·세모]
            ▼                          │
      [유아 게임 · 도형 놀이터] ─ 가족 확장 ─→ [라이선싱 · 문구/완구]
```
- **입구는 둘**: 어른은 블로그·웹툰·쇼츠로, 아이는 게임으로. 둘 다 같은 도형을 본다.
- **모든 끝은 같은 질문**: "당신은 어느 도형인가요?" — 이 한 줄이 채널을 잇는다. 바꾸지 않는다.
- **돈은 세모에서** 먼저 난다. 광고·유료화는 나중.

채널별 형식·주간 리듬은 `02_IP_STRATEGY.md`, 사업 로드맵·비용은 `04_IP_BUSINESS.md`.

## 3. 펜시(굿즈) 우선 원칙 — 그림을 그리는 기준

**"이 그림을 노트 표지에 그대로 찍을 수 있는가?"** 가 모든 작화 판단의 기준이다.
이 기준이 그림체를 결정했다(→ `03_STYLE_GUIDE.md` 에 수치로 잠금):

| 규칙 | 값 | 왜 |
|---|---|---|
| 채색 | 플랫 단색, 그라데이션·음영 0 | 인쇄·자수·실크스크린에서 그대로 재현 |
| 외곽선 | 연갈색 `#6b5443`, 균일 | 검정은 무겁고 클립아트처럼 보인다 |
| 배경 | 순백, 소품·글자 없음 | 배경 제거 후 어디에나 얹는다 |
| 의상 | 없음 | 도형의 추상성 유지, 시즌 의존 제거 |
| 액세서리 | 캐릭터당 딱 하나 | 작게 찍어도 식별된다 (세모 아내=리본) |
| 글자 | AI 에게 절대 안 시킴 | 오탈자·폰트 불일치. 글자는 우리가 얹는다 |

**두 층 구조**(§6과 연결): ChatGPT 에는 **깨끗하게** 뽑게 하고, 손맛(선 흔들림·종이 결)은 **우리 코드가 모든 캐릭터에 똑같이** 입힌다. 생성 단계에서 손맛을 넣으면 캐릭터마다 달라져 일관성이 깨진다.

### 4-2. 그래서 순서
> **시선은 쇼츠로, 공감은 웹툰으로, 돈은 굿즈로, 인지도가 쌓인 뒤 이모티콘.**

| 순위 | 무엇 | 왜 이 순서 | 비용 |
|---|---|---|---|
| 1 | **쇼츠** (10~20초, 3컷) | 도달 단가가 가장 싸다. 2026 쇼츠는 **짧을수록·말 없을수록** 유리하고 애니메이션 밈이 상위권. 우리 3컷 구조가 그대로 맞는다 | 사람 30분/편 |
| 2 | **웹툰 6컷 + 네모의 글** | 쇼츠에서 온 사람을 붙잡는다. 짧게(6컷) + 깊게(장문) 분리 | 사람 2h/화 |
| 3 | **굿즈 POD** (노트·스티커·키링) | 첫 수익. 재고 0. 실물 사진이 다시 콘텐츠가 된다 | 샘플 3~5만 원 |
| 4 | **블로그(네모)** | 검색 유입, 장기 자산. 사람이 직접 쓴다 | 사람 1.5h/편 |
| 5 | **이모티콘** | 승인률 5% → 인지도 쌓은 뒤 제안. 3회 제출 각오 | 시안 24종 |
| 6 | **유아 게임** | 다른 입구(아이). Dress Story 엔진 재사용 | AI 전담 |
| 7 | **라이선싱** | 실물 + 수치 + 라인업 시트를 들고 페어로 | P3 |

### 4-3. 시선을 끄는 장치 (무엇이 클릭을 만드나)
1. **세모 아내의 얼굴** — 굿즈·썸네일의 고정 주역. 예쁘고 요염하고 귀엽다.
2. **"오늘은 전투 / 내일은 사랑"** — 세모 부부의 극단이 한 장에 보인다. 공감과 웃음이 동시에.
3. **3지선다 질문** — "부의금, 당신은 얼마?" 같은 답 없는 질문. 댓글이 콘텐츠가 된다.
4. **도형 = 나** — 자기동일시. "나는 세모다" 라는 댓글이 나오면 IP 가 선 것이다.

## 5. 작화 원칙 — 귀엽게, 나이는 소품으로 (D5)

어른 캐릭터는 50 전후지만 **얼굴은 귀엽게 유지한다.** 근거:
1. **수익이 귀여움에서 난다.** 50대처럼 생긴 캐릭터는 노트에 찍히지 않는다.
2. **갭이 매력이다.** 유치할 만큼 단순한 그림 + 중년의 정서 = 망그러진 곰·최고심 계열의 성공 공식.
3. **추상성이 장치다.** 얼굴에 나이를 새기면 '특정 중년 남자'가 되고, "당신은 어느 도형?" 이 작동하지 않는다. 20대도 자기를 네모라고 말할 수 있어야 한다.
4. **귀여움이 무거운 소재를 견디게 한다.** 부고·병·돈 이야기를 사실적으로 그리면 읽히지 않는다.

**나이는 이렇게 낸다 (비용 순)**
| 수단 | 내용 | 상태 |
|---|---|---|
| 소품 | 믹스커피·돋보기·부의 봉투·약봉지·등산모·넥타이·경조사비 | coffee/americano/envelope/book/bag 구현됨, 나머지 추가 예정 |
| 대사·소재 | 부고·부의금·건강검진·학원비·대출·명절 | 소재 풀 확보 |
| 중년 기호 1개씩 | 아빠=콧수염+눈밑 주름 / 엄마=쪽머리 / 할머니=흰 쪽머리 | 시트에 반영됨 |
| 눈 크기 세대차 | **어른은 지금 크기, 아이는 얼굴의 절반** | 아이 시트에서 반드시 적용 |
| 배경·서체 | 사무실 창가·장례식장 + 명조체 내레이션 | 구현됨 |
| 상복·정장 | 코드 벡터로 처리 | 구현됨 |

## 6. 제작 시스템 — 지금까지 만든 것

### 6-1. 캐릭터: "정본은 시트, 배치는 코드"
- **정본** = ChatGPT 시트 (`assets/<캐릭터>/_sheet/sheet_vN.png`). 새 표정은 **이 시트를 첨부해서** 같은 스타일로 생성.
- **낱장** = 600×600 투명 PNG, 발끝 정렬. `python tools/ingest.py` 가 배경 제거·자르기·배치를 자동 처리.
- **배치** = `src/characters.js` 가 위치·크기·소품·컷 조립·손맛 렌더를 담당. `semoWife({emo:'angry'})` 한 줄이면 해당 PNG 가 붙는다.
- **표정 폴백**: 시트에 없는 표정은 가장 가까운 칸으로 자동 대체 (angry → bad → worry → good).
- **손맛 렌더**: `GF.setMode('hand')` — 선 흔들림·굵기 변화·칠 어긋남·종이 결·미세 기울기. 웹툰은 hand, 굿즈 인쇄는 clean.

## 10. 한 문단 요약

세 도형 가족이 같은 일을 각자 다르게 겪는다. 캐릭터는 시트로 고정되고 코드로 배치되어 **어디에 찍어도 같은 얼굴**이다. 쇼츠로 시선을 끌고, 짧은 웹툰과 긴 글로 붙잡고, 세모의 얼굴로 굿즈를 팔고, 인지도가 쌓이면 이모티콘과 라이선싱으로 넘어간다. 어른들은 50 전후지만 귀엽게 그린다 — 귀여움이 팔리고, 갭이 매력이고, 추상성이 "당신은 어느 도형인가요?"를 가능하게 하기 때문이다.
