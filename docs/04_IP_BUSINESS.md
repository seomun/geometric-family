# 04. 「기하학 가족」 IP 사업 전개 — 하나의 흐름

작성 2026-09-18. 운영 1인 + AI. 이 문서는 **"무엇을 어떤 순서로, 누가"** 를 정한다. 채널별 세부 형식은 `02_IP_STRATEGY.md`, 그림 규격은 `03_STYLE_GUIDE.md`.

---

## 1. 한 줄

> **평범한 네모가 이야기하고, 매력적인 세모가 팔리고, 완벽한 동그라미가 브랜드가 된다.**

세 도형은 캐릭터이자 **사업의 세 기둥**이다.

| 도형 | 뜻 | 사업에서의 자리 | 채널 |
|---|---|---|---|
| 🟦 **네모** | 평범 · 벅참과 결핍 | **화자.** 사람(작가)의 이름이자 목소리. 신뢰와 공감 | 블로그 「네모의 …」, 웹툰 내레이션, 유튜브 목소리 |
| 🔺 **세모** | 매력 · 삼한사온 | **얼굴.** 팔리는 것. 굿즈·스티커·이모티콘·썸네일 | 굿즈 스토어, 이모티콘, 쇼츠 |
| ⚫ **동그라미** | 완벽 · 균형 | **마크.** 로고, 품질 보증, "정답" 자리 | 로고, 앱 아이콘, 패키지 |

캐릭터는 코드(`src/characters.js`)라서 **어느 채널에 찍어도 같은 얼굴**이다. 이것이 1인 IP 가 대기업 IP 와 경쟁할 수 있는 유일한 지점이다 — 일관성은 돈이 아니라 규칙으로 만든다.

## 2. 흐름 (퍼널)

```
[블로그 · 네모의 글]  ──검색·공감──▶  [웹툰 · 자체 연재]  ──몰입──▶  [쇼츠]  ──도달──▶  (다시 웹툰)
        │                                    │                           │
        │                                    ▼                           ▼
        │                          [굿즈 · 세모]  ◀── 첫 수익 ──  [이모티콘 · 세모]
        │                                    │
        ▼                                    ▼
[유아용 게임 · 도형 놀이] ──가족 확장·앱스토어 노출──▶ [라이선싱 · 문구/완구]
```

- **입구는 둘**: 어른은 블로그·웹툰으로, 아이는 게임으로. 둘 다 같은 도형을 본다. 부모가 아이에게 "이거 아빠가 보는 웹툰 캐릭터야" 하는 순간이 IP 다.
- **돈은 세모에서** 먼저 난다(굿즈·이모티콘). 광고·유료 웹툰은 뒤.
- **모든 끝은 "당신은 어느 도형인가요?"** — 블로그 끝, 웹툰 끝, 쇼츠 끝, 게임 결과 화면. 이 질문이 채널을 잇는다.

## 3. 채널 정의

### 3-1. 블로그 — 「네모의 ○○」 (사람이 쓴다)
- 필명 **네모**. 1인칭. 평범한 아빠·직장인의 눈. 웹툰의 뒷이야기, 실제 경험, 1인 제작기.
- 플랫폼: 네이버 블로그(검색) + 브런치(감성). 같은 글, 제목만 다르게.
- 주 1~2편, 800~1500자. **AI 초안 금지.** AI 는 제목 후보·소제목·삽입 컷·태그만.
- 글 끝 고정: 웹툰 링크 + "당신은 어느 도형인가요?" + 세모 스티커 1장.
- KPI: 검색 유입, 웹툰 클릭률, 댓글 수.

### 3-2. 웹툰 — 자체 연재 (본진)
- `https://seomun.github.io/geometric-family/` 가 원본. 주 1화, 10~14컷, 투표 CTA.
- 네이버 도전만화·포스타입에 **미러**(노출용). 댓글은 양쪽 다 받고 좋은 사연은 외전.
- 사람: 원고(docs/01) + 최종 대사. AI: 컷 구성·조립·검증·배포.
- 시즌 1 = 12화. 소재 풀: 집 청소, 중고차, 어버이날, 명절, 건강검진, 학원비, 이사, 반려동물, 동창회, 휴가, 연말정산, 첫눈.

### 3-3. 쇼츠 — 3포맷 고정 (02 문서 §3-2)
- A 세 창가 / B 한 마디 / C 어느 도형?. 화당 2~3개. 마지막 컷 동일.
- 목소리: 사람 목소리(네모) 또는 TTS 1종 — **한 번 정하면 안 바꾼다.**
- 썸네일은 항상 세모 아내.

### 3-4. 굿즈 — 세모 중심, 재고 없이
- 1차(지금): **노트 3종**(담 너머 엿보기 / 칼과 방패 / 사랑) + **스티커 시트** → `web/goods.html` 아트보드. POD(마플샵·오프린트미·레드버블류)로 **재고 0 개시.**
- 2차: 이모티콘(카카오 24종 — 표정 12 × 포즈 조합에서 뽑음), 키링·엽서.
- 3차(반응 후): 소량 자체 제작(노트 100권) → 실물 사진이 블로그·쇼츠 원료가 된다.
- 문구 회사 라이선싱 제안은 실물 사진과 판매 수치가 있은 뒤.
- 사람: 문구·굿즈 선택, 주문. AI: 아트보드·규격 파일(PNG/PDF/SVG)·목업.

### 3-5. 유아용 게임 시리즈 — 「도형 놀이터」 (3~6세)
- 왜 도형인가: 네모·세모·동그라미는 **유아 교육의 첫 단원**이다. 캐릭터가 곧 교구.
- 엔진: Starry Village 의 Dress Story 엔진(단일 HTML, data JSON, 저장) 재사용. 광고·결제·서버 없음 → Families 정책 통과 쉬움.
- 시리즈(각 1개 HTML, 데이터만 다름):
  1. **도형 맞추기** — 빈 자리에 맞는 도형 넣기. 성공하면 세모가 춤춘다.
  2. **도형 색칠** — 세 가족 색칠. 결과를 이미지로 저장(부모 공유).
  3. **도형 가족 꾸미기** — Dress Story 의 옷 갈아입히기를 도형에.
  4. **어느 도형 테스트**(어른용, 웹툰 연계) — 같은 엔진, 성인 채널.
- 출시: 웹(PWA) → Google Play(Capacitor, 서명 키 있음) → iOS 는 Mac 확보 후.
- **Starry Village(Dress Story)** 는 실험 1호로 이미 출시. 4주 반응이 좋으면 유지, 아니면 엔진만 남기고 종료.

### 3-6. 이모티콘 · 라이선싱 (6개월 후)
- 카카오 이모티콘 스튜디오 제안: 세모 아내 24종. 승인율 낮으니 3회 제출 각오.
- 라이선싱: 문구(노트·펜) → 유아 교구(도형 블록) 순.

## 4. 역할 — 누가 무엇을
| | 사람(작가, 필명 네모) | AI(Claude Code) |
|---|---|---|
| 글 | 블로그 본문, 웹툰 원고·대사, 굿즈 문구, 스토어 설명, 댓글 답글 | 제목 후보, 구조, 길이, 오탈자 |
| 그림 | 표정·구도 OK/NO 판단 | 캐릭터 코드, 컷 조립, 굿즈 아트보드, 리스케일, 목업 |
| 게임 | 놀이 규칙 검토, 아이 테스트 | 전부 |
| 운영 | 플랫폼 계정, 결제, 주문, 상표 출원 | 배포, 스냅샷, KPI 표, 일정 알림 |
| 판단 | 무엇을 계속할지 | 근거 표 |

원칙: **AI 가 쓴 티 나는 글은 0줄.** AI 는 뼈대와 그림, 사람은 살과 목소리.

## 8. 리스크와 대비
- **1인 소진** → 주간 리듬(02 §4) 8시간 상한. 밀리면 쇼츠부터 뺀다, 웹툰은 격주로. 캐릭터는 코드라 "그림 밀림"은 없다.
- **톤 불일치** → 03 스타일 가이드 + 스냅샷 비교. 글은 네모 페르소나 문장 규칙(02 에 추가 예정).
- **실존 인물·기관** → 이름은 만든 것만. 1화 병원명 확인.
- **상표** → "기하학 가족" 문자 + 세모 아내 도형, P1 안에 출원. 남이 먼저 내면 끝.
- **플랫폼 의존** → 원본은 항상 자체 페이지 + 이 저장소. 플랫폼은 미러.
- **아동 정책**(게임) → 광고·결제·데이터 0 유지. Starry Village 에서 이미 검증한 절차(`05_STORE_RELEASE.md`) 재사용.

4. 상표 출원 견적 확인(특허청 키프리스 선행 검색은 AI 가 함).
