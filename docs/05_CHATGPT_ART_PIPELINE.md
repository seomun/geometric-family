# 05. ChatGPT 아트 파이프라인 — 하나의 손이 그린 것처럼

작성 2026-09-18. 목적: ChatGPT(이미지 생성)로 **네모·세모·동그라미 전 가족을 같은 그림체**로 뽑고, 몇 달 뒤에 새 표정을 뽑아도 같은 캐릭터가 나오게 한다.
핵심 원리 3개:
1. **정본은 시트 한 장이다.** 첫 승인된 시트(세모 아내 2×3)가 스타일의 유일한 기준. 모든 생성은 이 시트를 **첨부**하고 시작한다. 말로 설명하지 않는다.
2. **스타일 블록은 복사해서 붙인다.** 매번 같은 문장. 바꾸면 그림체가 바뀐다.
3. **한 번에 한 캐릭터, 한 장에 여러 표정.** 표정마다 따로 뽑으면 얼굴이 흔들린다. 같은 캔버스 안에서 뽑아야 같은 얼굴이 나온다.

---

## 0. 폴더·이름 규칙
```
assets/
  wife/      _sheet/sheet_v1.png   good.png wink.png surprise.png joy.png love.png worry.png   manifest.json
  husband/   _sheet/…              good.png smile.png angry.png worry.png surprise.png love.png
  nemo_dad/  nemo_mom/  nemo_kid1/ …  dong_dad/ dong_mom/ …
  scenes/    (표지·굿즈용 완성 일러)
```
- 시트는 `_sheet/sheet_vN.png`. **승인된 최신 버전만 첨부용으로 쓴다.** 이전 버전은 지우지 않는다(되돌리기용).
- 자르기: `python tools/cut_sheet.py assets/<dir>/sheet_vN.png --cols 3 --rows 2 --names a,b,c,d,e,f`
- 표정 이름은 코드의 emo 와 맞춘다: `good joy bad angry worry relief sad cry surprise love tired wink`.

## 1. 스타일 블록 (모든 프롬프트 맨 앞에 그대로 붙인다)
```
[STYLE — 기하학 가족 v1, 절대 변경 금지]
- 플랫 벡터 마스코트 스타일. 헬로키티·산리오처럼 단순하고 깔끔한 선.
- 외곽선: 얇고 균일한 진갈색(#6b5443). 검정 아님. 굵기는 캐릭터 폭의 약 1.5%.
- 채색: 단색 플랫. 그라데이션·음영·광택·질감·그림자 전부 없음.
- 배경: 순백(#FFFFFF). 바닥선·소품·글자·워터마크 없음.
- 몸: 도형 자체가 얼굴이자 몸. 모서리는 살짝 둥글게, 변은 직선.
- 팔다리: 살색(#f7dcc8), 아주 가늘고 길지 않게, 끝은 둥근 손. 여성은 분홍 힐(#f08aa4), 남성은 갈색 로퍼.
- 얼굴 비율: 눈은 도형 높이의 약 45% 지점, 넓게 벌림. 눈썹은 얇고 짧은 아치. 입은 아주 작게. 볼터치는 진분홍 원.
- 의상 없음. 액세서리는 캐릭터당 딱 하나(리본, 안경 등).
- 캔버스: 2×3 격자, 한 칸에 한 표정, 칸마다 같은 크기·같은 위치·같은 정면 자세. 여백 넉넉히.
- 첨부한 시트와 **같은 손으로 그린 것처럼** 선 굵기·색·비율을 완전히 동일하게.
```

## 2. 캐릭터 DNA 블록 (캐릭터마다 하나, 스타일 블록 뒤에 붙인다)

### 세모 아내 (정본 ✅ 승인됨 — 재생성 시 기준)
```
[CHARACTER — 세모 아내]
노란(#f6de5c) 역삼각형(꼭짓점이 아래). 왼쪽 위 모서리를 덮는 큰 분홍 리본(#f28ba5).
눈: 가로로 넓은 아몬드, 두꺼운 윗눈꺼풀 선이 눈 위 1/3을 덮음(반쯤 내린 눈), 큰 진갈색 홍채, 작은 하이라이트 1개,
바깥쪽 긴 속눈썹 3개가 위로 휨, 시선은 살짝 옆(애교). 얇은 아치 눈썹. 진분홍 볼 원. 아주 작은 미소.
살색 가는 팔은 몸 옆으로 얌전히, 다리는 곧게 모아 분홍 힐.
```

### 세모 남편
```
[CHARACTER — 세모 남편]
하늘색(#9fb6d0) 정삼각형(꼭짓점이 위). 꼭짓점에 짧은 머리카락 한 가닥(퀴프).
눈: 아내와 같은 아몬드형이지만 속눈썹 없음, 윗눈꺼풀 선은 얇게, 시선 정면. 날카롭고 쿨한 인상. 얇은 눈썹. 작은 입.
살색 가는 팔다리, 갈색 로퍼. 아내와 나란히 서면 같은 크기.
```

### 네모 아빠
```
[CHARACTER — 네모 아빠]
주황(#e29368) 정사각형, 모서리 둥글게. 정수리에 숱 적은 머리 3가닥. 콧수염(입 위, 작게). 눈 밑에 옅은 주름 선 하나.
눈: 둥글고 순한 눈, 흰자+진갈색 동공+하이라이트. 사람 좋은 미소. 살색 팔다리, 갈색 구두. 약간 통통한 느낌은 모서리 둥글기로만.
```
### 네모 엄마
```
[CHARACTER — 네모 엄마]
살구(#ecb383) 정사각형. 오른쪽 위에 쪽머리(검은 동그라미). 속눈썹 있는 둥근 눈, 밝은 미소.
팔이 4개(양옆 2개씩). 살색 팔다리, 낮은 굽 구두.
```
### 네모 할머니 / 아이들(큰딸·작은딸·작은아들·막둥이)
```
[CHARACTER — 네모 할머니] 베이지(#d8b58e) 정사각형, 정수리 흰 쪽머리, 눈밑 주름, 온화한 미소.
[CHARACTER — 네모 아이] 작은 정사각형(색: 큰딸 #f0c583 / 작은딸 #f2b49e / 작은아들 #e6a9c0 / 막둥이 #f8dcb0),
정수리에 삐친 머리 한 가닥, 아주 큰 눈(얼굴의 절반), 하이라이트 2개. 큰딸·작은딸은 속눈썹.
```
### 동그라미 아빠 / 엄마 / 아들 / 딸
```
[CHARACTER — 동그라미 아빠] 청회색(#9fb0bf) 정원. 단정한 가르마 선, 동그란 안경. 눈은 늘 평온(감정에도 눈매 고정), 작은 미소.
[CHARACTER — 동그라미 엄마] 회베이지(#c4b3a0) 정원. 웨이브 앞머리 선, 속눈썹, 목에 진주 점 5개. 평온한 미소.
[CHARACTER — 동그라미 아들] 연녹(#a9bcae) 작은 원, 바이올린을 든 모습.  [딸] 연보라(#cbb6c2) 작은 원, 분홍 핀, 테니스 라켓.
```

## 3. 시트 요청 블록 (마지막에 붙인다)
```
[SHEET]
2×3 격자, 순서대로: ① 기본 미소 ② 눈웃음(joy) ③ 윙크 ④ 하트 눈(love) ⑤ 놀람(작은 o 입) ⑥ 걱정(눈썹 처짐·땀방울)
모든 칸에서 몸 크기·위치·팔다리 자세 동일. 표정만 다르게. 흰 배경. 글자 없음.
```
포즈 시트가 필요하면:
```
[SHEET — POSE] 3×3 격자: 서기 / 손 흔들기 / 만세 / 턱 괴기 / 가리키기 / 허리에 손 / 어깨 으쓱 / 앞에 물건 들기 / 앉기. 표정은 모두 기본 미소.
```

## 4. 실행 순서 (이 순서를 지켜야 흔들리지 않는다)
1. **세모 아내 시트 v1 첨부** + 스타일 블록 + 남편 DNA + SHEET 블록 → 남편 시트 생성.
2. 검수(§5). 통과하면 `assets/husband/_sheet/sheet_v1.png` 저장 → `cut_sheet.py`.
3. **아내 + 남편 시트 두 장 첨부** → 네모 아빠. (첨부가 늘수록 그림체가 더 잘 고정된다.)
4. 이후 캐릭터도 "승인된 시트 전부 첨부"가 원칙. 첨부 상한(보통 4장)에 걸리면 **가족 라인업 한 장**(아래 §6)을 만들어 그것 한 장만 첨부.
5. 새 표정/포즈 추가는 **그 캐릭터의 시트를 첨부**하고 "같은 캐릭터, 같은 자세, 표정만 ○○로" 한 줄. 새로 그리게 하지 않는다.
6. 한 세션에서 한 캐릭터만. 세션을 바꾸면 반드시 시트를 다시 첨부한다(ChatGPT 는 지난 대화의 그림을 기억하지 않는다고 가정).

## 5. 검수 체크리스트 (하나라도 틀리면 **버리고 다시 뽑는다** — 고치려 하지 않는다)
| # | 확인 | 통과 기준 |
|---|---|---|
| 1 | 선 | 굵기 균일·진갈색·검정 아님. 시트 v1 과 나란히 놓고 같아 보이는가 |
| 2 | 채색 | 그라데이션·음영·광택 0. 도형 안이 단색인가 |
| 3 | 눈 | 아내 기준 아몬드형·윗눈꺼풀 선 굵기·속눈썹 수(3)·하이라이트 수(1). 남성은 속눈썹 0 |
| 4 | 비율 | 눈 높이 ≈ 도형 높이의 45%, 팔다리 굵기 ≈ 아내와 동일 |
| 5 | 배경 | 순백, 바닥선 없음, 글자 없음 (rembg 가 깨끗이 따야 함) |
| 6 | 격자 | 6칸 모두 같은 크기·위치. 한 칸이라도 기울거나 커지면 실패 |
| 7 | 식별자 | 리본/퀴프/콧수염/안경/쪽머리 — 캐릭터 DNA 의 딱 그 하나만 있는가. 추가된 장식이 있으면 실패 |
| 8 | 색 | HEX 근사치(±10%). 노랑이 주황으로, 하늘색이 남색으로 흐르지 않았는가 |
검수는 사람이 30초. 애매하면 **v1 시트를 옆에 붙여 나란히** 본다(`web/wife.html` 처럼 페이지에 같이 띄워서).

## 6. 라인업 고정 (모든 캐릭터가 승인된 뒤 1회)
```
[승인 시트 전부 첨부] 같은 스타일로, 세 가족 13명을 한 줄에 나란히: 네모 7 / 세모 2 / 동그라미 4.
키 순서: 어른 정사각형 = 세모 = 원 지름이 같고, 아이들은 60%. 모두 기본 미소, 정면, 흰 배경, 글자 없음.
```
이 한 장이 **`assets/_lineup_v1.png`** = 이후 모든 생성의 단 하나의 첨부 파일이 된다. 굿즈·표지 의뢰도 이걸 첨부한다.

## 7. 장면·굿즈 일러 (캐릭터 시트가 아닌 완성 그림)
캐릭터는 코드/스프라이트로 배치하는 게 원칙이지만, **표지·노트·썸네일**은 ChatGPT 완성 일러가 더 예쁘다. 그때도 규칙:
```
[라인업 첨부] + [STYLE 블록] + 장면 한 줄 + "캐릭터의 얼굴·비율·선은 첨부와 동일. 배경은 단색 또는 2색 플랫. 글자 없음(글자는 우리가 넣는다)."
예) 세모 아내가 담(노란 벽) 뒤에서 팔로 담을 안고 윙크하며 넘겨보는 장면. 몸의 위 절반만 보임. 세로 3:4.
예) 세모 부부가 마주보고 각각 칼과 방패를 든 장면, 둘 다 화난 표정. 가로 4:3.
예) 세모 부부가 마주보고 하트 눈, 사이에 하트 하나. 가로 4:3.
```
글자·로고는 절대 그리게 하지 않는다(오탈자·폰트 불일치). 우리가 `web/goods.html` 에서 얹는다.

## 8. 하지 말 것
- 프롬프트에서 스타일 블록을 줄이거나 바꾸기 ("좀 더 예쁘게" 같은 형용사 추가 금지 — 형용사는 그림체를 흔든다)
- 시트 첨부 없이 생성
- 한 캐릭터를 여러 세션·여러 날에 걸쳐 조금씩 뽑기
- 마음에 안 드는 칸만 골라 쓰기(칸마다 그림체가 다를 수 있음 → 시트 통째로 승인/폐기)
- 생성 결과를 포토샵으로 고치기(다음 생성이 고친 버전을 모른다) — 고칠 게 있으면 프롬프트를 고쳐 다시 뽑는다

## 9. 버전과 되돌리기
- 승인 = `_sheet/sheet_vN.png` 저장 + `DEVLOG` 한 줄("wife v1 승인, 근거: …").
- 그림체를 바꾸고 싶으면 **아내부터 다시** 뽑고 전원 재생성. 일부만 바꾸지 않는다. 그게 일관성의 비용이다.

### 10-1. 일관성 — 실제로 효과가 확인된 것
| 요령 | 우리 적용 |
|---|---|
| **레퍼런스 첨부 + "이 캐릭터 디자인을 정확히 사용해서"** 라고 명시. 말로 묘사하는 것보다 훨씬 강함 | §4 원칙. 프롬프트 첫 줄: `첨부한 시트의 캐릭터 디자인을 정확히 그대로 사용해서` |
| **시트에 이름을 적어 두면** 이후 "○○가 ~한다" 로 짧게 지시 가능 | 시트 생성 시 각 칸 아래 작은 글자로 `SEMO-WIFE` 를 넣게 한다 (자를 때 잘라냄). 이후 프롬프트는 "SEMO-WIFE 가 윙크" |
| **얼굴 시트 + 전신 시트를 분리**(얼굴 일관성 / 몸·의상 일관성) | 우리는 의상이 없으므로 표정 시트(2×3) + 포즈 시트(3×3) 두 장 |
| **같은 대화 스레드**에서 이어서 생성. 새 채팅 = 새 캐릭터 | 캐릭터당 스레드 1개를 만들고 이름을 붙여 둔다("GF-세모아내"). 스레드가 길어져 흔들리면 최신 승인 시트를 다시 첨부하고 새 스레드 |
| **부분 선택 편집**(이미지 위에서 영역 선택 → 그 부분만 수정)으로 작은 수정. 전체 재생성 금지 | 검수에서 한 칸만 틀리면 그 칸을 선택 편집 → 그래도 안 되면 시트 통째로 재생성 |
| 매 요청에 스타일 문장을 **그대로 반복** (모델은 이전 스타일 지시를 잊는다) | §1 스타일 블록을 매번 붙인다 |

### 10-2. "덜 AI 느낌" — 두 층으로 나눈다
AI 티가 나는 원인: 너무 매끈한 선, 완벽한 대칭, 균일한 채색, 배경까지 렌더된 느낌.
| 층 | 방법 | 이유 |
|---|---|---|
| **생성 층(ChatGPT)** | 프롬프트에 `no gradients, flat colors, clean uniform lines, white background` 를 **명시**. 형용사("예쁘게", "고급스럽게") 금지. 질감·그림자·하이라이트 요청 금지 | 매끈하고 깨끗해야 rembg 가 깨끗이 따고, 캐릭터끼리 같은 그림체가 된다. **여기서 손맛을 넣으면 일관성이 깨진다** |
| **렌더 층(우리 코드)** | `GF.setMode('hand')` — 선 흔들림·굵기 변화·칠 어긋남·종이 결·미세 기울기 (03 §1-2). 래스터 스프라이트에도 같은 필터를 건다 | 손맛은 **모든 캐릭터에 똑같이** 입혀야 한 사람이 그린 것처럼 보인다. 코드가 그걸 보장한다 |
결론: **ChatGPT 에는 "깨끗하게", 손맛은 우리가.** 트렌드(2026)도 "매끈한 AI 룩에서 벗어나 손으로 만든 온기" 쪽이라 이 두 층 구조가 맞다.

### 10-3. 프롬프트 최종 형태 (복사용)
```
첨부한 시트의 캐릭터 디자인을 정확히 그대로 사용해서 그린다. 새로 디자인하지 않는다.

[STYLE — 기하학 가족 v1, 절대 변경 금지]
(§1 블록 전체)

[CHARACTER — ○○]
(§2 블록)

[SHEET]
2×3 격자, 순서대로: ① 기본 미소 ② 눈웃음 ③ 윙크 ④ 하트 눈 ⑤ 놀람 ⑥ 걱정.
모든 칸에서 몸 크기·위치·팔다리 자세 동일, 표정만 다르게. 각 칸 아래에 작은 글자로 "○○-1"~"○○-6". 흰 배경.
no gradients, flat colors, clean uniform lines, no shadows, no texture, white background.
```
