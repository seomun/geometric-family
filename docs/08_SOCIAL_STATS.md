# 사회 통계 — 에피소드 훅 재료

> 목적: 쇼츠·웹툰의 **훅을 통계로 세운다.** 감정은 원고에서, 숫자는 여기서.
> 규칙: **출처·조사기관·표본·시점을 반드시 같이 적는다.** 화면에 숫자를 박을 때는 출처를 자막 하단에 작게 넣는다.

---

## 1. 부의금 / 축의금 — **「넌 얼마나 했냐?」(s02) 용**

### 1-1. 핵심: "부의금 10만원 시대" — **2026년 5월에 이미 터진 이슈**
2026년 5월 초~중순, 카카오페이 리포트와 설문 결과가 동시에 나오면서 언론이 일제히 다뤘다.
우리 원작 대사 **"넌 얼마나 했냐?" / "뭐 그런 거 알아 뭐하게"** 가 정확히 그 논쟁의 한복판이다.
**새 이슈를 만들 필요가 없다. 이미 있는 논쟁에 올라타면 된다.**

### 1-2. 카카오페이 송금 리포트 (2026-05-07, **실제 송금 데이터**)
| 항목 | 수치 |
|---|---|
| 부의금 | **올해 처음으로 10만원 송금 비중이 5만원을 넘어섰다** |
| 축의금 | 2022년까지 1위는 5만원 → **2023년부터 10만원이 1위** |
| 송금 봉투 10년 누적 | 4억 5,487만 건 |
| 봉투 사용 비중 | 2019년 13% → 2025년 23% |

- 설문이 아니라 **실제로 보낸 돈**이라 반박이 어렵다. 가장 센 근거.
- 출처: 머니투데이 2026-05-07 / 서울신문 2026-05-11

### 1-3. SM C&C 틸리언 프로 설문 (2026-05-08~11, **전국 성인 1,500명**)
| 부의금 | 축의금 |
|---|---|
| 평균 **95,300원** | 평균 **97,900원** |
| 10만원 **61.8%** | 10만원 **65.3%** |
| 5만원 **25.7%** | 5만원 **21.9%** |
| 15만원 7.2% | 15만원 6.3% |

- **"경조사비에 부담을 느낀다" 65.8%** ← 이 한 줄이 공감 트리거
- ⚠️ 연령대별 수치는 기사마다 정리가 엇갈린다. **인용하지 말 것.**
- 출처: 네이트/한국일보 2026-05-16 「10만원 봉투도 그저 그렇다」

### 1-4. 인크루트 설문 (2025-05, **직장인 844명**)
- 덜 친한 직장 동료 축의금 → **10만원 60.1%**

## 2. 통계 ↔ 세 도형 (이게 핵심이다)

실제 분포가 **우리 세 가족과 그대로 겹친다.** 억지로 만든 게 아니다.

| 도형 | 금액 | 실제 비중 | 왜 이 도형인가 |
|---|---|---|---|
| 🟦 **네모** | **5만원** | 25.7% | 종일 고민한다. 남들보다 적을까 봐 불안하다. **물어보지 못한다** |
| 🔺 **세모** | **10만원** | 61.8% | 남들 하는 만큼. 대신 "왜 그래야 하는데?" 하고 따진다 |
| ⚫ **동그라미** | **20만원** | 4.6% | 미리 준비해 왔다. 묻지도 답하지도 않는다 |

→ **훅 문장 후보**
- `부의금 평균 9만 5,300원. 당신은 얼마 내셨어요?`
- `5만원 낸 사람 25.7%, 10만원 낸 사람 61.8%`
- `이제 5만원은 소수가 됐습니다`
- `경조사비가 부담된다 — 65.8%`

## 4. 사용 규칙
1. 화면에 숫자를 박을 때 **하단에 출처 1줄**(예: `카카오페이 송금 리포트 2026.5`). 신뢰도가 확산을 만든다.
2. **통계는 훅에만 쓴다.** 결말은 통계로 맺지 않는다 — 잔잔하게 끝낸다(CLAUDE.md §1-2).
3. 수치가 애매하면 **버린다.** 틀린 숫자 하나가 채널을 죽인다.
