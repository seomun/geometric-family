대상: gf-game 1주차 결과물 (`games/`, 커밋 f4e9af7 — 엔진 + 1장 그림자 찾기 + 2장 같은 얼굴)
검사: 스모크 테스트(`node games/tools/smoke.js`) 1·2장 자동 완주 + 갤럭시 화면 4종 스크린샷(412×915 · 384×832 · 탭 세로 800×1280 · 탭 가로 1280×800) + 설계 문서 대조
기준: **갤럭시 스토어 퍼블리셔에게 보여 줄 수 있는 품질** (작가: "어느 정도 퀄리티는 나와야 한다, 퀄업 중심")

## 잘된 점 (유지)
- 에러 0, 1·2장 6스테이지 끝까지 완주, 저장·스티커·앨범·지도 동작
- 글자 없는 UI, 큰 버튼, 실패 없는 규칙, 적응형·힌트 — 유아 설계 원칙이 정확하다
- 캐릭터가 정본(래스터)과 일치, 화면 톤이 귀엽고 일관됨
- 엔진·모드 분리 구조가 시리즈 재사용에 맞다

## 판정: **기능 데모 단계. 퍼블리셔 데모 품질은 아직 아니다.**
→ 장을 늘리기 전에 **1장을 "버티컬 슬라이스"(출시 품질 100%)로 먼저 끌어올린다.** 1장만으로 퍼블리셔에게 보여 줄 수 있어야 2~5장을 같은 기준으로 찍어낸다.

## 3차까지 고칠 것
1. **태블릿 스케일** — 안전 영역을 세로 기준으로만 키워 탭 가로에서 캐릭터·버튼이 작고 가운데가 휑하다(홈 캐릭터 ≈ 화면 높이 1/10). 600dp 이상에서 UI 1.3~1.5배, 홈·그림책은 가로 구도(캐릭터 크게, 좌우로 펼침).
2. **홈 구성** — 캐릭터를 1.6배 이상, 언덕 위에 세우고 숨쉬기·눈 깜빡임. 제목은 해와 겹치지 않게(해 이동 또는 제목 외곽선).
3. **그림책(탭)** — 캐릭터가 작아 장면이 비어 보임 → 장면 높이의 40% 이상.
4. **나비** — 분홍 점처럼 보임 → 알아볼 크기로 키우거나 뺀다.
5. **2장 카드(탭)** — 세로 2열만 가운데 → 가로 4열로 화면을 채운다. (P1-9 표정 검수표 같이)
6. **플레이 영상** — 1장 30초 플레이 녹화(playwright video) → 손맛 검수 + 스토어 영상 초안.
7. 효과음은 작가 판정 후 지시.
