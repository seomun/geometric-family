# 16. 소리 — 교체 가능한 소리 목록 + 「기하학 가족」 테마 (2026-10-07)

원칙(작가 결정): **소리는 언제든 교체한다.** 그래서 소리는 "파일"이 아니라 **"자리(슬롯)"**로 관리한다. 자리 이름은 고정, 들어가는 파일만 바꾼다.
소리도 IP다 — 쇼츠·게임·웹툰이 **같은 테마와 같은 마무리 소리**를 쓴다(백서 §3-1 "같은 소리").

## 1. 교체 규칙
- 모든 소리는 `id` 로 부른다. 코드는 id만 안다 (`GF.sfx('ok')`, 쇼츠 `--bgm theme_short`).
- 교체 = 같은 이름의 파일을 덮어쓰거나, 목록(`data/sounds.json`, 이 문서 §2)의 `file` 만 바꾼다. 코드 수정 없음.
- 형식: 효과음 `wav/ogg 48kHz`, 음악 `ogg` 루프(처음·끝 이음매 없음), 피크 −1dB 이하, 효과음 체감 크기 맞춤(LUFS −16 근처).
- 교체할 때마다 출처·라이선스를 `games/SOUND_CREDITS.md` 에 한 줄. 자작이 아니면 **상업 이용 가능(CC0 등)만**.

## 3. 「기하학 가족」 테마 — 작곡 지침
**한 곡 안에 세 가족이 들어 있다.** 세 가족의 짧은 동기(라이트모티프)가 차례로 나오고, 마지막에 셋이 겹친다 = 세계관("같은 일을 세 가족이 겪는다").

| 동기 | 성격 | 음색·리듬 | 길이 |
|---|---|---|---|
| 🟦 네모 | 따뜻하고 북적, 조금 벅참 | 마림바·우쿨렐레, 4/4 또박또박, 음이 많고 바쁜데 밝다 | 2마디 |
| 🔺 세모 | 극단 — 티격태격과 달달함 | **두 악기가 주고받기**(부부 대화), 스타카토 ↔ 레가토 전환 | 2마디 |
| ⚪ 동그라미 | 반듯한데 조금 외롭다 | 첼레스타·패드, 느린 레가토, 마지막 음이 살짝 비어 있음 | 2마디 |
| 합주 | 셋이 한자리 | 세 동기를 겹쳐 한 화음으로 마무리 → `logo_sting` 은 여기 첫 네 음 | 4마디 |

- 조성 C장조 또는 F장조, 템포 84~96. 귀에 남는 첫 네 음(소리 로고)을 먼저 정한다.
- 기존 곡(동요·광고음) 닮지 않게 — 멜로디는 새로 쓴다.
- **만드는 방법(2026-10-07 작가 결정): 외주 없이 AI 툴(Suno Pro)로 직접** → `content/audio/SUNO_PROMPTS.md`(슬롯별 프롬프트) → `assets/_inbox/music/<슬롯>.mp3` → `python tools/music_prep.py`(무음 자르기·−16 LUFS·루프 이음매·소리 로고 자르기). 합성 시안은 '조잡' 판정으로 폐기.
- (이전 안) ① gf-game 의 합성 파이프라인(`make_audio.py`)으로 시안 3개 → 작가 귀 판정 → ② 채택안을 편곡 4종(§2-2)으로. 품질이 부족하면 나중에 외주 작곡으로 같은 지침을 넘긴다(그래서 지침을 글로 남긴다).

## 4. 쓰는 곳
- 게임: `theme_main`(타이틀) · `theme_kids`(놀이) · `night`(4장) · 효과음 9+2
