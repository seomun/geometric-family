## 3. 계획 — "한 달 한 번" 아트 패스
1. **Recraft Pro 한 달**(결제 먼저 — 무료 생성물은 상업 불가).
2. **스타일 학습**: 캐릭터 시트 + 1편 배경 중 좋은 것 + 굿즈 아트보드 → 브랜드 키트(색 `#6b5443` 외곽선·플랫·파스텔, 그라데이션 없음, 글자 없음 — 03_STYLE_GUIDE 규격).
3. **에셋 목록대로 일괄 생성**(아래 §4). Pro 의 **API** 로 허브가 목록을 자동 생성할 수 있다 → 작가는 계정·키만, 고르는 건 허브가 1차, 작가가 최종.
4. 받은 SVG 는 슬롯처럼 id 로 교체(`GF.props[id].src`, 배경 `BG[id]`, `room_items.json`) — 코드 수정 최소.
5. 한 달 뒤 해지해도 받은 파일은 계속 사용. 다음 아트 패스는 새 게임이 쌓였을 때.
