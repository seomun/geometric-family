# 20. 게임 이야기 원칙 — 익숙한 이야기 + 기하학 가족 배역 (2026-10-07, D13)

> 작가: "스토리가 하나로 엮일 필요 없어. 거꾸로 이미 익숙한 이야기들이 훨씬 나아. 아기돼지 삼형제 같은, 처음 기획대로 이야기를 끌고 가되 주인공들만 기하학 가족이면 돼."
> (같은 날 허브가 낸 「한 골목 1년 → 집들이」 통합안은 **폐기**.)

## 1. 원칙
1. **이야기 = 누구나 아는 옛이야기·명작 동화**, **배역 = 기하학 가족**. 놀이터 1·2권의 방식(세 마리 염소·호랑이와 곶감·아기돼지 삼형제·토끼와 거북이…)을 모든 게임으로 넓힌다.
2. 게임끼리 이야기를 잇지 않는다. 하나로 보이게 하는 건 **같은 배역·같은 화면(UI 키트)·같은 소리·같은 「우리 집」** 이다(docs/19 §0).
3. 배역은 세 가족 공식대로: 네모 = 많고 벅참 / 세모 = 극단·반전 / 동그라미 = 완벽한데 빈자리. 같은 이야기 안에서 **세 가족이 다르게 반응**하면 그게 우리 버전이다.
4. **저작권**: 쓰는 건 공유 저작물 원전만 — 한국 전래동화, 이솝, 그림 형제, 안데르센, 페로, 콜로디 등. 특정 회사 각색판(디즈니 등)의 이름·디자인·노래·장면 구성은 쓰지 않는다.
5. 무서운 장면은 순하게(늑대 → "바람 친구", 1권 방식). 설명하지 않는 웃는 결말.
6. 호칭은 그대로: 유아 앱 = 막둥이 시점 / 성인 앱 = 웹툰 기준. 세모네는 아이가 없다.

## 2. 게임별 적용 [제안 — 배역·장면 각색은 게임 세션, QA 때 허브 확인]
| 앱 | 지금 | 바꾸는 방향 |
|---|---|---|
| ① 놀이터 | 1·2권 옛이야기, 3권 사계절 | **그대로**(이미 이 원칙). 3권도 장마다 옛이야기 하나씩(어버이날 = 효녀 심청 순한 판·여름 = 개미와 베짱이·가을 = 금도끼 은도끼·첫눈 = 눈의 여왕 순한 판·김장 = 콩쥐팥쥐 독 채우기) |
| ② 세 가족 식탁 | 웹툰 사연(일상·계절) | **그대로** — 웹툰을 매일 여는 성인 앱이라 웹툰 사연이 이야기. 계절 사건에 옛이야기 패러디 한두 편은 선택 |
| ③ 도형 합치기 | 이사·집 채우기 12장 | **장마다 옛이야기 하나 = "집·물건을 만드는" 이야기**: 아기돼지 삼형제(집 짓기)·세 마리 곰(크기별 의자·그릇·침대)·콩쥐팥쥐(독 채우기)·흥부 박(합치면 대박 = 세모)·혹부리 영감(도깨비 방망이 뚝딱)·구두장이와 요정(밤새 만들기)·브레멘 음악대(넷이 쌓기)·금도끼 은도끼·해님 달님(동아줄)·개미와 베짱이(모으기)·피노키오(나무로 만들기)·잭과 콩나무(높이 쌓기) |
| ④ 막둥이 색칠북 | 가구 선화 + 웹툰 컷 12 | 웹툰 컷 색칠 12장 → **「옛이야기 색칠」 12장**(기하학 가족이 배역인 동화 명장면). 놀이터·합치기와 같은 이야기면 더 좋다(아는 장면을 칠함) |
| ⑤ 어느 도형? | 웹툰 장면 12 테스트 | **「동화 속 당신은?」** 테스트 추가 — 흥부와 놀부·토끼와 거북이·개미와 베짱이·아기돼지 삼형제·세 마리 곰 등에서 "당신은 어느 도형?". 웹툰 장면 테스트는 유지(성인 앱) |

## 3. 다음
- 게임 세션: ③④⑤ 이야기 데이터 교체안(장·페이지·테스트 목록 + 배역표) → 허브 QA → 반영. 그림은 임시 유지(아트 패스 때 이야기 배경으로).
- 옛이야기마다 **세 가족 배역표 한 줄**(누가 어느 역, 우리 버전 한 줄)을 데이터에 둔다.
