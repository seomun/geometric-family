# 「기하학 가족」 사업계획서 (요약판)

작성 2026-10-12 · 작성자 네모(1인 창작자) · 단계: 출시 준비(게임 10종 시험판 완성, 웹툰·쇼츠 연재 시작)

---

## 1. 한 줄 소개
**네모·세모·동그라미 세 도형 가족이 같은 일을 각자 다르게 겪는 이야기 IP.** 웹툰·쇼츠로 알리고, 게임·굿즈로 수익을 낸다.

## 2. 왜 지금, 왜 이것인가
- 작은 게임은 AI 덕분에 누구나 만들 수 있게 되어 **쏟아진다.** 게임 하나의 완성도만으로는 눈에 띄기 어렵다.
- 반대로 오래가는 것은 **캐릭터와 이야기**다(노래보다 가수·스토리가 소비되는 시대).
- 그래서 게임을 따로따로 파는 대신, **하나의 세계관에 웹툰·쇼츠·게임·굿즈를 묶는다.** 콘텐츠는 소비되지만 경험은 쌓인다.
- AI 로 그림·코드·검수를 맡겨 **1인이 여러 매체를 동시에** 운영할 수 있게 되었다.

## 3. 제품
| 매체 | 내용 | 현재 상태 |
|---|---|---|
| 웹툰 | 50대 동창 세 가족의 잔잔한 공감툰. 매 화 끝 "당신은 어느 도형인가요?" | 1·2화 제작, 네이버 블로그 연재 시작, 원고 15편·에피소드 씨앗 50여 개 |
| 쇼츠 | 통계 + 세 가족 반응, 작가 직접 나레이션 | 3편 제작, 유튜브·릴스·틱톡 |
| 정보 블로그 | 「짠내나는 경제학」(퇴직 후 혼자 버티는 작가 이야기 + 생활 통계) | 티스토리 준비 |
| 게임 10종 | 유아 3종(놀이터·색칠북·막둥이의 하루) + 성인 7종(방치형·머지·성격 테스트·틀린 그림·블록·정리·타일) | **출시 후보(RC7) 완성**, 웹 시험판 공개, 그림·음악 교체 대기 |
| 굿즈 | 캐릭터 스티커·노트·키링 + 게임 아이템 코드 | 기획(나중) |

**차별점**
1. **열 개 게임이 「우리 집」 하나를 공유** — 어느 게임에서 얻은 가구든 같은 집에 놓인다. 게임을 하나 더 깔 이유가 생긴다.
2. **누구나 아는 옛이야기 + 도형 가족 배역** — 설명이 필요 없는 이야기에 우리 캐릭터를 반복 노출.
3. **압박 없는 설계** — 하트·대기시간·뽑기 없음. 40~60대와 아이 부모가 안심하고 쓰는 브랜드.
4. **"당신은 어느 도형인가요?"** — 모든 매체 끝에 같은 질문. 댓글·공유가 IP 를 퍼뜨린다.

## 4. 고객
- **1차: 40~60대** — 웹툰 공감층, 퍼즐·방치형 게임 이용층(광고 수익의 중심).
- **2차: 3~7세 아이와 부모** — 유아 앱(안심 브랜드), 굿즈.
- 채널: 네이버 블로그(웹툰), 유튜브·인스타·틱톡(쇼츠), 티스토리(정보), 구글 플레이·갤럭시 스토어(게임).

## 5. 수익 모델
| 수익원 | 방식 | 시기 |
|---|---|---|
| 게임 광고 | 성인 7종: 보상형(선택) + 판 사이 광고(빈도 제한) + 홈 배너 / 유아 3종: 아동용 배너만 | 출시 즉시 |
| 게임 결제 | 광고 제거 1회 구매, 꾸미기 소품 팩(확정 지급, 뽑기 없음) | 출시 후 |
| 콘텐츠 | 블로그 광고(애드센스), 쇼츠 수익 | 구독자 조건 충족 후 |
| 퍼블리싱 | 게임 10종 퍼블리셔 계약(서버비 퍼블리셔 부담) | 협의 중 |
| 굿즈·협업 | 스티커·노트, 게임 아이템 코드 동봉 | 반응 확인 후 |

## 6. 지금까지 한 것 (2026년 9~10월, 약 4주)
- 세계관·캐릭터 13명 정본 시트, 상표 출원 준비(글자 + 캐릭터 그림)
- 웹툰 2화, 쇼츠 3편, 네이버 블로그·유튜브 채널 개설
- 게임 10종: 판 120개 안팎씩, 공통 화면·소리·「우리 집」·이야기 지도·순위표·이벤트 달력·광고 모듈·결제 모듈까지 → **출시 후보 완성**, 자동 점검 통과
- 출시 문서(스토어 문안·개인정보처리방침·아동 정책 점검표), 최저가 서버 단계 계획

## 8. 비용 (최소 운영)
| 항목 | 금액 | 비고 |
|---|---|---|
| AI 그림·음악 도구 | 약 $25~55 한 번(한 달 구독) | Scenario + Suno Pro, 이후 해지 |
| AI 개발 도구 | 월 구독료 | 기존 사용 |
| 상표 출원 | 류당 특허청 관납료 | 글자·캐릭터, 셀프 출원 |
| 서버 | 0원(1단계) | 정적 설정만. 늘면 퍼블리셔 부담(월 $5~20 수준 예상) |
| 스토어 등록 | 구글 플레이 1회 등록비 | 갤럭시 스토어 무료 |
→ **고정비가 거의 없는 구조.** 위험은 돈보다 시간과 반응이다.

## 9. 매출 가정 (보수적, 참고용)
- 광고 수익은 이용자 수에 비례한다. 예) 성인 앱 전체 **하루 이용자 1,000명**, 1인 하루 광고 1~2회, 광고 단가(eCPM) 약 $5~10 가정 → **월 약 $150~600**. 하루 이용자 1만 명이면 그 10배.
- 이 수치는 업계 평균 범위로 만든 **가정**이며 보장이 아니다. 출시 후 첫 3개월 실제 지표로 다시 쓴다.

## 10. 위험과 대응
| 위험 | 대응 |
|---|---|
| 알려지지 않음(유입 부족) | 웹툰·쇼츠·블로그가 게임 입구, "어느 도형?" 질문으로 공유 유도, 퍼블리셔 마케팅 |
| AI 그림의 저작권 | 상표(이름·캐릭터 그림) 우선 출원, 최종 그림은 사람이 손보고 과정 기록 후 저작권 등록 |
| 아동 앱 정책 | 유아 앱은 광고 최소·결제·알림·추적 없음, 정책 점검표로 관리 |
| 1인 운영 한계 | AI 로 제작·검수 자동화, 서버 없는 구조, 퍼블리셔에 운영 분담 |
