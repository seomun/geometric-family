# 25. ⑪ 아이용 방치형 RPG 「막둥이 원정대」(가칭) — 허브 컨셉 (2026-10-13, D22)

> 작가: "우리만의 독특한 게임을 하나 기획해 보자, 약간 방치형 RPG 같은 걸로, 아이들이 오래 할 수 있도록."

## 한 줄
**막둥이와 가족 친구들이 옛이야기 나라를 걸어가며, 곤란한 이웃을 "도와주고" 마을을 다시 세우는 방치형 RPG.** 싸우지 않는다 — **도와준다.**

## 왜 우리만의 것인가
- 방치형 RPG 의 "켜 두면 자란다·모으고 키운다" 재미는 그대로, **전투·피·뽑기 없이** "도와주기"로 바꾼다 → 유아·저학년도, 부모도 안심.
- 이미 만든 자산을 한 줄로 꿴다: 옛이야기 17편 = 17개 나라, 단일 배역표의 손님·카메오 = 동료, 「우리 집」 = 다시 세운 마을.

## 대상
만 5~9세(유치원 큰 반~초등 저학년) + 함께 보는 부모. 유아 그룹(D12, Families). 글자는 최소(아이콘·음성 슬롯), 저학년용 짧은 글은 선택.

## 코어 루프
```
원정대(3명: 네모·세모·동그라미 쪽 가족 한 명씩)가 이야기 길을 자동으로 걷는다
 → 「곤란」을 만난다(무너진 다리·바람 친구 장난·길 잃은 아기 곰·밑 빠진 독…)
 → 세 가족 힘으로 자동 해결: 네모 = 쌓고 막기(방패) / 세모 = 한 방에 번쩍(큰 힘) / 동그라미 = 정확히 고치고 돌보기(회복)
 → 별가루·이야기 조각을 얻는다 → 동료 키우기(레벨·소품 장비) → 다음 길
 → 장 끝 「큰 곤란」(그 이야기의 클라이맥스: 늑대 대신 바람 친구, 동아줄 내려 주기…) = 탭 몇 번으로 같이 돕는 짧은 놀이
 → 마을 재건: 도와준 이웃이 「우리 집」 마을로 이사 온다
```
- **방치**: 꺼 두어도 원정대가 천천히 걷는다(최대 8시간, 0.8배, 복리 없음 — ② 식탁과 같은 규칙).
- **켰을 때 할 일 3분**: 모인 별가루 받기 → 동료 1명 키우기 → 큰 곤란 하나 같이 돕기.

## 오래 하게 만드는 것 (압박 없이)
| 장치 | 내용 |
|---|---|
| 17개 나라 | 옛이야기 17편이 한 나라씩. 나라마다 곤란 30개 + 큰 곤란 1 |
| 동료 수집(뽑기 없음) | 이야기마다 도와준 손님이 동료로 합류 — 바람 친구·구름 거인·곰 세 식구… 확정 합류, 레벨·별 |
| 소품 장비 | 우산·모자·망치 등, 동료마다 3칸. 이야기 상징물(금도끼·꽃신)은 특별 장비 |
| 마을 재건 | 도와준 이웃의 집이 「우리 집」 옆 마을 칸에 생김 — 공유 룸과 연결 |
| 계절·이벤트 | 같은 주 같은 주제(달력) — 추석 원정·첫눈 원정 |
| 그림책 | 나라를 끝내면 그 이야기 그림책(우리 배역판)이 열림 — 부모와 읽기 |

## 지켜야 할 것
- 전투·쓰러짐·피·무서운 적 없음. 「곤란」과 「장난」만. 실패 없음(오래 걸릴 뿐).
- 뽑기·확률 보상·유료 재화 없음. 광고는 D19 유아 규칙(홈 배너만), 결제 없음.
- 놀이 시간 관리: 쉬어요 알림(보호자 설정) 그대로. 「오늘은 여기까지」 장면(원정대가 캠프에서 잠듦)으로 자연스럽게 끝맺음.
- 세 가족 공식·단일 배역표·호칭(막둥이 시점) 그대로. 악역은 가족 밖.
