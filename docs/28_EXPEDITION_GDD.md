# 28. ⑪ 「막둥이 원정대」 기획서 v1 (허브, 2026-10-13)

> 컨셉: docs/25. 이 문서는 **만들 수 있는 수준의 정본 기획서**다. 수치는 1차값 — gf-game 이 시뮬레이터로 검증하고 바꾼 값은 여기 고친다.
> 한 줄: **막둥이와 가족이 옛이야기 17나라를 걸으며 곤란한 이웃을 "도와주고", 도와준 이웃이 우리 마을로 이사 오는 방치형 RPG.** 싸우지 않는다.

| 그룹 | 유아 그룹(D12) — Families, 결제·알림·추적 없음, 광고는 홈·마을 화면 배너만(D19) |
| 글자 | 놀이 화면 글자 없음(아이콘·숫자 점·음성 슬롯). 이야기 자막 24px(끄기 가능). 숫자는 1~20까지만 화면에 |
| 세션 | **하루 2~3번 × 3~5분**, 보호자 「쉬어요」 알림 연동 |
| 오프라인 | 완전 오프라인. 방치 진행 최대 8시간, 0.8배, 복리 없음(② 식탁과 같은 규칙) |

## 2. 판타지 — 아이가 느껴야 할 것
1. **"내가 도와줬다"** — 곤란이 풀리는 순간이 매번 작게 기쁘다(전투의 쾌감 대신 해결의 쾌감).
2. **"우리 편이 늘어난다"** — 도와준 이웃이 동료가 되어 같이 걷는다.
3. **"우리 마을이 커진다"** — 그 이웃의 집이 마을에 생긴다. 다음 날 와 보면 마을이 바뀌어 있다.
4. **"그 이야기 알아!"** — 아는 옛이야기 속을 우리 가족이 걷는다.

## 3. 코어 루프
```
[걷기(방치)] 원정대 3명이 이야기 길을 자동으로 걷는다 → 「곤란」을 만난다(30초에 1번)
   → 자동 해결: 원정대 힘 합계 ≥ 곤란 크기면 바로 해결, 모자라면 천천히(실패 없음, 시간만 더 걸림)
   → 보상: 별가루(성장 재화) + 가끔 이야기 조각 · 소품
[켜기(3분)] 모인 별가루 받기(통 열기 연출) → 동료 한 명 키우기 → 「큰 곤란」 하나 같이 돕기(탭 놀이 20~40초)
[돌아가기] 장 클리어 → 도와준 이웃이 마을로 이사 → 그림책 한 장 열림 → 「오늘은 여기까지」 캠프 장면
```

## 4. 원정대와 「세 가족 힘」
- 원정대 3칸: **네모 칸 · 세모 칸 · 동그라미 칸** — 칸마다 그 가족 쪽 인물이나 동료 한 명.
- 시작 원정대: 막둥이(네모 칸) · 세모 이모(세모 칸) · 동그라미 아저씨(동그라미 칸).

| 힘 | 가족 공식 | 곤란에서 하는 일 | 표시 |
|---|---|---|---|
| 🟦 받치기 | 네모 = 많고 꾸준함 | 쌓기·막기·옮기기(무너진 다리, 짐 나르기) — **꾸준한 기본 힘** | 네모 블록 |
| 🔺 번쩍 | 세모 = 극단·한 방 | 가끔 크게(5번에 1번 ×3) — **반짝 연출** | 별 번쩍 |
| ⚪ 돌보기 | 동그라미 = 정확·채우기 | 고치기·달래기(아기 곰 달래기) — **모자란 만큼 채워 줌**(힘이 곤란보다 조금 모자랄 때 대신 메움) | 둥근 빛 |
- 곤란마다 **잘 맞는 힘**이 표시된다(아이콘 1개). 맞는 칸 동료가 힘을 1.5배로 낸다 → 아이가 "이번엔 세모가 잘해!"를 배운다(배치 = 유일한 전략, 어렵지 않게).

## 5. 동료 (수집 — 뽑기 없음)
- **확정 합류**: 나라마다 큰 곤란을 해결하면 그 이야기의 이웃 2명이 합류. 17나라 × 2 = **34명** + 시작 3명 + 가족(하나·두리·세찌·할머니·엄마·아빠 — 장 진행으로 합류) 6명 ≈ **43명**.
- 예: 아기돼지 나라 → 셋째 돼지(받치기), 바람 친구(번쩍, 장난을 그만두고 친구가 됨) / 세 마리 곰 나라 → 아기 곰(돌보기), 엄마 곰(받치기) / 흥부 나라 → 제비(번쩍).
- **성장**: 레벨 1~30. 레벨업 비용 = 별가루 `10 × 1.18^레벨`(1차값). 5레벨마다 모습이 조금 바뀜(모자·스카프 — 소품 장비 칸 열림).
- **소품 장비**: 동료당 1칸(5레벨)·2칸(15레벨)·3칸(25레벨). 소품 = 이야기 상징물(금도끼·꽃신·동아줄…) + 집 아이템 일부. 각 소품은 힘 +% 하나(단순).
- 중복·등급·별 강화·확률 **없음**. 모든 동료는 언젠가 다 모인다(완주 보장).

## 6. 나라와 곤란 (콘텐츠 분량)
- **17나라** = 옛이야기 17편(단일 배역표 순서). 나라당 **5장 × 6곤란 = 30곤란 + 큰 곤란 1**.
- 곤란 종류(아이콘): 무너진 것 고치기 · 짐 옮기기 · 길 찾기 · 달래기 · 장난 멈추기 · 물 채우기 · 높이 닿기 · 어둠 밝히기 — 8종을 나라마다 그 이야기 색으로 칠함(아기돼지 = 날아간 지붕, 콩쥐팥쥐 = 밑 빠진 독, 해님 달님 = 동아줄 내리기).
- **큰 곤란(나라 끝)** = 그 이야기의 클라이맥스를 탭 놀이로: 20~40초, 실패 없음. 놀이 8종을 돌려 씀(빠르게 톡톡 / 순서대로 / 끌어서 잇기 / 길게 누르기 / 같은 것 찾기 / 박자 / 문지르기 / 숨은 것 찾기 — ①⑩에서 이미 만든 놀이 재사용).
- 총: **510곤란 + 큰 곤란 17**. 1나라 ≈ 3~4일(하루 2~3세션) → 17나라 ≈ **2달**, 이후 「다시 걷기(시즌 길)」.

## 7. 마을 재건 (메타)
- 마을 = 「우리 집」 옆 칸들. 나라마다 이웃 집 1채 이사(17채) + 장마다 마을 소품 1개(85개).
- 마을 화면에서 이웃들이 **돌아다니며 인사**(카메오처럼). 탭하면 짧은 소리·몸짓.
- **마을이 주는 것**: 이웃 집 하나마다 별가루 통 크기 +5%(방치 효율 성장 — 이 게임의 장기 동력).
- 공유 룸 연결: 마을 소품은 유아 그룹 「우리 집」 아이템으로도 받는다(D12, ①④⑩ 과 공유).

## 8. 하루 리듬·오래 하게 하는 것 (압박 없이)
| 장치 | 내용 |
|---|---|
| 별가루 통 | 방치 보상은 통에 쌓이고, 열 때 쏟아지는 연출(가장 기쁜 순간). 8시간이면 가득 — 「통이 꽉 찼어요」 표시만, 알림 없음 |
| 오늘의 이웃 | 하루 한 명이 마을 광장에 찾아와 작은 부탁(곤란 1개) → 소품 확정. 놓쳐도 다음 날 다른 이웃 |
| 그림책 | 나라를 끝내면 그 옛이야기 그림책(우리 배역판, 8컷)이 열림 — 부모와 읽기, 자막·음성 슬롯 |
| 금요일 선물 | 유아 앱 공통(D21) |
| 계절 길 | 이벤트 달력과 같은 주 — 추석 길·첫눈 길(1주, 곤란 10개, 계절 소품). 놓쳐도 다음 해 + 「다시 열기」 |
| 「오늘은 여기까지」 | 세션 15분이 넘거나 보호자 쉬어요 시간이 되면 원정대가 캠프에 앉아 쉬는 장면 → 자연스러운 끝 |

## 9. 화면
1. 타이틀·첫 인사(막둥이가 손 흔들기) → 2. **원정 길**(메인: 가로로 흐르는 길, 원정대 3명, 위에 곤란 아이콘·진행 점, 아래 별가루 통) → 3. **원정대**(동료 카드 그리드, 칸에 끌어 놓기, 레벨업 큰 버튼 하나) → 4. **마을**(이웃 집·돌아다니는 이웃·오늘의 이웃) → 5. **이야기 지도**(GF.saga — 17나라) → 6. **그림책장** → 7. 큰 곤란 놀이 → 8. 집(공유 룸) · 보호자 메뉴(잠금 뒤: 쉬어요·소리·기록·놀이 요약)
- 키트·엔진 상단 바·GF.story·UK.finger·소리 id 그대로. 유아 앱이라 버튼은 그림만, ≥72dp.

## 10. 첫 20분(슬라이스 범위)
- 프롤로그 4컷(스토리 = 튜토리얼: 막둥이가 날아간 지붕을 보고 → 세모 이모가 번쩍 들어 올리고 → 동그라미 아저씨가 고쳐 주고 → "같이 가자!")
- 1나라(아기돼지 삼형제) 1~2장 = 곤란 12 + 손가락 시연 3번(통 열기·레벨업·배치)
- 첫 큰 곤란 미리보기(바람 친구가 지붕을 후~ → 탭으로 막기) → 바람 친구 합류
- 마을에 첫 이웃 집(셋째 돼지네 벽돌집) → 「오늘은 여기까지」
- 수용 기준: 첫 해결까지 15초 이내, 첫 레벨업 2분 이내, 글자 없이 아이(만 5세)가 혼자 진행 가능(헤드리스 시나리오 + 실기기 부모 1명)

## 11. 밸런스 1차값 (sim 으로 검증)
| 값 | 1차 |
|---|---|
| 곤란 크기 | 나라 n, 장 c: `8 × 1.35^(n-1) × 1.08^(c-1)` |
| 원정대 힘 | 동료 힘 = `3 × 1.15^(레벨-1)` × 맞는 힘 1.5 × 소품 % |
| 곤란 간격 | 30초(걷기) — 힘이 크기의 2배 넘으면 15초(빨리 감기) |
| 별가루 | 곤란 1개 = `크기 × 0.6`, 통 최대 = 8시간치 |
| 목표 | 나라당 3~4일, 레벨업은 세션마다 1~3번 가능, 막힘(진행 0) 없음 |
- sim(`tools/expedition_sim.js`): 하루 3세션 플레이어 모델로 17나라 완주 일수, 세션당 레벨업 횟수, 막힘 구간 0 단언.

## 12. 넣지 않는 것
전투·체력·쓰러짐·적 처치 / 뽑기·등급·중복 / 유료 재화·결제 / 에너지·대기시간 / 푸시 알림 / 채팅·친구 / 아이 개인정보. 악역은 가족 밖(바람 친구 등)이고 끝에는 친구가 된다.

## 13. 다른 게임과의 연결
- 단일 배역표(tales_cast) 그대로 — 원정대 동료 = 그 이야기의 배역.
- 이야기 카드: 나라를 끝내면 그 이야기 카드 1장(유아 그룹 장부).
- 카메오: ①④⑩ 의 가족이 마을에 놀러 옴.
- 그림 자리: 나라 배경 17 · 곤란 아이콘 8 · 동료 43 · 이웃 집 17 · 마을 소품 85 → ASSET_LIST(아트 패스 때 일괄).

## 14. 리스크
1. 방치형은 "할 게 없다"는 느낌 → 켤 때 3분 할 일(통·레벨업·큰 곤란·오늘의 이웃)을 항상 보장.
2. 유아에게 숫자 성장(%)은 안 읽힘 → 힘은 막대·별 개수로만, 숫자 최소.
3. 그림 수요가 큼(동료 43·집 17) → 동료는 기존 캐릭터·옛이야기 배역 재사용, 이웃 집은 room 아이템 재사용.
