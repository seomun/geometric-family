# 29. 「우리 집」 2.0 — 하우징 대개편 (허브, 2026-10-13, D24)

> 작가: "우리 집이 메인이잖아. 게임의 성패는 ① 우리 집을 채우고 싶고 ② 우리 집이 매력적이고 ③ 우리 집에 뭘 넣고 싶은지에 달려 있어. 채우는 목표와 다음 목표를 알려 주는 게 무척 중요해. 아이러브커피 등을 참고해서 대대적으로 개편하자."
> 지금 문제: 가독성 낮음(작은 아이콘 격자·빈 바닥), 채우고 싶은 동기 없음(목표·보상 없음), 무엇을 넣고 싶은지 보이지 않음(실루엣 자물쇠뿐).

## 0. 원칙 — 집이 메인, 게임 10종은 「가구를 벌어 오는 곳」
- 모든 앱의 홈 다음 화면이 집이다(집 → 「이 가구는 ○○ 게임에서」 → 게임 → 가구 들고 귀가).
- 레퍼런스: **아이러브커피**(인테리어 점수 → 손님·매출 증가, 카페 레벨로 공간·가게 해금, 방문), **홈스케이프·가든스케이프**(집 복원 이야기 + 할 일 목록 + 별), **동물의 숲**(가구 카탈로그·테마 세트·방문 평가), **쿠키런: 킹덤**(꾸미기가 성장과 연결), **포켓몬 캠프**(손님이 좋아하는 가구로 초대).

## 1. 채우고 싶다 — 「집 이야기」 목표 체계
- **집 이야기(복원 스토리)**: 세 가족이 막 이사 온 **텅 빈 집**에서 시작. 장마다 방 하나를 "사는 집"으로 만든다 — 1장 네모네 거실 「일곱 식구가 앉을 자리」, 2장 세모네 신혼집 「둘만의 여행 기념품 벽」, 3장 동그라미네 서재 「빈 의자 하나」…
- **할 일 3개가 항상 화면에** (홈스케이프식): 「네모네 거실에 큰 상 놓기 — **도형 합치기** 12판에서 얻어요 ▶」. 할 일을 끝내면 **별 → 방 이야기 다음 컷** + 집 레벨 경험치.
- **다음 목표 띠**(모든 앱 홈·결과 화면 공통): "다음: 소파 1개 남음 → 거실 완성!" + 그 가구를 주는 게임 바로가기(성인 그룹은 다른 앱 열기·스토어, 유아 그룹은 같은 앱 안 목표만).
- **방 완성도 %** 와 **세트 진행**(5개 중 3개)을 크게.

## 2. 매력적이다 — 「아늑함」 점수와 살아 있는 집
- **아늑함(집 점수)**: 가구마다 점수, **세트 완성·색 맞춤·테마 보너스**. 집 레벨 1~30.
- **집 레벨이 주는 것**: 새 방·마당·2층 확장(집이 실제로 커짐), 새 가구 진열장, 계절 장식, **가족 사연 컷**(그 방에서 일어나는 웹툰 한 장면).
- **살아 있는 집**: 세 가족 캐릭터가 방을 돌아다니고 **놓은 가구를 쓴다**(소파에 앉기·밥상에 둘러앉기·책장 앞에서 책 읽기). 가구를 탭하면 그 가구를 쓰는 짧은 동작.
- **손님(아이러브커피의 손님)**: 아늑함이 오를수록 카메오·이웃이 놀러 와 **좋아하는 가구 앞에서 말풍선**("이 김치냉장고 우리 집에도 있어요!"). 손님이 남기는 선물 = 소품(확정).
- **보기 좋은 화면**: 평면 격자 → **쿼터뷰(아이소메트릭) 방 한 칸 디오라마**, 바닥·벽지·창밖 풍경, 낮/저녁 조명. 사진 찍기(공유 카드).

## 3. 넣고 싶다 — 보이는 욕망
- **가구 카탈로그(도감)**: 모든 가구가 **흐린 실물 그림**(자물쇠 실루엣 아님) + 이름 + 「어디서 얻나(게임·판·이벤트)」 + 아늑함 점수 + 세트 소속.
- **완성 예시 사진**: 세트·방마다 "다 채우면 이렇게 돼요" 그림 한 장(꿈의 방) — 가장 강한 동기.
- **위시리스트 ♥**: 갖고 싶은 가구에 하트 → 다음 목표 띠에 우선 표시.
- **희귀 가구·계절 가구**: 이벤트 달력과 같은 주, 놓쳐도 「다시 열기」(D21 원칙).
- **색 바꾸기·변형**: 같은 가구 색 3~4종(모을수록 열림).

## 4. 가독성 — 화면 원칙
- 가구 카드 크게(성인 ≥ 88dp, 유아 ≥ 96dp), 이름·점수 한 줄, 카테고리 탭(가구·바닥·벽·소품·마당).
- 놓기: 끌어 놓을 때 **놓을 수 있는 칸 강조**, 자동 정렬 버튼, 되돌리기.
- 빈 방은 **「여기에 ○○를 놓아 보세요」 점선 자리** — 처음부터 무엇을 넣을지 보인다.
- 정보는 3층: 방 화면(크게) → 하단 「할 일 3」 → 카탈로그.

## 5. 게임과의 연결 (모든 앱 공통 변경)
- 결과 화면 보상 = **「집에 놓기」 버튼이 주인공**(가구 그림 크게 + 놓을 방 미리보기).
- 각 게임 홈에 「우리 집 레벨·다음 목표 띠」.
- 가구 분배표: 앱마다 그 장르에 맞는 방·세트(③ 가구·건축, ② 주방, ⑨ 마당 살림…)를 유지하되, **할 일이 여러 앱을 자연스럽게 돌게** 배치(성인 그룹 안 / 유아 그룹 안, D12).
- 유아 앱: 글자 없는 할 일(그림 + 화살표), 집 레벨은 별 개수로.

## 6. 하지 않는 것
유료 가구 뽑기(⑪ 예외 앱 제외), 아늑함 랭킹 경쟁, 꾸미기 시간 제한, 「안 들어오면 집이 낡는다」류 압박.
