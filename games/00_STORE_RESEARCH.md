# 00. 갤럭시 스토어 출시 경로·아동 앱 정책 조사

작성 2026-10-06 (gf-game). 웹 조사 기준이다. **셀러 포털에 로그인해 실제 화면으로 다시 확인해야 할 항목은 ⚠ 로 표시했다.**

## 결론 (요약)
1. **HTML5를 그대로 올리는 셀프서비스 경로는 지금 없다.** → **WebView APK로 포장**한다 (D10 대비안이 기본안이 된다).
2. 앱(APK)을 올리려면 **커머셜 셀러 승인**이 필요하다. 개인도 신분증으로 가능하지만 **판매자 이름·전화·주소·이메일·개인정보처리방침 URL이 스토어에 공개**된다.
3. 아동용은 **Kids 카테고리**: 13세 미만 설계, COPPA·GDPR 준수, **앱 밖으로 나가는 링크 금지**. 광고·결제·수집 없는 우리 설계와 맞는다.
4. 국내 게임 등급은 **삼성전자가 자체등급분류사업자**라 스토어 설문으로 받는다. 전체이용가는 게임물관리위원회(GRAC) 직접 신청 불필요.
5. **가장 큰 심사 리스크는 "비슷한 앱 여러 개 제출 금지"(배포 가이드 1.2.2)** 다. 시리즈를 작은 앱 5개로 쪼개면 걸릴 수 있다.

## 1. 출시 경로

| 경로 | 지금 상태 | 판단 |
|---|---|---|
| HTML5 직접 등록 (PWA) | 2019-11 미국 한정, 이메일 신청 방식으로 시작. 이후 공식 문서·셀러 포털에 셀프서비스 경로 없음 | ✗ |
| Instant Plays 1.0 (HTML5, 게임 런처) | 예외 목록에 이름만 남은 구형 프로그램. 신규 신청 안내 없음 | ✗ |
| Instant Plays 2.0 | **APK를 클라우드에서 스트리밍**하는 광고 유입용. 신청서 심사제 | ✗ (용도 다름) |
| **WebView APK** | 일반 안드로이드 앱. HTML·JSON·PNG를 앱 안(`assets/`)에 넣고 오프라인 실행 | **✓ 채택** |
| TWA (Bubblewrap) | 웹 호스팅 + 브라우저 의존. 오프라인·외부 링크 통제가 약함, Kids 정책과 충돌 소지 | △ |

**WebView 포장 기술 요건**
- 형식: APK 또는 AAB (AAB면 스토어가 범용 APK 생성)
- `targetSdkVersion ≥ 33` (Galaxy Store FAQ) — ⚠ 구글은 2026-08-31부터 36을 요구하므로 **35~36으로 맞춘다**
- 64비트 바이너리 1개 이상 — 네이티브 라이브러리 없는 순수 Java/Kotlin WebView 앱은 해당 없음
- 로컬 도구: **JDK 17, Android SDK(build-tools 34~36.1, platforms 33~34) 설치 확인됨** → Gradle 래퍼로 빌드 가능. platform 35/36만 추가 설치하면 된다
- 앱 안에서 다른 앱을 내려받게 하는 기능 금지(1.2.8)

## 2. 셀러 계정

| 항목 | 내용 |
|---|---|
| 비용 | 가입비·연회비 없음. 유료 결제 시 수수료 20% (우리는 무료라 해당 없음) |
| 상태 | 앱 배포에는 **Commercial Seller** 필요. Private Seller는 테마 등만 가능 |
| 개인 | 신분증 + 셀러 포털 이름 = 정산 계좌 예금주 이름 |
| 법인 | D-U-N-S 번호로 확인 (없으면 사업자 서류로 문의) |
| 이메일 | **Gmail 같은 공용 도메인은 비권장 — 쓰려면 사유 설명 필요.** 브랜드 Gmail(`{{SUPPORT_EMAIL}}`)을 쓰면 반려될 수 있다 ⚠ |
| 공개 정보 | 판매자명·회사명·**전화·주소**·개인정보처리방침 URL·지원 이메일이 스토어에 표시된다 |
| 승인 기간 | 수일~최대 영업일 10일 |
| 흔한 반려 | 회사 웹사이트 없음, 공용 도메인 이메일, 배포 계획 설명 부족, D-U-N-S 업종 불일치 |

→ **사람이 결정할 것**: 개인 명의로 갈지(실명·주소 공개) 사업자 명의로 갈지, 그리고 도메인 이메일을 만들지.

## 3. 아동용 정책 (Kids 카테고리, 배포 가이드 §3.3 외)
- 13세 미만 아동을 위해 설계되어야 한다
- 출시 국가의 아동 개인정보 법률 준수 (COPPA, GDPR, 국내 개인정보보호법 — 만 14세 미만 법정대리인 동의)
- **앱 밖으로 나가는 링크 금지** → 블로그·쇼츠·굿즈 링크를 게임 안에 넣지 않는다
- 광고는 연령에 맞아야 한다 (우리는 광고 없음)
- 데이터 수집이 없어도 **개인정보처리방침 URL은 등록 시 필요** → "어떤 정보도 수집하지 않습니다" 한 페이지를 자체 사이트(github.io)에 둔다
- 연령 등급: 전체 / 12+ / 16+ / 18+. 등록 시 지정하고 삼성 심사자 3명 이상이 합의해 확정
- 품질: "가치 있거나 재미있거나 독특해야", **비슷한 앱 여러 개 금지**(1.2.2), 다른 앱 베끼기 금지(3.2.1)

## 4. 국내 게임 등급
- 게임은 유통 전에 등급분류를 받아야 한다 (개인도 예외 없음)
- 자체등급분류사업자 10곳에 **삼성전자 포함** → 갤럭시 스토어 등록 설문으로 등급 부여. 청소년이용불가·아케이드만 GRAC 직접 심의
- 다른 플랫폼(원스토어 등)으로 넓힐 때는 GRAC에 게임물 정보를 전달해야 한다
