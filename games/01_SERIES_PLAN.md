# 01. 유아 게임 시리즈 기획안

작성 2026-10-06 (gf-game). 근거: `00_STORE_RESEARCH.md`, D10, 백서 §1·§5.

## 1. 대상
- **3~6세** (주 4~5세). 글을 못 읽는다고 가정 → **글자 없이 그림·소리·움직임으로 안내**. 버튼은 최소 64px, 드래그 판정은 넉넉하게.
- 실패 없음: 틀려도 캐릭터가 "다시!" 표정만 짓고 벌점·시간제한·점수 경쟁 없음.
- 부모: 한 판 3~5분, 설정·음량은 **부모 잠금**(버튼 3초 누르기) 뒤에.
- 세계관 연결: 네모네 막둥이(5살)가 주인공 겸 안내자. 도형 = 이름 = 성격이 아이에게도 그대로 통한다.

## 2. 앱 구조 — 하나의 앱에 호를 쌓는다 (권장)
배포 가이드 1.2.2 "비슷한 앱 여러 개 금지" 때문에 작은 앱 5개는 반려 위험이 있다.

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A. 놀이터 앱 1개 (권장)** | 「기하학 가족 놀이터」 하나에 1호→5호를 업데이트로 추가 | 심사·등급·개인정보 문서 1번, 리뷰·설치 수가 한곳에 쌓임, 아이가 계속 같은 앱을 연다 | 스토어 노출 칸이 1개 |
| B. 호마다 별도 앱 | 게임마다 앱 1개 | 노출 칸이 많다 | 1.2.2 반려 위험, 등록·관리 5배 |

방치형(어른용)은 대상·카테고리가 달라서 **별도 앱**.

## 3. 1~5호 (자산 준비 순서로 재배열 제안)
| 호 | 이름 | 놀이 | 필요한 그림 | 준비 |
|---|---|---|---|---|
| 1 | **도형 맞추기** | 네모·세모·동그라미 조각을 끌어 같은 구멍에 쏙 → 그 가족 캐릭터가 기뻐함 | 도형(코드 SVG) + 표정 PNG | ✅ 지금 있음 |
| 2 | **표정 짝꿍** | 카드 뒤집기(4→6→8장), 같은 표정 찾기 | 표정 PNG (세모 아내 12종 등) | ✅ 지금 있음 |
| 3 | **색칠 놀이** | 칸을 톡 → 색이 채워짐 | **칸이 나뉜 선화 SVG** (PNG로는 칸 채우기 불가) | ⬜ 허브 요청 |
| 4 | **꾸미기** | 모자·리본·옷 붙이기 (starry-village 엔진 이식) | **옷·소품 낱장 PNG** | ⬜ 허브 요청 |
| 5 | **모양 집짓기** | 도형 조각으로 집·기차·케이크 만들기 (칠교 입문) | 도형(코드) + 배경 | ✅ 거의 있음 |

D10의 순서(맞추기→색칠→꾸미기)에서 **2호에 「표정 짝꿍」을 끼워** 허브가 선화·옷 자산을 만드는 시간을 번다.

## 4. 공통 엔진 (`games/engine/`)
```
games/
├── engine/gf.js        ← 공통 엔진 (아래 6개 모듈, 의존성 없음)
├── engine/gf.css       ← 360×640 기준 레터박스, 큰 버튼, 부모 잠금
├── playground/index.html  ← 놀이터 홈 (호 선택 = 큰 그림 카드)
├── 01-shape-match/index.html
├── tools/build.py      ← 엔진·JSON 인라인 → 단일 HTML, 캐릭터 PNG 축소 복사
└── android/            ← WebView 포장 템플릿 (Gradle, 오프라인, 외부 링크 차단)
data/
├── chars.json          ← assets/*/manifest.json 을 읽어 만든 게임용 목록
└── 01-shape-match.json ← 단계·도형·칭찬 데이터
```
| 모듈 | 하는 일 |
|---|---|
| `scene` | 화면 전환(goto), 페이드, 뒤로가기(안드로이드 back 키 연동) |
| `touch` | 탭·드래그·스냅 판정, 멀티터치 무시, 손가락 크기 보정 |
| `sound` | WebAudio 효과음(코드로 합성) + 짧은 음성 클립, 음소거 |
| `save` | localStorage 이름공간(`gf:<게임>:`), 스티커·진행도, 실패해도 게임은 돈다 |
| `chars` | 캐릭터 PNG·표정 불러오기, 없는 표정은 폴백 (허브의 `src/` 방식 존중, 읽기만) |
| `gate` | 부모 잠금, 외부 링크 원천 차단 |

starry-village `dress-story` 에서 가져오는 것: 360×640 레터박스 `fit()`, `goto`/`save`/`load` 구조, 토스트·큰 버튼 CSS. 빼는 것: 광고(`showRewardedAd`), 대사창.
