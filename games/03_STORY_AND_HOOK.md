# 03. 차별화: 그림책 스토리 + 「나는 어느 도형?」 [제안]

작성 2026-10-06 (gf-game).

## 2. 스토리: 공공 전래동화의 뼈대를 그대로 쓴다
전래동화·옛이야기는 **저작권이 없다**(줄거리·구조·등장 동물). 다만 시중 그림책의 **글·그림·번역문과 상표 캐릭터**는 저작물이라, 줄거리만 가져와 **우리 말로 다시 쓰고 그림은 우리 것**으로 한다.

| 이야기 뼈대 | 기하학 가족 버전 | 이어지는 게임 |
|---|---|---|
| **아기돼지 삼형제** (세 형제, 세 집, 늑대) | **세 가족, 세 집.** 네모네는 벽돌집이 튼튼, 세모네는 지붕 뾰족한 집, 동그라미네는 둥근 집. 바람이 후~ 불어도 도형 조각을 맞게 쌓은 집은 안 무너진다 | 5호 도형 맞추기 / 집짓기 |
| **커다란 순무(무 뽑기)** | 마당의 큰 무를 네모네 할머니→엄마→아이들→막둥이가 줄줄이 당긴다. 마지막에 **세모 이모·동그라미 아저씨가 도와** 쑥! 7인 대가족이라 줄이 길다 | 4호 퍼즐 조각 (조각이 하나씩 모임) |
| **해와 달 / 호랑이와 곶감** | 곶감이 "뚝!" 하면 도망가는 호랑이 대신 **'뚝!' 소리에 깜짝 놀라는 세모 이모**. 무서운 건 빼고 소리 놀이로 | 2호 같은 얼굴 (놀람 표정) |
| **세 마리 염소(다리 건너기)** | 작은·중간·큰 도형이 다리를 건넌다. 동그라미 아저씨가 다리 아래에서 길을 터 준다 | 1호 그림자 찾기 (크기 순서) |
| **금발머리와 곰 세 마리** | 아빠 의자·엄마 의자·아기 의자 — **세 크기** 맞추기. 동그라미 아저씨·세모 이모·막둥이 | 크기 맞추기 확장 |

- **톤:** 무서운 장면은 지운다. 늑대는 "바람 친구", 호랑이는 나오지 않는다. 결말은 설명하지 않고 **웃는 컷 한 장**으로 끝낸다 (세계관 규칙 3·4).
- **세모 이모·동그라미 아저씨**는 항상 **도와주는 쪽**, 네모네 아이들은 **사건의 주인공**으로 둔다.
- **형식:** 그림책 6~8장면, 탭하면 넘어감, **글 없음 + 짧은 음성**(작가 녹음 또는 효과음). 이야기 하나가 끝나면 **이어지는 게임으로 자동 연결**되고, 게임을 깨면 그 이야기의 스티커 한 장.
- **제작량:** 한 이야기 = 기존 표정 PNG 6~8컷 조합 + 배경(코드). 새 캐릭터 그림 없이 가능하다.

## 3. 보너스: 「나는 어느 도형?」 (사진 없음)
- 아이가 **모양(네모·세모·동그라미) → 색 → 표정 → 소품(리본·안경·모자)** 을 고르면 **기하학 가족의 새 가족 한 명**이 만들어진다.
- 가족 사진 장면에 **우리 아이가 나란히 선다** — 앨범 마지막 장에 "우리 가족 사진" 한 장으로 저장(기기 안 localStorage, 공유는 부모 잠금 뒤 저장만).
- 세계관 훅 **"당신은 어느 도형인가요?"** 를 아이 눈높이로 옮긴 것이다. 사진도 서버도 필요 없다.
- 소품이 부족하면 허브에 요청한다(코드 SVG로 가능한 범위부터).

## 4. 차별화 한 줄
> **광고 없는 유아 앱 + 옛이야기를 도형 가족으로 다시 읽는 그림책 + 내 도형 가족 만들기.**
기존 유아 앱은 게임 묶음이거나 IP 한 편이다. 우리는 **그림책 → 게임 → 스티커 → 내 도형** 한 흐름이 있다.

## 5. 일정 영향
5개 게임은 그대로, 이야기 2편(아기돼지 삼형제·커다란 순무)을 1차 출시에 넣는다. 도형 아바타는 출시 후 첫 업데이트(2주 추가)로 둔다.
