# 04. 1편 「막둥이의 생일 가는 길」 — 이야기·스테이지·시스템 설계

작성 2026-10-06 (gf-game). 01~03 문서를 이 문서가 대체·구체화한다 (게임 순서 변경됨).
모델: **무료 · 광고 없음 · 결제 없음 · 가입 없음 · 오프라인.** 수익은 앱에서 내지 않는다. 목적은 IP 노출과 방치형(어른용) 유입이다. 앱 안에서 밖으로 나가는 링크는 없다(Kids 정책).

## 1. 이야기 — 하나로 이어지는 5장
**틀:** 오늘은 **막둥이(5살) 생일**. 세 가족이 언덕 위 잔칫집에서 모이기로 했다. 막둥이가 큰누나와 함께 잔칫집으로 가는 **다섯 개의 길목**에서 옛이야기를 하나씩 만난다. 옛이야기는 사건이 끝나면 **다음 길목으로 이어지는 실마리**를 남긴다.

| 장 | 옛이야기 뼈대 | 길목 | 우리 버전 한 줄 | 놀이 | 실마리 → 다음 장 |
|---|---|---|---|---|---|
| 1 | 세 마리 염소 (다리 건너기) | **시냇가 다리** | 다리가 좁아서 큰·중간·작은 순서로 줄을 서야 건넌다. 동그라미 아빠가 다리 아래서 길을 터 준다 | **그림자 찾기** | 건너편에서 "뚝!" 하는 소리 |
| 2 | 호랑이와 곶감 | **고갯마루** | 곶감이 "뚝!" 떨어지자 모두 깜짝! 세모엄마가 놀란 얼굴, 안 놀란 얼굴, 웃는 얼굴… 표정 짝을 찾아 소리의 정체를 밝힌다 (정체는 곶감) | **같은 얼굴 찾기** | 곶감 한 줄을 받아 든다 |
| 3 | 커다란 순무 | **마당 밭** | 잔칫상에 올릴 큰 무가 안 뽑힌다. 할머니→엄마→아이들→막둥이가 줄줄이 당기고, 마지막에 세모엄마·동그라미 아빠가 도와 쑥! | **퍼즐 조각** | 무가 빠진 구멍에서 해가 진다 |
| 4 | 해님 달님 | **해 질 녘 밤길** | 해가 지고 길이 깜깜하다. 막둥이와 누나가 해·달·별에 색을 칠해 하늘을 밝히며 간다 | **색칠하기** | 멀리 잔칫집 불빛 |
| 5 | 아기돼지 삼형제 | **언덕 위 잔칫집** | 바람(늑대 아님, "바람 친구")이 후~ 불어도 세 가족이 도형 조각을 맞게 쌓은 집은 무너지지 않는다. 문이 열리면 생일 잔치 | **도형 맞추기** | **가족사진 → 「나는 어느 도형?」 해금** |

- **난이도 곡선:** 끌어놓기(1) → 눈으로 찾기(2) → 맞추기(3) → 고르고 칠하기(4) → 쌓고 맞추기(5). 앞 장이 쉽고 뒤로 갈수록 한 단계 어렵다. 3살은 1~3장, 6살은 5장까지.
- **톤:** 무서운 건 없다. 호랑이 대신 "뚝!" 소리, 늑대 대신 바람 친구. 결말은 설명 없이 웃는 컷 한 장 (세계관 규칙 3·4).
- **가족 역할:** 아이들(막둥이·누나)이 **사건의 주인공**, 세모엄마·동그라미 아빠·네모네 어른은 **도와주는 쪽**, 세 가족은 5장에서 처음 한자리에 모인다.
- **작가 확인:** 장면 문장은 짧게 쓰고, 작가 녹음이 가능하게 **문장 20~30개**로 제한한다 (§7).

### 쓸 수 있는 그림 (assets 현재 기준)
| 인물 | 표정 | 비고 |
|---|---|---|
| 세모엄마 `wife` | 12 (angry bad calm cry good joy love smug surprise tired wink worry) | 가장 풍부 → 2장 주인공 |
| 동그라미 아빠 `dong_dad` | 6 (calm good joy surprise trouble warm) | 말없이 돕는 어른 |
| 네모 아빠·엄마 | 6 (good joy love surprise wink worry) | |
| 막둥이 `baby` | 6 (cry good joy love surprise tired) | 안내자 |
| 네모 아이들 `nemo_kids` | 1장씩 (kid1~3) | **표정 없음** → 포즈만 |
| 할머니 `nemo_grandma` | 1 (good) | 3장 순무에 "줄 서기"로만 |
※ 그림이 부족하면 장면을 바꾼다. 허브 요청은 **막판에 아이들·할머니 표정 몇 장**만 (선택).

## 2. 스테이지 구성
```
챕터 1개 = ①그림책 프롤로그(4~5컷) → ②놀이 스테이지 A·B·C → ③에필로그 컷 + 스티커
스테이지 1개 = 라운드 3개 (한 라운드 30~60초)
```
| 층 | 개수 | 시간 |
|---|---|---|
| 챕터 | 5 | |
| 스테이지 | 15 (장당 3) | 3~4분 |
| 라운드 | 45 | 한 판 30~60초 |
| **첫 완주** | | **약 40~60분** (3~6세가 여러 번 나눠서) |

### 장당 스테이지 사다리 (A 쉬움 → B 보통 → C 도전)
| 장·놀이 | A | B | C |
|---|---|---|---|
| 1 그림자 찾기 | 그림자 2개, 모양 크게 다름 | 그림자 3개, **크기 순서**(큰·중·작) | 그림자 4개, 닮은 모양(네모네 가족) |
| 2 같은 얼굴 | 4장 | 6장 | 8장, 세모엄마 12표정 |
| 3 퍼즐 조각 | 2조각 | 4조각 | 6조각, 조각 회전 없음 |
| 4 색칠하기 | 색 3, 칸 4개 | 색 5, 칸 6개 | 색 8, 칸 8개, 하늘+캐릭터 |
| 5 도형 맞추기 | 3개 구멍 | 5개 구멍 | 7개 구멍 + 바람 막기 |

### 라운드 규칙
- **실패 없음, 점수 없음, 시간제한 없음.** 틀리면 제자리로 튕겨 돌아가고 캐릭터가 고개를 갸웃(표정 `worry`)할 뿐.
- **별 1~3개 (자동):** 라운드를 깨면 ★1, 틀림 2회 이하 ★2, **힌트 안 쓰고 틀림 없음 ★3**. 다시 할 이유를 준다. 별은 스테이지 합계로 모은다.
- **힌트:** 5초 동안 입력 없으면 손가락 그림이 정답으로 움직인다. 10초면 정답 칸이 반짝.
- **적응형:** 연속 3번 틀리면 다음 라운드를 한 단계 쉬운 설정으로, 연속 3번 무틀림이면 한 단계 어렵게 (스테이지 안에서만, 숨김).
- **해금:** 스테이지 A만 처음 열려 있고, A를 깨면 B, B를 깨면 C, 한 장의 C를 깨면 다음 장. **별 조건은 없다** (못 넘어가는 일이 없게).

### 완주 이후 (다시 할 이유)
| 장치 | 내용 |
|---|---|
| **놀이방** | 5개 게임을 장 순서와 상관없이 고른다. 무한 모드: 라운드가 계속 새로 섞여 나오고 난이도는 아이가 정한다 (쉬움·보통·어려움 세 버튼) |
| **스티커 앨범** | 장마다 캐릭터 카드 5장씩, 모두 25장. 라운드 ★3이면 "반짝이 카드"로 업그레이드 |
| **별 3개 모으기** | 스테이지 C를 ★3으로 깨면 앨범에 금테 |
| **숨은 친구** | 홈 화면의 그림 속 동그라미 아빠·할머니를 탭하면 소리 + 스티커 (찾기 즐거움) |
| **그림책 다시 보기** | 깬 장의 그림책을 다시 본다 |
| **「나는 어느 도형?」** | 5장 완주 시 해금. 모양·색·표정·소품 고르기, 우리 가족사진에 서기 |

## 3. 화면 흐름
```
시작(로고 1.5초) → 홈 ─┬─ 이야기(길 지도: 5개 길목, 잠긴 곳은 그림자 처리)
                      ├─ 놀이방(게임 5장 카드)
                      ├─ 앨범(스티커 25 + 가족사진)
                      └─ 숨은 부모 메뉴(소리 크기·진행 지우기·방침) ← 3초 길게 누르고 + 간단 계산
이야기 → 그림책(탭으로 넘김) → 스테이지 선택(A·B·C 3칸) → 라운드 → 결과(별·스티커) → 다음
```
- **글자 없음**: 모든 버튼은 그림, 안내는 목소리·손가락 그림. 글은 부모 메뉴에만.
- **상단 고정 바**(모든 화면 공통): 홈 ⌂ · 별 ★ · 소리 ♪ . 홈 버튼은 **2번 탭**해야 나가 우발 종료를 막는다.
- 하단 큰 버튼 2개(다시·다음)만 있다. 안드로이드 뒤로가기 = 한 단계 위로, 홈에서 한 번 더 누르면 종료 확인.

## 4. 시스템 구성
### 폴더
```
games/
├── app/index.html          ← 단일 HTML (빌드 산출물, 소스는 아래)
├── engine/
│   ├── gf.js               ← 엔진 본체 (모듈 7개)
│   ├── gf.css              ← 공통 UI (360×640 레터박스, 64px 버튼)
│   └── modes/              ← 게임별 모듈: shadow.js faces.js puzzle.js paint.js shapes.js
├── scenes/                 ← 그림책(장별 컷 목록)
├── tools/build.py          ← 인라인 + PNG 축소(WebP) → app/index.html
└── android/                ← WebView 포장
data/
├── chars.json              ← 캐릭터·표정 목록 (assets/*/manifest.json 에서 생성)
├── story.json              ← 5장 컷·음성 id·실마리
├── stages.json             ← 15 스테이지 × 3 라운드 설정
└── stickers.json           ← 25장 정의
```
### 엔진 모듈
| 모듈 | 책임 |
|---|---|
| `core` | 화면 스택(push/pop), 상단 바, 뒤로가기, 레터박스 `fit()` |
| `input` | 포인터 통합(터치·마우스), 드래그·스냅, 손가락 크기 보정(판정 반경 +20%), 멀티터치 무시 |
| `audio` | WebAudio 효과음(코드로 합성), 음성 클립 재생, 볼륨, 첫 터치에 잠금 해제 |
| `store` | `localStorage` `gf:v1` 한 키에 JSON, 쓰기 실패해도 계속 동작, 버전 마이그레이션 |
| `chars` | `data/chars.json` 읽기, 캐릭터 `<img>` + 표정, 없는 표정은 `good` 폴백(허브 `src/` 방식과 동일) |
| `book` | 그림책 뷰어: 컷 목록 + 음성 id + 탭 넘김 |
| `stage` | 스테이지·라운드 러너, 별 계산, 힌트 타이머, 적응형 난이도, 해금 |
| `reward` | 별·스티커·앨범·가족사진 |
| `gate` | 부모 메뉴 잠금, 외부 링크 원천 차단(`<a href>` 자체를 만들지 않음) |

### 게임 모드 인터페이스 (게임은 이 하나만 구현)
```js
GF.mode('shadow', {
  setup(root, round, ctx){},   // round = stages.json 의 라운드 설정
  hint(level){},               // 1: 손가락, 2: 반짝
  destroy(){}
});
// ctx: { chars, audio, done({stars, mistakes, hints}), toast(imgId) }
```
새 게임 = `modes/*.js` 1개 + `stages.json` 설정. 메뉴·UI·저장은 건드리지 않는다.

### 데이터 예시
```json
// stages.json
{ "ch1": { "mode": "shadow", "stages": [
  { "id": "1A", "rounds": [
    { "targets": ["wife.good","dong_dad.good"], "decoys": 0, "sizeOrder": false },
    { "targets": ["wife.joy","nemo_dad.good"],  "decoys": 0 },
    { "targets": ["baby.good","wife.wink"],     "decoys": 1 } ] } ] } }
// story.json
{ "ch1": { "cuts": [
  { "bg":"stream", "chars":["baby.good","kid1"], "voice":"c1_01" },
  { "bg":"bridge", "chars":["dong_dad.warm"],    "voice":"c1_02" } ],
  "next":"c2_hint" } }
```
### 저장 (localStorage 한 키)
```json
{ "v":1, "stages": { "1A": { "done":true, "stars":3 } },
  "stickers": { "s01": 1, "s02": 2 }, "chapter": 2, "avatar": null,
  "settings": { "vol": 0.8, "mute": false } }
```
수집하는 개인정보 없음. 이름·사진·위치·기기 ID·분석 도구 없음 → 개인정보처리방침은 "수집 안 함" 한 장.

### 성능·품질
- 캐릭터 PNG는 빌드에서 **WebP 최대 480px 높이**로 줄여 앱 용량 15MB 이하 목표 (지금 PNG 총 약 18MB).
- 저사양 갤럭시 A 시리즈 기준 60fps(드래그), 메모리를 위해 화면 밖 이미지 해제.
- 접근성: 색 구분은 색+모양 모두, 소리 끄기 가능, 깜빡임 없음.

## 5. 게임별 핵심 메커니즘 (구현 메모)
| 게임 | 구현 | 어려운 점 |
|---|---|---|
| 그림자 찾기 | PNG를 `canvas`로 검정 실루엣화, 그림자 위 드롭 → 스냅 | 비슷한 실루엣은 사람이 보기 쉬운 것끼리 짝지음 |
| 같은 얼굴 | 카드 뒤집기 CSS, 표정 id로 짝 | 표정 12종이 모두 구분되는지 눈으로 검수 |
| 퍼즐 조각 | PNG를 격자로 잘라 조각 `canvas`, 비율 맞춰 스냅 | 투명 배경 조각 경계 |
| 색칠 | **먼저 시험**: 캐릭터 PNG 외곽선이 닫혀 칸 채우기(flood fill)가 되는지. 안 되면 코드 SVG 도안(집·해·달·별)으로 | 시험 결과에 따라 색칠 대상 변경 |
| 도형 맞추기 | 도형은 코드 SVG. 구멍 모양 = 도형 실루엣 | 5장 "바람 막기" 연출 |

## 7. 음성·글 (작가 몫 최소화)
- 그림책 **문장 25개 안팎** (장당 5개), 놀이 안내 **효과음 + "우와!" "다시!" 같은 반응 5개**.
- 녹음 전까지는 효과음과 말풍선 그림(🎵)으로 대체해 게임은 돈다. 음성이 도착하면 `voice` id 파일을 넣기만 하면 된다.
- 초안 문장은 제가 쓰고 작가가 고친다.
