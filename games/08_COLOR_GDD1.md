# 막둥이 색칠북 GDD-1 (docs/19 §10 양식)

## 한 줄 / 장르 / 대상 / 앱 분리
- **한 줄**: 내가 칠한 그림이 **집 벽의 액자**가 되는 색칠북 — 칠하면 걸린다.
- **장르**: 유아 창작(색칠·스티커·벽지) / **대상**: 3~7세 / **앱**: **유아 그룹**(①④) — 공유 룸 저장소 `gf:house:kid:v1`, 글자 없는 놀이 UI, 이야기는 24px 자막(GF.story), 보호자 잠금 `GF.gate`.
- 광고·결제·서버·공유 버튼 **없음**. 그림은 **기기 안에만**(저장 = 색 번호·스티커 위치뿐, 사진·그림 파일 내보내기 없음).

## 코어 루프 (3줄)
1. 색칠북에서 **그림 종류**(아이콘 6개)를 고르고 페이지를 연다.
2. 칸을 탭해 색을 칠하거나(번호·점 잇기·스티커·벽지는 각자의 방식) **완성 ✔** 을 누른다.
3. 완성작이 **액자가 되어 아이 방 벽에 걸린다**(대표 장면: 액자가 톡 떨어져 걸림 + 새 액자·장식 선물).

## 세 가족이 다른 맛 (docs/19 §2-2)
| 가족 | 색칠북에서 | 구현 |
|---|---|---|
| 🟦 네모 | 많이 — 칸이 많은 그림, 팔레트 10색, 액자가 벽을 가득 채움 | 자유 색칠 26장, 액자 8칸 격자 |
| 🔺 세모 | 큰 한 방 — 한 번에 바뀌는 것 | 벽지 만들기(색 두 번이면 방 전체가 바뀜) |
| ⚪ 동그라미 | 정확 — 맞는 색을 찾아야 | 번호 색칠(맞는 색만 칠해짐, 틀리면 갸웃·벌 없음), 점 잇기(1부터 차례로) |

## 웹툰 연결
**웹툰 컷 색칠** 12장 = 도형 가족 장면 12(저녁 식사·소파에서·이삿짐·화장실 줄·냉장고 앞·거실 꾸미기·김장하는 날·손님이 온다·큰 상 차리기·이사 가는 날·동네 한 바퀴·세 가족 한자리) — 도형 합치기 12장과 같은 사연([제안], `merge_extra.stories` 재사용). 칠하기 전에 공용 사연 컷(GF.story) 두 컷이 먼저 나온다.

## 집 세트 (벽지·액자 세트, 아이 방)
`w_frame` 내 그림 액자(완성작마다 한 장씩, `placed[].img = 페이지 id`) · `w_frame_gold`(5장) · `w_frame_pink`(10) · `w_garland` 깃발 줄(15) · `w_balloons` 풍선(20) · `w_stars` 별 모빌(30) · `w_rainbow` 무지개(45) · `w_crown` 왕관 걸이(60) — 완성 장수로 열림(데이터 `needPages`). 벽지는 방당 "무늬+두 색" 설명 하나(`Room.S.wall.kid`). 이모지는 임시 그림(ASSET_LIST 반영).

## 진행 구조 (docs/19 §5) — 페이지 68장, 데이터 한 줄로 무한 확장
| 판 종류(`type`) | 장 수 | 방식 |
|---|---|---|
| `free` 자유 색칠 | 26 | 집 가구·도형 얼굴 선화(룸 아이템 그림을 그대로) 칸 탭 칠하기 |
| `number` 번호 색칠 | 10 | 칸마다 번호, 맞는 색 번호를 골라야 칠해짐(원래 색이 정답) |
| `trace` 점 잇기 | 8 | 1부터 차례로 점을 이으면 모양이 나타나고 이어서 색칠 |
| `sticker` 스티커 장면 | 6 | 배경 6종에 가족·가구 스티커 16종을 끌어 놓기(3개 이상) |
| `wall` 벽지 만들기 | 6 | 도형 무늬 3 × 두 색 → 아이 방 벽지가 바뀜 |
| `webtoon` 웹툰 컷 색칠 | 12 | 사연 컷 → 장면 선화 색칠 |
- 튜토리얼: 첫 판 아이콘 한 장씩(글자 없음). 쉬어 가기: 자유 색칠이 그 역할. 마일스톤: 5장마다 장식 선물.
- **페이지 확장**: `tools/color_gen.py` 의 목록(또는 JSON)에 한 줄 추가 = 새 페이지. 새 선화는 룸 아이템 그림(아트 슬롯 교체 시 자동 갱신).

## 리스크 3개
1. **글자 없는 번호 색칠**: 번호는 숫자라 3~4세에게 어려움 → 번호 대신 색 점 힌트(색 모양 맞추기)를 병행할 수 있게 `number` 의 번호 표시를 나중에 옵션으로.
2. **선화 품질**: 지금은 룸 아이템 코드 그림이라 단순함 → 아트 패스(Recraft)로 선화 전용 SVG 교체(슬롯 `room[id]` 그대로).
3. **저장 용량·개인정보**: 완성작을 이미지로 저장하지 않고(설명만) 액자 때 다시 그림 → 용량 작음, 사진·내보내기 없음. 단, 스티커 장면 액자 이미지는 매번 합성(성능 확인 필요).
