# 당신은 어느 도형? GDD-1 (docs/19 §10 양식)

## 한 줄 / 장르 / 대상 / 앱 분리
- **한 줄**: 웹툰 속 하루 장면으로 "나는 네모·세모·동그라미 중 어느 쪽?"을 알아보고, 결과 카드가 **내 집의 문패·배지**가 되는 성격 테스트+미니게임.
- **장르**: 성격 테스트 + 미니게임 / **대상**: 만 13세↑ 일반(D12), 구현은 Families 수준(서버·SDK·외부 링크 0, `GF.gate` 유지) / **앱**: 성인 그룹(②③⑤) — 공유 룸 `gf:house:adult:v1`. 스토어 문구에 "아이용/유아" 표현 금지.
- **IP 역할**: 웹툰 모든 화 끝의 CTA 「당신은 어느 도형인가요?」를 게임으로 만든 **라인업 입구**. 결과 이미지 한 장이 공유 단위(이미지 저장).

## 코어 루프 (3줄)
1. 테스트(웹툰 장면 6문항, 선택지 3개)를 고른다 → 상황 컷을 보며 끝까지 고른다.
2. 결과 = **가족 1(네모·세모·동그라미) + 세부 타입 1(9종)** 의 카드: 이름·한 줄·장점·"다음 걸음"·가족별 비율 막대.
3. 카드가 **집의 문패·배지**가 되고(`q_plate_*`·`q_type_*`), 테스트를 더 할수록 **내 도형**(가장 많이 나온 가족)이 굳어져 다른 성인 앱의 힌트로 쓰인다(`Room.me`).

## 세 가족이 다른 맛 (docs/19 §2-2)
| 가족 | 세부 타입 3종(칭찬 먼저) |
|---|---|
| 🟦 네모 | 아빠형 「책임지는 든든한 계산기」 · 엄마형 「다 챙기는 만능 주머니」 · 막둥이형 「눈치 빠른 낙천가」 |
| 🔺 세모 | 남편형 「큰 한 방의 모험가」 · 아내형 「솔직한 감정 직진」 · 화해형 「싸우고 풀고 또 웃는 달달러」 |
| ⚪ 동그라미 | 아빠형 「완벽한 계획가」 · 엄마형 「조용한 관찰자」 · 아들형 「혼자서도 잘하는 모범생」 |
- 결과 문구 원칙: **어느 도형도 깎아내리지 않는다**(행복 먼저, 아이러니는 뒤). 각 타입에 "장점"과 부드러운 "다음 걸음"(장난스러운 제안)만 둔다. 점수·순위·집계 없음.

| 구간 | 내용 |

## 결과 공유(이미지 저장) — 정책
- 외부 SNS SDK·링크·서버 없음. **결과 카드를 PNG 이미지로 기기에 저장**하는 것까지만(웹: 브라우저 내려받기 / APK: 안드로이드 저장 브리지는 수익·정책 확정 후 연결, 권한 불필요한 방식 우선). 결과·응답은 기기 안에만 저장(`gf:quiz:v1`), 집계·통계 없음.

## 리스크 3개
1. **결과 신뢰·재미**: 3지선다 6문항은 단순 → 같은 사람이 테스트마다 다르게 나올 수 있음 → "내 도형"은 여러 테스트 누적으로 정하고, 카드에도 "여러 테스트 중 가장 많이 나온 쪽"임을 알린다.
2. **웹툰 원문 훼손**: 질문이 원문 장면을 가볍게 만들 수 있음 → 전부 [제안] 표기, 원문 문장은 질문 상황으로만 사용(QA 확인).
3. **이미지 저장 방식**: APK(WebView)에서 `a[download]` 가 동작하지 않음 → 안드로이드 브리지 필요(권한 없는 MediaStore 저장). 그때 정책 점검표 갱신.
