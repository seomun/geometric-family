# ① 놀이터 4권 「막둥이의 옛이야기 나들이」 GDD-1 (설계 · D6)

> 설계 문서만 있다(코드·데이터는 아직 없음). 그림은 전부 **슬롯**(`data/art_slots.json`)으로 비워 두고, 아트 패스(2026-10-10 이후)에 채운다. 문구·구성은 모두 **[제안]**.

16~20장, 3권(사계절)에 이어 **막둥이가 가족과 옛이야기 속을 걸어 보는** 나들이. 장마다 옛이야기 하나 + 놀이 하나. 놀이 화면에 **글자 없음**(큐는 그림·소리), 화자는 막둥이, 호칭은 아빠·엄마·할머니·세모 이모·세모 삼촌·동그라미 아저씨. 배역은 단일 배역표(`tools/tales_cast.py`)를 따르고, 가족 밖 악역(호랑이·늑대 등)은 **순한 판**이며 무서운 표현이 없다(유아 정책).

## 공통 규칙(1~3권과 같음)
- 틀려도 벌 없음(갸웃·제자리), 별 = 3판 평균(틀린 횟수 기준), 힌트 2단(깜빡 → 반짝), 놓친 것은 그냥 지나감. 정리 놀이(A21)처럼 **끌다가 닫기 사고**가 없도록 닫기는 꾹 누르기.
- 이야기: `GF.story`(장당 앞 3컷·뒤 3컷, 막둥이 시점), 스티커 25(`ch16_A`~`ch20_book`).
- 색 구분 돕기(C14)를 켜면 색만으로 고르는 놀이에 무늬를 더한다(신규 3종도 지킨다).
- 책장: 4권은 3권을 끝내면 열리고(2·3권과 같은 방식), 표지는 4번째 책 코드 그림(`COVER[4]`)·그림 슬롯 `cover.book4`.

## 신규 놀이 3종 설계
### `pair` 연못 짝 찾기 (18장)
- 연못 위 둥근 잎 카드가 엎어져 있고, 눌러 뒤집어 **같은 그림 한 쌍**을 찾는다. 그림은 가족 얼굴·소품(날개옷·사슴·보름달·장작 …).
- cfg: `{cards: 4|6|8, deck: [그림 id…], peek: ms}`. 시작에 잠깐(peek) 모두 보여 준다. 틀린 쌍은 1초 뒤 다시 엎어지고 **틀린 횟수만 ★에 반영**. 한 쌍씩 맞히면 연꽃이 핀다(닫는 연출·소리).
- 힌트: 1단 = 짝 하나가 살짝 반짝, 2단 = 한 쌍을 잠깐 보여 줌. 놓친 건 없음.
- 시험: `root.__pair` 훅으로 쌍을 풀어 3장×3판 통과 + 글자 없음 + 틀린 쌍 되돌림 + 터치 영역.

### `order` 크기 순서 (19장)
- 물고기 3~5마리가 흩어져 있고 **작은 것부터 큰 것 순서로** 줄 세운다(끌어다 칸에 놓기, 칸은 점선 윤곽 크기 순). 맞는 칸이면 붙고, 아니면 제자리(정리 놀이 3종 중 「크기 순서」와 같은 손 동작 재사용).
- cfg: `{n: 3|4|5, dir: 'up'|'down'}`(down = 큰 것부터, 3판째만). 크기 차이는 갈수록 줄어든다(1.6배 → 1.25배).
- 힌트: 1단 = 가장 작은 물고기 반짝, 2단 = 다음 칸 윤곽 반짝.

### `pattern` 무늬 이어 놓기 (20장)
- 길에 흘린 빵 부스러기(색·모양)가 AB·AAB·ABC 로 이어지다 **끊긴 자리**에 다음 것을 골라 끼운다(보기 3개, 하나만 맞음).
- cfg: `{unit: 'AB'|'AAB'|'ABC', len: 4~7, set: 모양 3종}`. 색만으로 맞히는 문제가 되지 않게 **모양도 항상 다르게**(C14).
- 힌트: 1단 = 끊긴 자리 깜빡, 2단 = 앞의 반복 한 묶음을 묶어 보여 줌.
