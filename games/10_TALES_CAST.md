## ③ 도형 합치기 12장 · ④ 옛이야기 색칠 12장 (같은 이야기, 장당 4컷 기승전결)

### 1장 아기돼지 삼형제 — 영국 민담(공유 저작물)
- 배역: 첫째 돼지(볏짚집) → 네모네 큰아이 [주인공·네모네] / 둘째 돼지(나무집) → 네모네 둘째 [주인공·네모네] / 셋째 돼지(벽돌집) → 네모네 셋째 [주인공·네모네] / 엄마 돼지 → 네모 엄마 [조력·네모네] / 늑대 → 바람 친구 → 바람 친구(가족 밖, 소리·바람) [악역·가족 밖]
- 우리 버전: 늑대 대신 바람 친구가 후— 불고, 지쳐서 웃는다. 벽돌집에서 모두 한 상에
- 원작에서 유지: 세 형제가 각자 집을 짓는다 · 볏짚·나무집은 날아가고 벽돌집은 끄떡없다 · 셋째의 집으로 모인다(셋째 집)

### 2장 세 마리 곰 — 영국 민담(사우디 1837, 공유 저작물)
- 배역: 큰 곰 → 동그라미 아빠 [주인공·동그라미네] / 중간 곰 → 동그라미 엄마 [주인공·동그라미네] / 아기 곰 → 동그라미 아들 [주인공·동그라미네] / 길 잃은 손님(소녀) → 세모 아내 [웃긴 실패역·세모네]
- 우리 버전: 동그라미네가 곰 가족. 크기가 다른 그릇·의자·침대, 아기 곰 것이 딱 맞는다 — 마지막엔 같이 한 상
- 원작에서 유지: 큰 것·중간 것·작은 것 세 번 시도 · 아기 곰의 것이 딱 맞음 · 곰이 돌아와 발견
- 그림 대기: 동그라미 엄마·아들 시트(임시: 동그라미 아빠 그림만 보임)

### 3장 구두장이와 요정 — 그림 형제(공유 저작물)
- 배역: 가난한 구두장이 → 네모 아빠 [주인공·네모네] / 구두장이 아내 → 네모 엄마 [조력·네모네] / 밤의 작은 요정들 → 요정(art.fairy) [조력·가족 밖]
- 우리 버전: 밤새 요정이 구두를 뚝딱, 아침마다 가죽이 늘어난다
- 원작에서 유지: 남은 가죽 한 켤레를 잘라 두고 잠든다 · 아침에 구두가 완성돼 있다 · 몰래 지켜보다 요정에게 옷을 지어 준다

### 4장 콩쥐팥쥐 — 한국 전래동화(공유 저작물)
- 배역: 콩쥐 → 네모네 큰아이 [주인공·네모네] / 팥쥐 → 네모네 둘째 [웃긴 실패역·네모네] / 도와주는 두꺼비 → 동그라미 아빠 [조력·동그라미네] / 꽃신 주인을 찾는 원님 → 세모 남편 [조력·세모네] / 일을 시키는 새엄마 → 깐깐한 아주머니(가족 밖, 목소리만) [악역·가족 밖]
- 우리 버전: 새엄마는 가족 밖 아주머니, 두꺼비가 독 구멍을 막고 마지막엔 팥쥐도 박수
- 원작에서 유지: 밑 빠진 독에 물 채우기 · 두꺼비·새의 도움 · 잔치에서 꽃신 한 짝을 잃는다 · 원님이 꽃신 주인을 찾는다

### 5장 흥부 박 — 한국 전래동화(공유 저작물)
- 배역: 흥부 → 네모 아빠 [주인공·네모네] / 흥부 아내 → 네모 엄마 [조력·네모네] / 놀부 → 세모 남편 [웃긴 실패역·세모네] / 제비 → 제비(art.swallow) [조력·가족 밖]
- 우리 버전: 식구 많은 흥부가 제비를 도와 박씨를 받는다, 놀부는 따라 하다 풍물패가 쏟아져 함께 잔치
- 원작에서 유지: 다친 제비를 고쳐 줌 · 박씨 → 박 타기 · 놀부의 따라 하기와 박

### 6장 브레멘 음악대 — 그림 형제(공유 저작물)
- 배역: 당나귀 → 네모 아빠 [주인공·네모네] / 개 → 세모 남편 [주인공·세모네] / 고양이 → 세모 아내 [주인공·세모네] / 수탉 → 동그라미 아빠 [주인공·동그라미네] / 도둑들 → 허깨비 도둑(가족 밖, 소리·그림자) [악역·가족 밖]
- 우리 버전: 늙었다고 쫓겨난 네 친구가 노래로 빈집을 얻는다 — 네 도형이 한 탑을 쌓음
- 원작에서 유지: 쫓겨난 동물 넷이 브레멘으로 · 탑처럼 올라서서 함께 소리 · 도둑이 달아나고 집을 차지

### 7장 혹부리 영감 — 한국 전래동화(공유 저작물)
- 배역: 혹부리 영감 → 네모 아빠 [주인공·네모네] / 도깨비 → 도깨비(art.dokkaebi, 순한 판) [악역·가족 밖] / 따라 하는 욕심쟁이 영감 → 동그라미 아빠 [웃긴 실패역·동그라미네]
- 우리 버전: 노래 주머니 혹과 도깨비 방망이 뚝딱, 따라 한 영감은 혹이 하나 더 붙고 함께 노래
- 원작에서 유지: 혹에서 노래가 나온다고 속음 · 도깨비 방망이(보물) · 따라 한 영감은 혹이 하나 더 붙음

### 8장 금도끼 은도끼 — 한국 전래동화(공유 저작물)
- 배역: 나무꾼 → 네모 아빠 [주인공·네모네] / 산신령 → 동그라미 아빠 [조력·동그라미네] / 욕심쟁이 이웃 → 네모 엄마 [웃긴 실패역·네모네]
- 우리 버전: 정직한 나무꾼은 금·은·쇠 도끼를 모두 받고, 따라 한 이웃은 웃음이 터져 쇠도끼만 받는다
- 원작에서 유지: 도끼가 연못에 빠짐 · 금도끼·은도끼·쇠도끼 세 번 물음 · 정직하면 모두 받음

### 9장 해님 달님 — 한국 전래동화(공유 저작물)
- 배역: 오빠(달님) → 네모네 큰아이 [주인공·네모네] / 동생(해님) → 네모네 둘째 [주인공·네모네] / 떡 팔러 간 엄마 → 네모 엄마 [조력·네모네] / 호랑이 → 바람 호랑이 → 바람 호랑이(가족 밖, 소리·그림자) [악역·가족 밖]
- 우리 버전: 호랑이는 가족 밖 바람 호랑이, 엉덩방아만 찧고 웃는다 — 동아줄은 그대로
- 원작에서 유지: 엄마 흉내를 내는 호랑이 · 나무 위로 피함 · 하늘에서 튼튼한 동아줄 · 해님과 달님이 됨

### 10장 개미와 베짱이 — 이솝(공유 저작물)
- 배역: 개미 → 네모 엄마 [주인공·네모네] / 베짱이 → 세모 남편 [웃긴 실패역·세모네] / 지켜보는 이웃 → 동그라미 아빠 [조력·동그라미네]
- 우리 버전: 여름엔 노래, 겨울엔 빈 곳간 — 개미는 곡식 한 줌과 「내년엔 같이」를 건넨다
- 원작에서 유지: 여름에 일하는 개미 / 노는 베짱이 · 겨울에 베짱이가 문을 두드림

### 11장 피노키오 — 콜로디(1883, 공유 저작물)
- 배역: 제페토(목수) → 네모 아빠 [주인공·네모네] / 피노키오(나무 인형) → 네모 막둥이 [웃긴 실패역·네모네] / 파란 요정 → 요정(art.fairy) [조력·가족 밖]
- 우리 버전: 거짓말하면 코가 길어지는 인형이 진짜 아이가 된다
- 원작에서 유지: 통나무로 인형을 만듦 · 거짓말하면 코가 길어짐 · 진짜 아이가 되는 소원

### 12장 잭과 콩나무 — 영국 민담(공유 저작물)
- 배역: 잭 → 네모네 둘째 [주인공·네모네] / 잭의 엄마 → 네모 엄마 [조력·네모네] / 구름 위 거인 → 구름 거인(가족 밖, 쿵쿵 소리·그림자, 순한 판) [악역·가족 밖] / 잔치 손님 → 세모 남편·동그라미 아빠 [조력·세모네]
- 우리 버전: 콩나무는 하늘까지, 거인은 구름 위에서 손을 흔든다 — 마지막엔 세 가족이 큰 상에
- 원작에서 유지: 소를 팔고 마법의 콩을 받음 · 하룻밤에 자란 콩나무 · 구름 위 거인의 성과 황금알 거위 · 콩나무를 베어 내려옴

## ① 놀이터 3권 11~15장 (막둥이 시점)

### 11장 의좋은 형제 — 한국 전래동화(공유 저작물) (놀이: 꽃 심기(수 세기 — 볏단 세기))
- 배역: 형 → 네모 형 [주인공·네모네] / 아우 → 막둥이 [주인공·네모네]
- 우리 버전: 밤마다 몰래 볏단을 옮기다 달밤에 딱 마주쳐요. 몇 단인지 세어 보며 놀아요.
- 원작에서 유지: 볏단을 똑같이 나눔 · 밤마다 몰래 서로에게 볏단을 옮김 · 아침마다 수가 그대로여서 이상해함 · 달밤에 길에서 마주침

### 12장 개미와 베짱이 — 이솝(공유 저작물) (놀이: 똑같이 나눠요(나눔))

- 우리 버전: 겨울이 오기 전에 열매를 똑같이 나눠요. 겨울에 베짱이가 문을 똑똑, 개미는 나눠 줘요.
- 원작에서 유지: 여름에 일하는 개미와 노는 베짱이 · 겨울에 베짱이가 문을 두드림

### 13장 금도끼 은도끼 — 한국 전래동화(공유 저작물) (놀이: 숨은 그림 찾기)
- 배역: 나무꾼 → 아빠 [주인공·네모네] / 산신령 → 동그라미 아저씨 [조력·동그라미네] / 욕심쟁이 이웃 → 세모 삼촌 [웃긴 실패역·세모네]
- 우리 버전: 정직한 아빠는 금도끼 은도끼를 모두 받고, 따라 한 세모 삼촌은 웃음이 터져요.
- 원작에서 유지: 도끼가 연못에 빠짐 · 금도끼·은도끼·쇠도끼를 차례로 물음 · 정직하면 모두 받음

### 14장 눈의 여왕(순한 판) — 안데르센(공유 저작물) (놀이: 눈송이 잡기(색 고르기))

- 원작에서 유지: 눈송이(거울 조각)가 눈에 들어감 · 눈의 여왕이 카이를 데려감 · 게르다가 찾아가 눈물로 녹임
- 그림 대기: 동그라미 아주머니 시트(임시: 그림 없이 글로만)

### 15장 콩쥐팥쥐 독 채우기 — 한국 전래동화(공유 저작물) (놀이: 박자 맞추기)

- 장면: 다친 제비 → 박씨 → 박 타기 → 쌀이 쏟아짐 → 형이 찾아옴 → 잔치 뒤 밤
- 방식: 장면마다 세 가지 반응(예: 박을 탈 때 하나씩 천천히 / 한 번에 다 / 순서대로 정확히) 중 내 쪽을 고른다
- 원작에서 유지: 제비를 고쳐 준 흥부 · 박 타기 · 형제의 방문

### 토끼와 거북이 — 이솝(공유 저작물)
- 장면: 출발 신호 → 그늘 → 낮잠 든 친구 → 결승선 → 경주가 끝남 → 저녁
- 방식: 경주·낮잠·결승선 장면에서 내 반응을 고른다
- 원작에서 유지: 느린 쪽과 빠른 쪽의 경주 · 낮잠

### 개미와 베짱이 — 이솝(공유 저작물)
- 장면: 여름 한낮 → 놀자는 친구 → 곳간 채우기 → 겨울 → 배고픈 이웃 → 봄
- 방식: 여름·겨울·곳간 장면에서 내 반응을 고른다
- 원작에서 유지: 여름의 일과 놀이 · 겨울에 문을 두드림

### 아기돼지 삼형제 — 영국 민담(공유 저작물)
- 장면: 집 짓기 → 바람 → 날아간 이웃집 → 벽돌집 → 지친 바람 → 완성된 밤
- 방식: 집 짓기·바람·벽돌집 장면에서 내 반응을 고른다
- 원작에서 유지: 세 형제 세 집 · 벽돌집은 끄떡없음

### 세 마리 곰 — 영국 민담(사우디, 공유 저작물)
- 장면: 그릇 → 의자 → 침대 → 곰의 귀가 → 같이 먹자는 말 → 식사 뒤
- 방식: 그릇·의자·침대 장면에서 내 반응을 고른다
- 원작에서 유지: 큰 것·중간 것·작은 것 · 작은 것이 딱 맞음
