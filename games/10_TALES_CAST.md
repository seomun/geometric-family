## ③ 도형 합치기 12장 · ④ 옛이야기 색칠 12장 (같은 이야기)

### 1장 아기돼지 삼형제 — 영국 민담(공유 저작물)
- 배역: 첫째 돼지(볏짚집) → 네모네 큰아이 / 둘째 돼지(나무집) → 네모네 둘째 / 셋째 돼지(벽돌집) → 네모네 셋째 / 늑대 → 바람 친구 → 세모 남편 / 엄마 돼지 → 네모 엄마
- 우리 버전: 늑대 대신 장난꾸러기 바람 친구, 벽돌집에서 모두 한 상에
- 원작에서 유지: 세 형제가 각자 집을 짓는다 · 볏짚·나무집은 날아가고 벽돌집은 끄떡없다 · 셋째의 집으로 모인다(셋째 집)

### 2장 세 마리 곰 — 영국 민담(사우디 1837, 공유 저작물)
- 배역: 큰 곰 → 동그라미 아빠 / 중간 곰 → 네모 엄마 / 아기 곰 → 네모 막둥이 / 길 잃은 손님(소녀) → 세모 아내
- 우리 버전: 크기가 다른 그릇·의자·침대, 아기 곰 것이 딱 맞는다 — 마지막엔 다 같이 한 상
- 원작에서 유지: 큰 것·중간 것·작은 것 세 번 시도 · 아기 곰의 것이 딱 맞음 · 곰이 돌아와 발견

### 3장 구두장이와 요정 — 그림 형제(공유 저작물)
- 배역: 가난한 구두장이 → 네모 아빠 / 구두장이 아내 → 네모 엄마 / 밤의 작은 요정들 → 요정(art.fairy)
- 우리 버전: 밤새 요정이 구두를 뚝딱, 아침마다 가죽이 늘어난다
- 원작에서 유지: 남은 가죽 한 켤레를 잘라 두고 잠든다 · 아침에 구두가 완성돼 있다 · 몰래 지켜보다 요정에게 옷을 지어 준다

### 4장 콩쥐팥쥐 — 한국 전래동화(공유 저작물)
- 배역: 콩쥐 → 네모네 큰아이 / 팥쥐 → 네모네 둘째 / 일을 시키는 어른 → 동그라미 아빠 / 도와주는 두꺼비 → 네모 엄마 / 꽃신 주인을 찾는 원님 → 세모 남편
- 우리 버전: 새엄마 대신 깐깐한 어른, 두꺼비가 독 구멍을 막고 마지막엔 팥쥐도 박수
- 원작에서 유지: 밑 빠진 독에 물 채우기 · 두꺼비·새의 도움 · 잔치에서 꽃신 한 짝을 잃는다 · 원님이 꽃신 주인을 찾는다

### 5장 흥부 박 — 한국 전래동화(공유 저작물)
- 배역: 흥부 → 네모 아빠 / 흥부 아내 → 네모 엄마 / 놀부 → 세모 남편 / 제비 → 제비(art.swallow) / 박 → 박(art.gourd)
- 우리 버전: 식구 많은 흥부가 제비를 도와 박씨를 받는다, 놀부 박에서는 풍물패가 나와 함께 잔치
- 원작에서 유지: 다친 제비를 고쳐 줌 · 박씨 → 박 타기 · 놀부의 따라 하기와 박

### 6장 브레멘 음악대 — 그림 형제(공유 저작물)
- 배역: 당나귀 → 네모 아빠 / 개 → 세모 남편 / 고양이 → 세모 아내 / 수탉 → 동그라미 아빠 / 도둑 → 놀란 집주인 → (소리만)
- 우리 버전: 늙었다고 쫓겨난 네 친구가 노래로 빈집을 얻는다 — 네 도형이 한 탑을 쌓음
- 원작에서 유지: 쫓겨난 동물 넷이 브레멘으로 · 탑처럼 올라서서 함께 소리 · 도둑이 달아나고 집을 차지

### 7장 혹부리 영감 — 한국 전래동화(공유 저작물)
- 배역: 혹부리 영감 → 네모 아빠 / 도깨비 → 도깨비(art.dokkaebi) / 따라 하는 욕심쟁이 영감 → 세모 남편
- 우리 버전: 노래 주머니 혹과 도깨비 방망이 뚝딱, 욕심쟁이는 혹이 하나 더 붙고 함께 노래
- 원작에서 유지: 혹에서 노래가 나온다고 속음 · 도깨비 방망이(보물) · 따라 한 영감은 혹이 하나 더 붙음

### 8장 금도끼 은도끼 — 한국 전래동화(공유 저작물)
- 배역: 나무꾼 → 네모 아빠 / 산신령 → 동그라미 아빠 / 욕심쟁이 이웃 → 세모 남편
- 우리 버전: 정직한 나무꾼은 금·은·쇠 도끼를 모두 받고, 이웃은 웃음이 터져 쇠도끼만 받는다
- 원작에서 유지: 도끼가 연못에 빠짐 · 금도끼·은도끼·쇠도끼 세 번 물음 · 정직하면 모두 받음

### 9장 해님 달님 — 한국 전래동화(공유 저작물)
- 배역: 오빠(달님) → 네모네 큰아이 / 동생(해님) → 네모네 둘째 / 떡 팔러 간 엄마 → 네모 엄마 / 호랑이 → 바람 호랑이 → 세모 남편
- 우리 버전: 호랑이는 엉덩방아만 찧고 웃는다(무서운 장면 순하게) — 동아줄은 그대로
- 원작에서 유지: 엄마 흉내를 내는 호랑이 · 나무 위로 피함 · 하늘에서 튼튼한 동아줄 · 해님과 달님이 됨

### 10장 개미와 베짱이 — 이솝(공유 저작물)
- 배역: 개미 → 네모 엄마 / 베짱이 → 세모 남편 / 지켜보는 이웃 → 동그라미 아빠
- 우리 버전: 여름엔 노래, 겨울엔 빈 곳간 — 개미는 곡식 한 줌과 「내년엔 같이」를 건넨다
- 원작에서 유지: 여름에 일하는 개미 / 노는 베짱이 · 겨울에 베짱이가 문을 두드림

### 11장 피노키오 — 콜로디(1883, 공유 저작물)
- 배역: 제페토(목수) → 네모 아빠 / 피노키오(나무 인형) → 네모 막둥이 / 파란 요정 → 요정(art.fairy)
- 우리 버전: 거짓말하면 코가 길어지는 인형이 진짜 아이가 된다
- 원작에서 유지: 통나무로 인형을 만듦 · 거짓말하면 코가 길어짐 · 진짜 아이가 되는 소원

### 12장 잭과 콩나무 — 영국 민담(공유 저작물)
- 배역: 잭 → 네모네 둘째 / 잭의 엄마 → 네모 엄마 / 구름 위 거인 → 동그라미 아빠 / 황금알을 낳는 거위 → (소품)
- 우리 버전: 콩나무는 하늘까지, 거인은 구름 위에서 손을 흔든다 — 마지막엔 세 가족이 큰 상에
- 원작에서 유지: 소를 팔고 마법의 콩을 받음 · 하룻밤에 자란 콩나무 · 구름 위 거인의 성과 황금알 · 콩나무를 베어 내려옴

## ① 놀이터 3권 11~15장 (막둥이 시점)

### 11장 효녀 심청(순한 판) — 한국 전래동화(공유 저작물) (놀이: 꽃 심기(수 세기))
- 배역: 심청 → 막둥이 / 심봉사(앞이 안 보이는 아버지) → 아빠 / 공양미를 말해 준 스님 → 할머니 / 연꽃 잔치의 임금님 → 동그라미 아저씨
- 우리 버전: 인당수에 빠지는 대신 연꽃이 막둥이를 안아 올려 줘요. 연꽃 잔치에서 아빠 눈이 번쩍!
- 원작에서 유지: 앞이 안 보이는 아버지 · 눈을 뜨게 해 줄 약속 · 연꽃으로 다시 만남 · 잔치에서 아버지가 눈을 뜸

### 12장 개미와 베짱이 — 이솝(공유 저작물) (놀이: 똑같이 나눠요(나눔))
- 배역: 개미 → 엄마·막둥이 / 베짱이 → 세모 삼촌
- 우리 버전: 겨울이 오기 전에 열매를 똑같이 나눠요. 겨울에 베짱이가 문을 똑똑, 개미는 나눠 줘요.
- 원작에서 유지: 여름에 일하는 개미와 노는 베짱이 · 겨울에 베짱이가 문을 두드림

### 13장 금도끼 은도끼 — 한국 전래동화(공유 저작물) (놀이: 숨은 그림 찾기)
- 배역: 나무꾼 → 아빠 / 산신령 → 동그라미 아저씨 / 욕심쟁이 이웃 → 세모 삼촌
- 우리 버전: 정직한 아빠는 금도끼 은도끼를 모두 받고, 세모 삼촌은 웃음이 터져요.
- 원작에서 유지: 도끼가 연못에 빠짐 · 금도끼·은도끼·쇠도끼를 차례로 물음 · 정직하면 모두 받음

### 14장 눈의 여왕(순한 판) — 안데르센(공유 저작물) (놀이: 눈송이 잡기(색 고르기))
- 배역: 카이 → 네모 형 / 게르다 → 막둥이 / 눈의 여왕 → 동그라미 아저씨
- 우리 버전: 얼음 궁전은 포근한 눈 궁전, 막둥이의 따뜻한 눈물에 눈송이가 녹아요.
- 원작에서 유지: 눈송이(거울 조각)가 눈에 들어감 · 눈의 여왕이 카이를 데려감 · 게르다가 찾아가 눈물로 녹임

### 15장 콩쥐팥쥐 독 채우기 — 한국 전래동화(공유 저작물) (놀이: 박자 맞추기)
- 배역: 콩쥐 → 막둥이 / 팥쥐 → 네모 형 / 도와주는 두꺼비 → 할머니 / 꽃신 주인을 찾는 원님 → 세모 삼촌
- 우리 버전: 구멍 난 독은 두꺼비 할머니와 박자를 맞춰 채워요. 꽃신을 찾아 준 원님 앞에서 형도 함께 웃어요.
- 원작에서 유지: 밑 빠진 독에 물 채우기 · 두꺼비의 도움 · 꽃신 한 짝을 잃고 원님이 찾아 줌

## ⑤ 「동화 속 당신은?」 5종

### 흥부와 놀부 — 한국 전래동화(공유 저작물)
- 선택지 배역: 흥부 → 네모형 선택 / 놀부 → 세모형 선택 / 둘 사이에서 지켜보는 이웃 → 동그라미형 선택
- 우리 버전: 제비·박·나눔 장면마다 세 가지 반응 중 내 쪽을 고른다
- 원작에서 유지: 제비를 고쳐 준 흥부 · 박 타기 · 놀부의 따라 하기

### 토끼와 거북이 — 이솝(공유 저작물)
- 선택지 배역: 거북이 → 네모형 선택 / 토끼 → 세모형 선택 / 심판 → 동그라미형 선택
- 우리 버전: 경주·낮잠·결승선 장면에서 내 쪽을 고른다
- 원작에서 유지: 느린 거북이와 빠른 토끼의 경주 · 토끼의 낮잠

### 개미와 베짱이 — 이솝(공유 저작물)
- 선택지 배역: 개미 → 네모형 선택 / 베짱이 → 세모형 선택 / 곳간을 지켜보는 이웃 → 동그라미형 선택
- 우리 버전: 여름·겨울·곳간 장면에서 내 쪽을 고른다
- 원작에서 유지: 여름에 일하는 개미와 노는 베짱이 · 겨울에 문을 두드림

### 아기돼지 삼형제 — 영국 민담(공유 저작물)
- 선택지 배역: 셋째(벽돌집) → 동그라미형 선택 / 첫째(볏짚집) → 세모형 선택 / 둘째(나무집) → 네모형 선택
- 우리 버전: 집 짓기·바람·벽돌집 장면에서 내 쪽을 고른다
- 원작에서 유지: 세 형제 세 집 · 벽돌집은 끄떡없음

### 세 마리 곰 — 영국 민담(사우디, 공유 저작물)
- 선택지 배역: 큰 곰 → 동그라미형 선택 / 중간 곰 → 네모형 선택 / 작은 곰·손님 → 세모형 선택
- 우리 버전: 그릇·의자·침대 장면에서 내 쪽을 고른다
- 원작에서 유지: 큰 것·중간 것·작은 것 · 작은 것이 딱 맞음
