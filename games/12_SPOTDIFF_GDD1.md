# ⑥ 다른 그림 찾기 GDD-1 (docs/19 §10 양식 · docs/21 D14) — 설계안, 20판 슬라이스 전

## 한 줄 / 장르 / 대상 / 앱 분리
- **한 줄**: 두 그림을 나란히 보고 다른 곳을 눌러 찾는다. 그림은 옛이야기 장면과 웹툰 컷이고, 틀린 곳 하나하나가 가족의 작은 이야기가 된다.
- **장르**: 틀린 그림 찾기(검증된 문법 그대로: 위아래 두 그림, 다른 곳을 탭, 찾으면 동그라미 표시, 남은 개수 칩). **시간 제한·하트 없음**, 틀리게 눌러도 벌 없이 살짝 흔들림만, 힌트는 언제든.
- **대상**: 만 13세↑ 일반(D12), 구현은 Families 수준(데이터·SDK·외부 링크 0, 권한 0). **앱**: 성인 그룹(②③⑤⑥⑦) — 공유 룸 저장소 `gf:house:adult:v1`, flavor `spot`(`com.geometricfamily.spot`).
- 한 판에 걸리는 시간 1~3분. 글자 크기 18px 이상, 한 손 조작(그림은 세로로 위아래 배치).

## 코어 루프 (3줄)
1. 위 그림(원본)과 아래 그림(바뀐 그림)을 본다. 아래 그림에서 다른 곳을 탭한다(손가락으로 두 번 짚어 확대도 가능).
2. 맞으면 동그라미가 그려지고 소리 `ok`(찾을수록 한 음씩 올라감), 남은 개수 칩이 줄어든다. 틀리면 살짝 갸웃(소리 `hmm`)만, 횟수에는 영향 없음.
3. 모두 찾으면 클리어. 별: 힌트·틀린 탭이 적을수록(★3 = 힌트 0·틀린 탭 3 이하). 찾은 곳마다 그 장면의 한 줄 사연이 뜨고, 판을 깨면 사진 한 장이 「우리 집」 벽에 걸린다.

## 장면 만들기 — 생성기가 곧 정답표
- 장면 = 요소 목록(캐릭터 `id.표정`·소품 art·도형·배경·글씨 없음) + 좌표. 코드 SVG/PNG 합성이라 저작권이 깨끗하고, 같은 장면에서 **틀린 곳을 연산으로 만들기 때문에 정답 좌표가 정확히 알려져 있다**(사람이 일일이 찍지 않는다).
- 틀린 곳 연산 7가지: 색 바꾸기 · 없애기 · 추가하기 · 위치 옮기기 · 크기 바꾸기 · 뒤집기 · 표정 바꾸기. 판마다 N곳(3→10)을 서로 겹치지 않게 고른다.
- **검증(생성기 단언)**: ① 틀린 곳 영역끼리 거리 ≥ 최소값 ② 모든 틀린 곳이 화면 안 ③ 색 차이는 명도 차 기준 이상(보이게) ④ 변화가 실제로 두 그림 픽셀을 바꿈(렌더 비교). 안 보이는 틀린 곳이 있는 판은 버리고 다시 만든다.

## 판 종류 (6+ 목표) · 공통 4
| type | 규칙 |
|---|---|
| `diff` 기본 | 위아래 두 그림, 틀린 곳 N개 |
| `odd` 다른 하나 | 같은 그림 9칸 중 하나만 다르다(몇 번 하면 쉬운 워밍업) |
| `hidden` 숨은 물건 | 한 장면에 숨은 물건 목록(예: 곶감·금도끼·박씨)을 찾기 |
| `zoom` 확대 | 큰 그림을 확대·이동하며 작은 차이 찾기 |
| `memory` 기억 | 원본을 3초 보여 주고 가린 뒤 바뀐 곳 찾기(시간 압박 없이 다시 보기 가능) |
| `three` 세 가족 | 같은 장면을 네모·세모·동그라미가 다르게 겪은 세 장 — 세 그림 사이 차이를 찾는다(틀린 곳 = 가족 차이) |
| 공통: 오늘의 한 판 | 날짜 시드 장면 |
| 공통: 시즌 판 | 추석·김장·연말 장면 |
| 공통: 사연 판 | 장의 마지막 판을 깨면 옛이야기 4컷(D13) |
| 공통: 세 가족 판 | 같은 장면을 세 규칙으로: 네모=틀린 곳이 많음(여러 곳을 눌러도 됨) · 세모=틀린 곳이 크고 색이 튐 · 동그라미=작고 한 곳씩 정확히 |

## 이야기 (D13)
- 장 이름은 옛이야기 + 웹툰 컷 섞기. 판마다 장면은 그 이야기의 명장면(예: 흥부 박에서 박이 열린 장면), 틀린 곳마다 한 줄 사연(「제비 다리의 붕대가 사라졌어요」). 악역은 가족 밖, 호칭은 웹툰 기준.
- 1~2장은 ⑦과 같은 옛이야기(아기돼지·브레멘)로 시작해 타이틀 간 통일감, 3장부터는 ⑥만의 장면(세 가족 웹툰 컷 4장 포함). 배역표는 `tools/tales_build.py`에 ⑥ 항목으로 추가해 가족 악역 0·세모 웃긴 실패역 ≤3 단언 적용.

## 집 세트 — 「사진·앨범 세트」(벽 사진·앨범장, 아이 방·거실 벽)
판 클리어마다 한 장이 앨범에 모이고, 장을 끝내면 벽 사진·액자·앨범장이 열린다(8종 → 장당 1). 그림은 임시 이모지(ASSET_LIST), 코드(선물·굿즈)는 불변 번호 `no`.

## 난이도 곡선 (측정 계획)
- 틀린 곳 수 3→10, 크기 큼→작음, 색 차이 큼→미묘, 판 종류 도입 순서(diff → odd → hidden → three → zoom → memory).
- sim: 생성된 판마다 정답 좌표를 모두 탭하는 풀이 재생(성공 100%), "초보 탭 모델"(큰 차이 우선·무작위 탭 12%)로 힌트 없이 끝낼 확률을 지표로 곡선을 잰다.

## 통일성 §0 체크 (처음부터)
키트(UK)·엔진 상단 바·같은 `GF.story` 사연 컷·`UK.finger`(첫 판에서 틀린 곳 하나를 알려 줌)·첫 인사 `greet`·같은 sounds id(`ok`·`hmm`·`pick`·`star`)·공유 「우리 집」·홈 대표 그림 슬롯 `hero:spot`·호칭은 웹툰 기준. 첫 30초 1~2탭, 압박 없음(하트·에너지·대기 없음, 실패 개념 자체가 없음), 20판 슬라이스는 틀린 곳 연산·판 종류 6·공통 판 4를 갖춘다.

## 슬라이스 범위(허브 OK 후)
`games/spot/{spot-core.js(채점·좌표),spot-gen.js(장면·연산·검증),spot.js,spot.css,index.html}` · `data/spot_levels.json`(+`spot_extra.json` 사연·시즌) · `tools/spot_gen.js`·`spot_sim.js`·`spot_smoke.js` · `games/tools/build_spot.py` · flavor `spot` · 스토어 문서·스크린샷·ASSET_LIST. 순서는 ⑦ 확장 → ⑥ 슬라이스 → ⑨ → ⑧ → ⑩.

## 열린 질문 (허브)
1. 장면 그림은 임시로 기존 캐릭터·소품 합성으로 가도 되는지(아트 패스에서 일러스트 한 장씩 교체).
2. `memory` 판은 「시간 제한 없음」 원칙과 맞는지(3초 보여 주고 다시 보기 무제한).
3. ⑥의 사연 한 줄을 판마다 넣으면 텍스트 양이 많아 작가 확인 부담이 큼 — 슬라이스에선 장당 4컷 사연 + 틀린 곳 한 줄 자막만으로 한정하는지.
