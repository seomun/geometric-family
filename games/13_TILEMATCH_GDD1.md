# ⑨ 세 가족 짝 맞추기 GDD-1 (docs/19 §10 양식 · docs/21 D14) — 설계안, 20판 슬라이스 전

## 한 줄 / 장르 / 대상 / 앱 분리
- **한 줄**: 쌓여 있는 그림 타일을 눌러 아래 바구니에 모으고, 같은 그림 세 개가 모이면 사라진다. 타일은 집 살림·음식·세 가족 얼굴이고, 같은 것 세 개는 옛이야기의 상징(흥부 박·금도끼·곶감)이 된다.
- **장르**: 타일 매치(3개 모으기, 7칸 바구니 — 타일 마스터형). **검증된 문법 그대로**: 위층 타일이 아래 타일을 가리고(가려진 타일은 어둡게, 누를 수 없음), 누른 타일은 바구니에 줄지어 들어가며, 같은 그림 3개가 모이면 지워진다. 바구니가 가득 차면 끝.
- **압박 없음**: 시간 제한·하트·에너지·유료 이어하기 없음. 바구니가 차면 벌 없이 즉시 새 판(한 번 더), **되돌리기 한 판에 한 번(마지막 타일을 바구니에서 빼기)**, **섞기 한 판에 한 번**, 힌트(누를 수 있는 같은 그림 하나 반짝)는 언제든. 쉬어 가기 판은 바구니 9칸.
- **대상**: 만 13세↑ 일반(D12), 구현은 Families 수준(데이터·SDK·외부 링크 0, 권한 0). **앱**: 성인 그룹(②③⑤⑥⑦⑨) — 공유 룸 저장소 `gf:house:adult:v1`, flavor `tile`(`com.geometricfamily.tile`).
- 글자 크기 18px 이상, 한 손 조작, 타일은 한 변 44~52px(터치 64dp 기준).

## 코어 루프 (3줄)
1. 쌓인 타일 더미에서 **가려지지 않은 타일**을 탭하면 아래 바구니(7칸)로 날아가 줄지어 선다(같은 그림끼리는 나란히 붙는다).
2. 같은 그림이 3개 모이면 **톡** 사라진다(연속으로 사라지면 소리가 한 음씩 올라감 `GF.sfx('ok',{st})`). 사라지면 칸이 비어 여유가 생긴다.
3. 더미를 전부 치우면 클리어. 별: 쓴 되돌리기·섞기·힌트가 적을수록(★3 = 도구 0회). 판을 깨면 마당 살림 소품이 「우리 집」에 놓인다.

## 판 만들기 — 풀 수 있음을 구성으로 보장
- 타일 수 = 3의 배수. **풀이 순서에서 거꾸로 만든다**: 같은 그림 3개 묶음을 한 번에 하나씩 맨 위에서부터 놓아 가며 층을 쌓으므로, 처음부터 어떤 순서로 누르면 항상 클리어되는 판이 나온다(검증 풀이 = 이 순서).
- 난이도 지표: 풀이 순서와 별개로 **탐욕 사람 흉내**(같은 그림이 이미 바구니에 있으면 우선, 가려진 타일을 열어 주는 쪽 우선, 12% 무작위)로 승률을 재고, 바구니 최대 사용 칸 수도 잰다. 판이 갈수록 층 수·종류 수가 늘고 승률이 내려가는 곡선을 sim 으로 확인.
- 타일 그림: 방 아이템(`b_*`·`o_*`·`p_*`)·음식 이모지·세 가족 얼굴(타일용 작은 얼굴)·이야기 소품(박·곶감·도끼 등). **그림만으로 구분되게** 색에 의존하지 않고 모양이 다른 것끼리만 한 판에 쓴다(비슷한 모양 쌍은 같은 판에 못 나옴).

## 판 종류 (6+ 목표) · 공통 4
| type | 규칙 |
|---|---|
| `classic` | 더미를 전부 치우기(바구니 7칸) |
| `goal` 모으기 | 정해진 그림 N묶음(예: 박 ×3 두 묶음)을 먼저 만들면 클리어(나머지 타일은 남아도 됨) |
| `lock` 잠금 | 자물쇠 타일은 같은 줄의 열쇠 타일을 먼저 지워야 눌린다 |
| `narrow` 좁은 바구니 | 바구니 5칸(대신 타일 수가 적고 풀이가 짧다) |
| `pair` 짝 | 같은 그림 2개만 모이면 지워짐(워밍업, 초반 판) |
| `trio` 세 가족 | 타일이 네모·세모·동그라미 얼굴 — 같은 가족 세 얼굴이 모이면 지워짐(바구니는 가족별로 색 띠) |
| 공통: 오늘의 한 판 | 날짜 시드, 종류가 요일마다 바뀜 |
| 공통: 시즌 판 | 추석(송편·감)·김장(배추·무)·연말(귤·종소리) 타일 세트 |
| 공통: 사연 판 | 장의 마지막 판을 깨면 옛이야기 4컷(D13) |
| 공통: 세 가족 규칙 판 | 같은 판을 세 규칙으로: **네모** 바구니 8칸(여유 있게) · **세모** 반짝 타일은 아무 그림 대신 쓸 수 있는 와일드(2개 + 반짝 1개) · **동그라미** 정확히 3개만(2개 뒤에 다른 그림이 끼면 정리 불가) |

한 종류가 3판을 넘게 이어지지 않는다(⑥·⑦과 같은 생성기 보정).

## 이야기 (D13)
- 같은 옛이야기는 앱이 달라도 같은 배역(`tools/tales_cast.py`). 같은 그림 세 개가 상징이 되는 이야기부터: **흥부 박**(박 세 개 = 쌀·비단·가구), **금도끼 은도끼**(금·은·쇠 도끼 세 번 묻기), 곶감(호랑이와 곶감 — 유아 앱 이야기와 겹치지 않게 ⑨에서는 곶감 타일만 사용), 아기돼지(집 세 채)·세 마리 곰(그릇·의자·침대 세 벌)·개미와 베짱이(곳간 세 칸).
- 장 순서는 ⑥·⑦과 같은 12장(아기돼지 → … → 토끼와 거북이)을 따라 3~12장을 확장 단계에서 채우고, 슬라이스(20판)는 1~2장. 사연은 장 끝 4컷([제안]), 가족 악역 0·세모 웃긴 실패역 전체 ≤3 단언 적용.

## 열린 질문 (허브)
1. 7칸 바구니의 「섞기」는 같은 그림 위치만 바뀌고 층 구조는 유지(무료 한 판 1회) — 원칙(무료 도구)에 맞는지.
2. 세모 와일드 타일은 세 가족 규칙 판 한정(기본 판에는 넣지 않음)으로 충분한지.
3. 타일에 세 가족 얼굴을 쓰면 「가족 캐릭터 모양 변형」이 되지 않는지 — 기존 캐릭터 PNG 를 작게 줄여 쓰고 새로 그리지 않는 안(허브 확인 필요).
