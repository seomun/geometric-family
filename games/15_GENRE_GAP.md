# 15. 장르 레퍼런스 대비 빠진 UI·콘텐츠 (2026-10-08)

> 작가 요청: 「다른 게임들 검색해 UI 와 추가 콘텐츠 보충, 하나하나의 게임에 빠진 UI·필요한 콘텐츠 보충」. 광고는 `16_ADS_RND.md` 에 따로.
> **조사 방법과 한계**: 웹 검색으로 장르별 상위 게임의 스토어 설명·소개·분석 글을 읽고 정리했다(직접 설치·플레이는 하지 않음). 수치·순위는 출처 글의 주장이며 보증하지 않는다. 표시: ✔ 구현(이번 커밋) · 계획 · 보류(원칙 충돌 → 허브 결정 요청, §4).
> 원칙(변경 불가): 압박 없음 · 뽑기 없음 · 서버 없음 · 유아 앱 글자 없음 · 통일성 §0. 공통 항목은 엔진·키트에 먼저 넣고, 앱별 필수 → 권장 순서.

## 4. 허브 결정(D15, 2026-10-08)과 처리 — 원래는 「원칙과 충돌해서 구현하지 않은 것」
1. **진동**: 성인 앱만 허용 → ✔ 구현(C13).
2. **리더보드·멀티·친구 비교**: D15 에서는 거부였으나 **D16(작가 지시)으로 수정** — 서버 없는 순위표(내 기록·세 가족)는 구현(C14), Play 게임즈는 브리지(꺼짐), 멀티·친구 비교는 계속 거부.
3. **푸시 알림·연속 출석 보상·카운트다운 이벤트**: 거부. 출석은 「끊겨도 잃는 것 없는 도장」으로만 구현.
4. **뽑기·상자·확률 보상·유료 재화**: 원칙상 영구 보류.
5. **큰 글씨 전면 적용**: 성인 앱 ✔(C2). 유아 앱은 글자 자체가 거의 없어 제외.
6. **성인 앱 대상 연령**: 만 13세↑ 유지(D15). 광고 켤 때 심사에서 지적되면 다시 논의.
7. **남은 필수(M) 중 콘텐츠 분량 항목**(허브·작가 창작/그림 결정 필요, 코드로 해결 불가): ① 새 장·새 놀이 · ④ 도안 80→120 · ⑤ 새 테스트 정기 추가 · ⑥ 판 수 확장. 제안: ⑤ 시즌 테스트 2종, ④ 계절 도안 20장, ⑥ 장면 20판 추가 — 승인 시 진행.
