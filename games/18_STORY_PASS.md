# 18. 스토리·설명 보강 (허브 지시 2026-10-09, 작가: 「설명과 스토리 진행이 거의 없네… 게임별로 스토리가 있어야 해」)

> 모든 글은 **[제안]** 각색(작가 확인 전). 옛이야기는 단일 배역표 `tools/tales_cast.py`(같은 이야기 = 같은 배역, 악역은 가족 밖). 작가 원문 문장은 이름·대사로 쓰지 않았다.

## 1. 구조 — 공용 `GF.tale` (`games/engine/tale.js`) + 앱별 `data/story_<앱>.json`
| 층 | 언제 | 내용 |
|---|---|---|
| 프롤로그 | 앱 첫 실행, 첫 인사 다음(한 번) | 2~3컷, 이 게임이 무엇인지 + 세 가족 |
| 기(起) | 장의 첫 판을 열 때 | 앱 한 줄(1장만) + 옛이야기 컷1 |
| 승(承)·전(轉) | 장 40%·70% 판을 깬 직후 | 옛이야기 컷2 · 컷3 |
| 결(結) | 장의 마지막 판을 깬 직후 | 옛이야기 컷4(+) → 결과 화면 |
| 판 안 말풍선 | 판 시작·클리어 | 그 장 배역 얼굴 + 한 줄(돌려 가며). 유아 앱은 글 없이 얼굴+💬+음성 슬롯 |
| 판 종류 설명 | 처음 나오는 판 종류(1회) | 아이콘+제목+설명 모달, 설정 「도움말 → 판 종류 설명」으로 다시 보기 |
| 이야기 지도 | 판 목록 장 머리글 아래 | 기·승·전·결 점 + 배역 얼굴 + 상태(잠긴 장은 실루엣) |
| 엔딩 | 마지막 장 결 컷 뒤 | 가족 엔딩 3컷 → **「당신은 어느 도형인가요?」** 카드 + 댓글 안내 문구 |
- 모든 컷은 탭으로 넘기고 **「건너뛰기」** 로 끝낼 수 있다. 한 번 본 컷은 자동으로 다시 나오지 않는다(`gf:<앱>:tale`). 설정 「이야기 다시 보기」로 처음부터.
- 자동 시험(webdriver)은 컷을 건너뛰고, `?story=1` 로 확인한다. 점검: `node tools/story_shots.js`(프롤로그·승 컷·건너뛰기·재실행), `node tools/story_flow.js`(기 컷→설명→말풍선).
