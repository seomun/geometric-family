# 19. 이야기 지도(사가 맵) — 레퍼런스 · 확정 스펙 · 데이터 · 슬롯 (허브 D18, 2026-10-09)

> 이 문서 = 조사 요약 + 확정 스펙(`docs/19 §4-1` 초안과 다른 곳은 §5 에 이유) + 데이터 형식 + 슬롯 목록. 구현: `games/engine/saga.js`·`saga.css`, 데이터 `data/maps/<앱>.json`(생성 `tools/map_build.py`), 슬롯 `data/art_slots.json` 의 `map`.

## 2. 확정 스펙
**구조**: 세로 스크롤, **아래→위**로 올라가는 길. 장 = 구역(옛이야기 장소, 높이 `zoneH`). 구역 안에 판 노드 `per`개(③⑥⑦⑧⑨ 10개, ⑩ 5개)가 길(점선 → 깬 구간은 노란 실선)로 이어진다.
| 요소 | 내용 |
|---|---|
| 구역 머리글 | `N장 · 이야기 제목` + ★ 합계 + **기·승·전·결 점·배역 얼굴·상태**(`GF.tale.strip`). 유아: 배역 얼굴 3 + 그림 점(글자 없음) |
| 판 노드 | 번호 + 별 0~3 + 판 종류 작은 아이콘, 잠김=회색, 쉬어 가기=초록, 특수 판=분홍 테두리, 현재 판=두근. 유아: 84px, 번호 대신 판 종류 그림 |
| 이야기 책(관문) | 구역 시작 옆. 누르면 그 장 컷 전부 다시 보기(`GF.tale.replay`) |
| 구역 상자 | 구역 끝. 구역 판을 모두 깨면 열림(`열기` → 우리 집으로). 안 열렸으면 「N판을 더 깨면 열려요」(압박 아닌 안내) |
| 랜드마크 | 그 이야기 상징물 2개(🧱·🌾 등), 슬롯으로 교체 |
| 아바타 | 현재 노드 위. 유아 = 막둥이, 성인 = 내 도형(`Room.me`), 없으면 네모 아빠. 지난번 위치가 바뀌었으면 **0.8초 걸어가고**, 새 구역이 열렸으면 **구름이 걷힌다** |
| 잠긴 구역 | 구름이 덮임(시간 잠금 없음, 앞 판을 깨면 열림) |
| 곁가지 | 오른쪽 **세로 레일**(키트 아이콘 + 짧은 글자). 길을 가리지 않는다 |
| 이어서 | 왼쪽 아래 큰 버튼 「이어서 · 레벨 N」(유아: 큰 ▶) |
| 광고 배너 | 지도 화면 하단. 네이티브가 WebView 를 줄여 레이아웃이 비켜 준다(D19) |
| 성능 | 구역 단위 가상 스크롤: 현재 구역 ±1 즉시, 나머지는 `IntersectionObserver`(600px 여유)로 보일 때 생성 — 140판(14구역)도 DOM 은 보이는 구역 위주 |
| 큰 글씨 | 글자 토큰(`--uk-fs-*`) 사용, 노드 숫자는 `--uk-fs-k` 배율 |

**장 흐름(10앱 공통, 한 번에 한 모양)**: 지도에서 노드 → ①이야기 컷(기) → ②설명 카드 1장(처음 나온 판 종류만) → ③손가락 시연 → ④판(첫 조각을 놓은 뒤 말풍선, 클리어 때 한마디) → ⑤장 중간 컷(승·전) → ⑥장 끝 컷(결) + 구역 상자 → ⑦지도로 돌아와 아바타가 걷고 다음 구역 구름이 걷힘. (구현: `GF.tale` + `GF.saga`)

## 3. 데이터 형식 `data/maps/<앱>.json`
```json
{ "app":"block", "kid":false, "per":10, "zoneH":910, "nodeSize":58, "special":[],
  "zones":[ { "ch":1, "title":"…", "tale":"pigs", "pal":["#위색","#아래색"], "faces":["nemo_mom.joy",…],
    "nodes":[[x%, y px]×per],  "gate":[x%, y], "chest":[x%, y], "marks":[{"e":"🧱","x":18,"y":409},…] } ] }
```
y 는 구역 위에서부터 px(노드 1이 구역 아래). 길 모양 = 프리셋 4종(사인파 둘·지그재그·코사인)을 구역마다 돌려 씀(`tools/map_build.py`). 좌표는 이 파일만 고치면 된다.

## 4. 이미지 교체 슬롯 (`data/art_slots.json` → `map`, 값 = 파일 경로 또는 data URI. 없으면 코드 그림)
| 슬롯 id | 크기 | 쓰임 |
|---|---|---|
| `<앱>:<장>:bg` | 가로 360 × 세로 `zoneH`(910/690) 세로 타일 | 구역 배경(이웃 구역과 위·아래 이음) |
| `<앱>:<장>:gate` | 정사각 ~160 | 이야기 책 관문 |
| `<앱>:<장>:mark1` · `mark2` | ~220 정사각(투명 PNG/SVG) | 랜드마크 2개 |
| `sky` | 360×90 | 지도 맨 위 하늘 띠 |
| `node` · `node_lock` | 정사각 ~160 | 판 노드 배경 / 잠김 |
| `chest` · `chest_open` | 정사각 ~160 | 구역 상자 닫힘/열림 |
| `type:<판종류>` | 정사각 ~96 | 판 종류 아이콘(앱마다 id: lines·family·junk… / diff·odd·hidden… 등) |
ASSET_LIST 우선순위: **구역 배경·관문·랜드마크 = 우선순위 1, 노드·상자·종류 아이콘 = 2**(`tools/asset_prio.py`).

## 5. docs/19 §4-1 초안과 달라진 점 (이유)
- **곁가지 위치**: 초안은 「지도 옆 고정 버튼」, 첫 구현에서 길을 가려 **오른쪽 세로 레일**로 확정(허브 검토 반영).
- **구역 상자**: 초안은 「10판마다 상자(열면 집에 놓기)」. 새 보상 로직을 만들지 않고, **기존 확정 집 소품 지급(앱별 REW/보상 표)은 그대로** 두고 상자는 「구역 완료의 시각적 매듭 + 집으로 가는 길」로 했다(이중 지급·뽑기 오해 방지).
- **노드 좌표 데이터화**는 초안과 동일하되, 길 프리셋 4종은 코드(`map_build.py`)에 두고 JSON 에는 결과 좌표만 저장(그림 담당이 JSON 만 고치도록).
- **구름 연출**: 초안 「구름이 걷힘」 유지. 단, 열리는 구역에 **처음 들어올 때 한 번**(저장: `gf:<앱>:saga.cur` 비교).
- **친구/서버 요소 전부 제외**(Candy Crush 의 친구 아바타·티켓, Merge Mansion 이벤트 타이머).
