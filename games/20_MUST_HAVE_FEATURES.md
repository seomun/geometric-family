## 3. 항목별 근거 · 제안

### 3-A. Top 15
**① 첫 판 온보딩 — 유지.** 근거: 온보딩을 끝낸 사용자의 잔존이 2~3배라는 업계 분석(출처 §6-4). 우리는 RC6 에서 설명 카드→손가락→말풍선 순서, 건너뛰기, 첫 30초 점검(`first30_check`)을 갖췄다. 추가 제안 없음.

**② 일일 도전 — 권장·중.** 근거: Block Blast 는 매일 바뀌는 배치·일일 챌린지(출처 §6-3), Naavik 은 Royal Match 의 일일 잭팟 이벤트가 매일 접속의 이유라고 설명(§6-2). 우리: ③⑥⑦⑧⑨ 「오늘의 한 판」. 빠진 곳: ②(계절 사건만)·⑤·유아 3앱. 제안: ⑤ 「오늘의 한 문항」(한 줄 질문), 유아 ⑩ 「오늘의 하루 한 판」은 **글자 없이** 막둥이가 하는 오늘의 일 1개(보호자 정책 맞음, 보상 없이 칭찬 연출만).

**③ 연속 출석·복귀 보상 — 권장·소.** 근거: 업계 리텐션 글은 Day 3~30 에 일일 스트릭·데일리 드롭이 꼬리를 만든다고 정리(§6-4). **원칙 충돌**: 연속이 끊기면 잃는 구조는 압박. 제안: 스트릭 대신 「오랜만이에요」 복귀 선물(7일↑ 쉬었다 오면 집 소품 1개 확정, 문구는 환영만, 끊김 표시 없음). 출석 도장은 지금 구조 유지(주간 7칸, 1칸이라도 불이익 0).

**④ 이벤트 달력 — 권장·중.** 근거: GameRefinery 는 상위 게임의 이벤트 수가 2023.5~2025.1 에 35% 늘었고 중핵 게임은 동시에 20개↑ 운영한다고 보고(§6-1), 캐주얼은 「가벼운 수집형」 리듬이 맞다고 정리. 서버 없이 가능한 변형: **앱 안 날짜 규칙 달력**(추석·김장·연말 등 시즌 판 12종을 한 화면 「올해의 달력」으로, 지난 달은 「내년에 또 와요」). **FOMO 금지**: 기간 지나면 영영 못 얻는 보상 없음(순환).

**⑤ 컬렉션 앨범 — 권장·중.** 근거: GameRefinery 는 컬렉션 메카닉이 약 80% 게임에 있고 캐주얼 퍼즐이 2개월 한정 컬렉션을 **무한 반복 앨범**으로 바꾸는 추세(§6-1), Monopoly Go 는 앨범·교환이 핵심 수익원(§6-6). **원칙 충돌**: 확률 팩·중복 교환은 뽑기 → 금지. 제안: 앱 공통 「앨범」 화면 하나 — 집 소품·이야기 컷 카드·배지·시즌 도안을 **획득 순 확정 지급**으로 모으고 세트 완성 시 확정 소품(우리 공유 룸 보상 구조 재사용). 중복·확률 없음.

**⑥ 꾸미기·메타 / ⑦ 스토리·지도 — 유지.** Homescapes 류의 「이야기 챕터 + 꾸미기」를 우리가 이미 갖췄다(D13·D18).

**⑧ 미션·퀘스트 — 권장·중.** 근거: Sensor Tower 는 상위 게임의 이벤트를 상시(일일 미션·체크인)·기능(패스·미니게임)·대형 이벤트의 3층으로 정리(§6-2). 제안: 「오늘의 작은 일 3개」(예: 별 3개 모으기·한 판 깨기·집 소품 놓기), 안 해도 없어지지 않고 다 해도 확정 소품 1개 이하, 유아 앱은 제외(보호자 정책).

**⑨ 시즌 패스 — 보류(허브 결정).** 근거: 전투 패스는 참여·잔존을 올리는 핵심(Sensor Tower, §6-2), Naavik 은 비과금자도 보상받는 병행 트랙을 권한다. 우리: 유료 패스 금지. 제안 「**시즌 길**」= 한 달짜리 무료 진행 트랙(판 N개 깨면 소품). 기간이 지나도 보존해 압박 없음. 효과 대비 구현이 크고 ④·⑧과 겹쳐 후순위.

**⑩ 순위·경쟁 — 유지.** 하이브리드(경쟁 + 개인 달성) 권장과 일치(§6-2): D16 로컬·세 가족 순위표.

**⑪ 소셜(공유·친구·팀) — 보류·대·허브 결정.** 근거: Royal Kingdom 은 레벨 21 에서 팀(최대 50명)에 들어가면 매일 목숨·골드를 받는다(§6-7), Monopoly Go 는 중복 스티커를 친구에게 보내 사회적 의무망을 만든다(§6-6). 서버·계정이 있어야 해서 **서버 없음 원칙과 충돌**. 서버 없는 변형 3개: (a) 결과 **이미지 공유**(⑤ 에 이미 저장 기능 — 모든 앱으로 확장, 권한 0), (b) **가족 코드**: 점수·도형을 짧은 코드로 만들어 카톡 등에 붙여넣어 서로 비교(서버·계정 없음), (c) 같은 기기 형제 앱 공유(이미 있음). 친구·팀 자체는 하지 않는 것을 권장.

**⑫ 수익 균형 — 허브 결정.** 근거: 2025 년은 광고·결제·구독 하이브리드가 표준이고 광고 제거 1회 구매가 흔한 옵션(§6-8). 우리: 광고(D19) 도입 완료. 광고 제거·스타터 팩은 **「결제 없음」 원칙과 충돌**. 선택지: (a) 유지(광고만) (b) 성인 앱 한정 「광고 제거 1회 구매」(Play 결제, 서버 없이 가능; 유아 앱 제외, 광고 제거는 배너·전면만 제거하고 보상형은 남김) (c) 소품 팩. 시장 관행상 (b) 가 가장 압박이 적다 → 권장하되 결정은 허브/작가.

**⑬ 클라우드 저장 — 권장·대.** 근거: Google Play 게임즈 「저장 게임」은 서버 없이 Google 서비스로 진행을 기기 간 동기화(§6-9). 우리 D16 의 PGS 브리지 설계와 같은 연결(작가 계정 뒤). **성인 7앱만**, 로그인은 설정에서 눌렀을 때만, 실패해도 로컬 유지. 서버 없는 대안: **백업 코드 내보내기/가져오기**(기기 안 저장을 문자열로, 유아 앱은 보호자 메뉴 안) — 작게 먼저 할 수 있다(중).

**⑭ 알림 — 권장(결정 후)·중.** 근거: Android 13+ 에서 `POST_NOTIFICATIONS` 런타임 권한이 필요하고 게임 옵트인은 높은 편(최대 76%)이지만 관련 없는 알림은 해지로 이어진다(§6-10). 제안: **로컬 알림만**(서버 푸시 금지) — 「오늘의 한 판 도착」 하루 1회 이하, 성인 앱·**기본 꺼짐**·사용자가 설정에서 켤 때만 권한 요청, 야간(22~8시) 금지. 유아 앱 금지. 매니페스트 권한 추가라 **스토어 문구·KIDS_COMPLIANCE 갱신 필요** → 허브 결정.

**⑮ 운영 창 묶음 — 필수(문의)/권장.** (a) **문의·FAQ**: 설정에 「문의하기」(mailto)와 짧은 FAQ(오프라인 정적) — 스토어 정책상 필요, 현재 `{{SUPPORT_EMAIL}}` 자리표시 → 이메일 확정 뒤 연결(소). (b) **새 소식·업데이트 안내**: 서버 없이 앱 번들 안의 정적 JSON, 업데이트 후 첫 실행에 「새로 생긴 것」 1장(소). (c) **인앱 리뷰**: Google 인앱 리뷰 API 는 앱이 충분히 쓰인 뒤 긍정적 순간에 한 번만, **질문 없이** 표시(§6-11). 제안: 성인 앱 장 끝 컷 직후 최대 90일에 1회, 유아 앱은 **요청 금지**(아이에게 평가 요청 정책). (소)

### 3-B. 부록
- **다국어(권장·대·허브 결정)**: Distimo 분석 — 현지어 지원 후 일본 다운로드 17배·매출 4배(Boom Beach), 아시아권에서 효과가 큼(§6-12). 우리는 한국어만. 서버 없이 문자열 JSON 치환이 가능하나 글 양이 많아(이야기·설명·스토어) **영어·일본어부터** 부분 번역이 현실적. 한국 시장만 겨냥하면 보류. 큰 결정(작가).
- **접근성(권장·소~중)**: Game Accessibility Guidelines 가 흔한 4대 불만으로 글자 크기·색맹·자막·조작을 꼽고 「색이 의미를 혼자 지니지 않게」·「모션 줄이기」·진동 끄기를 권한다(§6-13). 우리: 큰 글씨·진동 끄기 ✔, 자막 ✔(유아 보호자 메뉴). 빠진 것: `prefers-reduced-motion` 반영(소), 색 외 모양 표식(우리는 가족별 색+모양 표식 있어 대부분 충족, ⑨ 타일·⑧ 통 점검 필요 — 소).
- **방치형 ②**: 오프라인 진행은 방치형의 핵심 기대(§6-14) — 우리 ② 는 있음. 환생(프레스티지)은 장수의 핵심이지만 우리 작은 규모엔 과함(보류). 광고 보너스(2배)는 이미 보상형 자리.
- **유아 보호자 기능**: 연구·업계 글은 보호자 시간 제한·투명한 이유 설명·내재 동기를 권한다(§6-15). 우리: 쉬어요 알림·보호자 잠금(구구단) ✔. 제안(보류): 보호자 메뉴에 「오늘 놀이 시간」 요약(통계 유아 비노출 원칙과 보호자 메뉴 안에서만 허용으로 정리 필요).
- **Toca Boca World 사례**: 광고 없이 월간 신규 장소·금요일 선물 우체국·오프라인 플레이(§6-16). 우리 유아 3앱은 광고 배너(D19)를 택했으므로 **Toca 식 「매주 금요일 선물」**(서버 없이 날짜 규칙, 보호자 정책 맞음)을 광고 대신 신뢰를 주는 유아용 기능으로 제안(권장·소).

## 5. 조사 한계 (정직)
- **직접 플레이하지 않았다.** 모든 항목은 웹 검색 결과·분석 글의 요약에 근거한다. 게임 안에서 실제로 어떻게 보이는지·정확한 수치는 확인하지 못했다.
- 검색 결과 중 일부(Block Blast 운영 수치, 「70M DAU」 등)는 출처 품질이 낮은 블로그·집계 사이트여서 **방향 참고용**이다. GameRefinery 문서·Naavik·Sensor Tower·Google 문서가 비교적 신뢰도가 높다.
- Sensor Tower·GameRefinery 의 원본 보고서 본문(유료·PDF)은 읽지 못했고 공개 요약만 봤다. 「이벤트 수 +35%」 등 수치는 그 요약의 인용이다.
- 요청에 언급된 Kings Cup·Lightning Rush 같은 개별 이벤트명은 검색에서 확인하지 못했다(문서에 쓰지 않았다). Pinkfong·Township·Royal Kingdom 의 세부 기능은 일부만 확인(Pinkfong 은 검색에서 구체 자료를 못 찾음).
- 업계 글은 대형 퍼블리셔(중핵·과금형) 편향이 있어, **우리의 작은·무서버·압박 없음 규모에는 그대로 맞지 않는다.** 우리 판정은 원칙(D12~D19)을 앞세운 것이다.
- 코드 상태 대조(§2)는 RC6 기준 내 기억·문서에 근거하며, 앱별 세부 칸은 일부 근사(◐)이다. 승인 뒤 구현 전에 앱별로 다시 확인한다.
