# 유아 정책 점검표 — 갤럭시 스토어 Kids + Google Play Families (2026-10-07)

> 기준: **Google Play 가족(Families) 정책**(어린이 대상 앱 = 가장 엄격한 쪽)을 만족하면 갤럭시 Kids 요건도 만족한다고 보고 그 기준으로 점검한다. 정책 원문은 개정되므로 **제출 직전에 최신 문서로 다시 확인**한다(이 표는 내부 점검 기록이지 법률 자문이 아님).
> 대상: ① 기하학 가족 놀이터(유아) · ④ 막둥이 색칠북(유아, 미구현 — 설계 단계 요구사항) · 공유 룸. 성인/전연령 앱 ②③⑤는 맨 아래 §5.
> 범례: ✔ 충족(근거) / △ 애매 또는 조치함 / ✘ 위반(고침) / ☐ 아직 없는 기능의 설계 요구

## 2. ④ 막둥이 색칠북 — 설계 요구사항(구현 때 이 표로 점검)
| # | 요구 | 상태 | 규칙 |
|---|---|---|---|
| 1 | 색칠 그림은 **기기 안에만** | ☐ | 서버 업로드·공유 버튼·갤러리 내보내기·SNS 공유 **없음**. 저장은 localStorage(또는 앱 전용 저장소). "저장해서 사진첩으로 내보내기" 기능은 두지 않는다(저장소 권한·유출 경로) |
| 2 | 카메라·사진·마이크 권한 없음 | ☐ | 아이 사진 캐리커처 같은 기능 금지(이전 제안은 폐기) |
| 3 | 완성작 → 집 액자 | ☐ | 액자 데이터는 앱 안에만. **다른 앱과 공유하는 저장소에 그림 데이터를 쓰지 않는다**(§3 의 id 목록만 공유) |
| 4 | 외부 링크·구매·다른 앱 안내 없음 | ☐ | ① 과 동일 |
| 5 | 보호자 잠금 | ☐ | `GF.gate` 재사용(설정·집 가족 화면·코드 입력) |
| 6 | 개인정보 0 · 권한 0 · 광고·결제 0 | ☐ | ①과 동일 방침 문서 |

## 3. 공유 룸 「기하학 가족의 집」 (유아 앱 포함 시)
| # | 요구 | 상태 | 규칙·구현 |
|---|---|---|---|
| 1 | 저장은 **아이템 id 목록 + 놓은 위치**뿐 | ✔ | `engine/room/room.js` store 스키마: `{items:[id], placed:{room:[{id,x,y,flip,c}]}, done:[setId]}` — 이름·사진·기기 ID·그림 데이터 없음 |
| 2 | 유아 앱은 **자기 세트(아이 방)만** 보임 | ✔ | `Room.cfg.mode='kid'` → 탭은 아이 방만, 아이템은 자기 `game` 세트만. 다른 세트는 목록에 없음 |
| 3 | 다른 게임 세트는 **보호자 잠금 뒤 "가족 집"**, **잠긴 실루엣만** | ✔ | 자물쇠 탭 → `Room.cfg.guard`(= `GF.gate`) 통과 후 전체 방·세트 표시. 미획득 아이템은 검은 실루엣+자물쇠 |
| 4 | **설치 권유·링크·"다운로드" 버튼 절대 없음** | ✔ | 실루엣에 "어느 게임에서 얻는지" 문구·링크 없음(토스트는 "아직 못 얻었어요"만 — 게임 이름을 유아 화면에 쓰지 않도록 아래 개선 적용) | 
| 5 | **코드 입력(굿즈 코드) 화면은 보호자 잠금 뒤** | ☐ | 코드 입력 UI 구현 시 `GF.gate` 필수. 코드는 서버 확인 없음(체크섬만) |
| 6 | **유아 앱 ↔ 성인 앱 간 저장소 공유는 하지 않는다** | ✔ (D12 승인) | 공유 저장소를 **유아 그룹(①④) `gf:house:kid:v1` / 성인 그룹(②③⑤) `gf:house:adult:v1`** 로 분리. 유아↔성인은 보호자 잠금(`GF.gate`) 뒤 6자리 코드로만 연결(자동 연결 없음). ③은 `adult` 키 사용 중 |

## 4. 보호자 잠금 방식이 충분한가
- **결론: 구구단 4지선다(6~9단)는 충분**하다고 판단(만 3~7세 대상). Google 은 "보호자 확인" 방식으로 아이가 쉽게 풀 수 없는 문제(예: 연산·글 읽기)를 예시로 든다. 단순 덧셈·버튼 길게 누르기는 약하다고 본다 → **덧셈 폐기**.
- 개선 여지: 선택지 위치·오답은 매번 무작위(적용됨). 필요하면 한국어 숫자 읽기("칠십이를 고르세요")로 바꿀 수 있다.
- 잠금 지나는 곳: 설정 메뉴 / 가족 집 / 코드 입력 / (향후) 외부 링크·구매가 생기면 전부.

## 5. 성인·전연령 앱 ②③⑤ — 아동 대상 아님 표시
| 항목 | 규칙 |
|---|---|
| ② 세 가족 식탁 | 스토어 대상 연령 **성인(만 14세↑ 일반)**, "아동 대상" 체크 안 함. 음주 언급 정직 체크(`store/RATING_idle_ko.md`) |
| ③ 도형 합치기 · ⑤ 당신은 어느 도형? | 대상을 "전 연령"으로 하면 Google 이 **아동 포함 대상**으로 보고 Families 정책 전부(광고 SDK 인증·잠금 등)를 요구할 수 있다. **애매** — 귀여운 도형 캐릭터는 "아동 매력(appeal to children)" 판단 요소. **D12 결정**: ③⑤ 는 만 13세↑ 일반 신고 + 구현은 Families 수준(데이터·SDK·외부 링크 0, GF.gate 유지), 스토어 문구·아이콘에 "아이용/유아" 표현 금지 |
| 공통 | 아동 대상 아님으로 신고한 앱이라도 **유아 앱을 광고·유도하지 않는다**(교차 홍보는 유아 앱 쪽에서 금지, 성인 앱·웹툰에서만 허용 — docs/17 §6) |

## 6. 이번 점검에서 고친 것 / 허브에 올릴 것
- 고침: 보호자 잠금 강화(덧셈→구구단 4지선다, `GF.gate` 공용화), 점검표 신설.
- 허브 결정 필요(정책): ① 공유 저장소 유아/성인 분리(§3-6) ② ③⑤ 대상 연령 신고(§5).
- 구현할 때 지킬 것: 코드 입력 화면 `GF.gate`, 색칠 그림 기기 안 보관, 가족 집 문구에 게임 이름 쓰지 않기(유아 화면).
