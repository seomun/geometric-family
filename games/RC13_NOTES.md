- **A10 앨범**(날짜 도장 자동 기록) · **A11 세트 완성 가족 장면 6종**.

## RC13 확인 결과 (추가)
- **구간 회귀(별도 워크트리)**: 73구간 중 72 통과. 1구간(합치기 1~5, 잠긴 칸 확인)은 부하 때 한 칸 늦게 열리는 시험 쪽 흔들림이라 재시도(최대 4번·350ms)로 보강했고 다시 돌려 통과.
- **APK 안 HTML 확인** (`node tools/apk_check.js`): 11개 APK 의 index.html 해시가 src 와 모두 같음. 원정대 APK 에 출시 플래그·서버 주소 자리·요일 던전·도감·전리품·육성·상점·튜토리얼 컷·전투 연출·정찰이 들어 있고, file:// 로 열어 개발 문구 없이 홈 버튼 3개 확인. 전체 ALL PASS.
- **RC12 원정대 APK 오래된 HTML 문제**: build_apk 가 원정대 빌드에 `app` 인자를 안 넘긴 탓 → 수정·재빌드. 이제 build_apk 가 빌드 끝에 APK 안 HTML 과 src 해시를 비교하고(원정대는 GF_RELEASE·GF_API·xdun·xdex 포함 여부도) 다르면 실패 처리.
- **A11 보정**: 소파·상은 흐리지 않고 또렷하게, 가족은 그 앞에 앉힘. 할머니 1.3배. 가족끼리 겹침 0 (시험 추가).
