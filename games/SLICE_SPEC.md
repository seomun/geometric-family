# 1장 규격 (SLICE SPEC) — 잠금본 v1

1장 「그림자 찾기」가 허브 QA 3차를 통과한 기준(커밋 9daa813)을 문서로 잠근다. **2~5장과 새 게임은 이 규격을 따른다.** 값은 코드(`engine/gf.js` · `gf.css` · `modes/*.js`)와 일치한다. 코드를 바꾸면 이 문서도 같이 고친다.
소리는 작가 귀 검수 대기 중이라 §6 은 **잠정**이다.

## 1. 화면과 배율
| 항목 | 세로(폰·탭 세로) | 가로 태블릿 |
|---|---|---|
| 안전 영역(UI·놀이가 앉는 곳) | 360×640 | 720×440 (`screen.wide()` 가 true 인 화면만) |
| 배율 | `min(가로/360, 사용높이/640)` | `min(가로/720, 사용높이/440)` |
| 예 | 412×915 → 1.14 · 800×1280 → 2.0 | 1280×800 → 1.78 (이전 1.25) |
| 배경 | 화면 전체(full-bleed). 하늘·땅·언덕이 좌우위아래로 이어진다 | 같음. 땅을 170 위로 올려 낮은 장면에 맞춘다 |
| 상단 바 | 화면 위 가장자리(시스템 바 인셋 안쪽), 좌우 12 여백: 홈 · 별 · 소리 | 같음 |
| 회전 | 화면이 가로 지원 여부를 바꾸면 현재 화면을 다시 그린다 | |

- 가로를 지원하는 화면: 홈 · 지도 · 스테이지 선택 · 그림책 · 놀이방 · 앨범 · 5개 놀이 모두.
- 새 화면은 `GF.screen(name, { wide: () => true, enter(r){...} })` 로 가로를 켠다. 좌표는 `GF.safe.w/h` 기준으로 짠다(고정 360/640 금지).
- 놀이 모드는 `land: true` 와 `ctx.W`(안전폭) · `ctx.H`(안전높이 − 64) 로 배치한다.

## 2. 터치 판정
- 어떤 요소든 **화면에서 64dp 이상**의 판정 영역을 갖는다. 보이는 크기와 무관(1장 작은 토큰 포함).
- 구현: `fit()` 이 `--hit = 64 / 배율` 을 넣고, `.tok .round-btn .fcard .card` 의 `::before` 가 `max(100%, var(--hit))` 로 판정 영역을 넓힌다.
- 드래그는 동시에 하나만(멀티터치 무시). 놓은 곳이 정답 칸 반경(칸 크기의 0.7배, 최소 56) 안이면 판정, 밖이면 오답 없이 복귀.
- 색칠: 선 위를 눌러도 반경 22px 안의 가장 가까운 칸이 칠해진다.

## 3. 캐릭터 비율
**호칭(세계관, 허브 결정)**: 세모네는 아이 없는 부부다. 막둥이 시점에서 세모 아내 = **세모 이모**, 세모 남편 = **세모 삼촌**, 동그라미 아빠 = **동그라미 아저씨**. 화면·자막·음성 대본·문서 모두 이 호칭만 쓴다(코드 id `wife` `dong_dad` 는 내부 이름이라 그대로). 주인공 막둥이는 네모네 아이라 네모 아빠 = **아빠**, 네모 엄마 = **엄마**, 할머니 = **할머니**.

| 장면 | 규칙 |
|---|---|
| 그림책 | 어른 = 장면 높이 55% · 아이 = 어른×0.8 · 막둥이 = 어른×0.45 (역할은 id 로 판정). 코드 그림(무 등)은 작성 높이를 같은 비율로 환산 |
| 폭이 모자랄 때 | 같은 비율로 모두 줄인다(세로는 서로 26% 겹쳐 선다, 가로는 간격 14) |
| 홈 | 세로 세모 이모 160 · 막둥이 112 · 동그라미 아저씨 148 / 가로 190 · 126 · 172 |
| 순서 | 어른 > 아이 > 막둥이 를 깨지 않는다(세계관) |

## 5. 규칙(별·난이도)
- 라운드 별: 틀림 0·힌트 0 → ★3 / 틀림 ≤2 → ★2 / 그 외 ★1.
- 스테이지 별 = 라운드 별 평균 **내림**(최소 1). 별 3개를 받으려면 모든 라운드가 완벽해야 한다.
- 적응: 한 라운드에서 3번 틀리면 다음 라운드 한 단계 쉽게, 완벽한 라운드가 2번 이어지면 한 단계 어렵게.
- 해금: A 클리어 → B → C → 다음 장(별 조건 없음). 놀이방은 전부 열려 있다.
- 실패·시간제한·점수 경쟁 없음. 오답 소리는 부정 신호를 약하게(`hmm`).

## 7. 새 장·새 게임 체크리스트
1. `modes/<name>.js` + `land: true` + `ctx.W/H` 배치 + 힌트 2단계.
2. 정답=`ctx.sfx('ok')` + `GF.snap` + `GF.burst`, 오답=`tilt`+`hmm`, 놓기=`drop`.
3. 끝낼 때 `ctx.done({mistakes})` 만 호출(클리어 연출은 엔진 몫).
4. `data/stages.json` 에 3스테이지×3라운드, `data/story.json` 에 그림책, 스티커 5장.
5. 표정·카드는 보이는 크기 ≥120px(작은 카드에서 구분 가능해야 함). 비슷한 표정은 한 판에 같이 내지 않는다.
6. `smoke.js` 에 풀이기를 추가하고, `devices.js` 로 4기기 확인 후 QA 요청.

## 8. 5장 도형 맞추기 연출 (5차 추가)
- 판 = 잔칫집 마당(만국기·구름·꽃·길). 칸 = **설계도**(조각 색을 옅게 칠한 점선 칸). 조각마다 질감: 벽돌·기와·나무결·물방울·줄무늬, 창은 십자 살, 문은 손잡이, 해는 웃는 얼굴, 선물은 리본.
- **세 가족이 지켜본다**: 바닥 줄에 아빠(네모 아빠)·막둥이·세모 이모·동그라미 아저씨. 정답이면 기뻐서 점프(joy), 오답이면 걱정(worry/trouble) 표정 0.9s.
- 완성하면 **문이 활짝**(0.52s) + 안에서 따뜻한 빛 + 반짝이. 마지막 판(바람)은: 바람 친구 구름이 후~ (0.7s 입장) → 집 흔들림 + 바람 줄기 1.5s → 집은 끄떡없고 바람 친구가 웃으며 사라짐 → **생일 잔치 컷**(케이크·풍선·온 가족 점프) → 5.6s 뒤 결과.
