# 소리 통일 규칙 (docs/19 §0) — 같은 동작 = 같은 소리 id

`data/sounds.json` 하나 + 엔진 공용 로더(`engine/gf.js`: GF.sfx / GF.bgm / GF.say). 게임 전용 소리는 **고유 동작**에만 쓴다.

| 동작 | 소리 id | 비고 |
|---|---|---|
| 모든 버튼·UI 누름 | `tap` | 키트 버튼(UK.btn/round)이 자동으로 부른다 |
| 선택·집기·카드 열기 | `pick` | 레벨·카드·식탁 상세 열기 포함 |
| 놓기·스냅(조각·가구·그림 맞추기) | `drop` | |
| 정답·성공·합치기·구매 | `ok` | |
| 아이템·별·도장 획득 | `star` | 집 아이템 얻을 때 필수 |
| 클리어·세트 완성·엔딩 | `celebrate` | 키트 UK.result 가 자동 |
| 갸웃(오답·잠김·재시작) | `hmm` | ①의 옛 `no` 도 `hmm` 으로 통일(2026-10-07) |
| 컷·화면 넘김 | `page` | 공용 사연 컷 플레이어(GF.story)가 자동 |
| 타이틀 | `theme_main` + `logo_sting` | 지금은 음원 교체 전이라 무음(`musicEnabled:false`) |
| 고유(예) | `wind`(세모 여행) · `door` · `shutter`(사진) · `whistle`(기차) · `flip`(카드) | 게임 고유 동작에만 |
