# 기하학 가족 — 퍼블리셔 데모 (한 장 요약)

세 도형 가족(네모·세모·동그라미)이 **같은 사건을 다르게 겪는** 웹툰 IP의 게임 두 종. 캐릭터는 SVG/코드 기반이라 매 컷 동일하고 저작권이 깨끗하다. 둘 다 **서버·가입·개인정보 수집 없음**, 단일 HTML(오프라인).

| | ① 기하학 가족 놀이터 | ② 기하학 가족: 세 가족 식탁 |
|---|---|---|
| 대상 | 만 3~6세 (Kids) | 성인 일반 (50대 공감) |
| 장르 | 쉬운 놀이 모음 + 이어지는 옛이야기 | 잔잔한 방치형 + 사연 수집 |
| 분량 | 2편 10장 · 30단계 + 놀이방 + 스티커 50 | 사연 30편 · 계절 사건 7종 · 소품 30종 · 엔딩 |
| 수익 | 광고·결제 없음 | 미정(유료 1회 / 소품 팩 둘 다 붙일 수 있게 `IDLE.grant` 자리만) |
| 크기 | HTML 6.0MB · APK 8.5MB | HTML 4.9MB (APK는 수익 방식 확정 후) |
| 해보기 | `play_toddler.html` | `play_threetables.html` (`?season=12` 연말 사건) |

## 폴더
- `play_toddler.html`, `play_threetables.html` — 브라우저에서 바로 실행(폰 세로 권장)
- `toddler_debug.apk` — 안드로이드 설치용(WebView, 서명 전 디버그)
- `screens_*/` 스크린샷 6장(액자형), `video_*_30s.webm` 30초 영상(소리 없음), 표지·아이콘
- 소개 문구·개인정보처리방침·등급 답안: `games/store/`

## 정직한 현재 상태
- 소리(테마·효과음)·음성은 **임시**(작가 판정·성우 녹음 대기). 방치형 소품 일러스트 19종은 임시 아이콘.
- 판매자 등록·서명 키·방침 게시·실기기 테스트는 사람 일로 남음.
- 방치형 수익 방식은 퍼블리셔 협의 사항.

재생성: `python games/tools/make_demo.py` (HTML·APK는 용량 때문에 git에 올리지 않음)
