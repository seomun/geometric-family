핵심 고리

  1. 1. 목표나라마다 단계를 깨며 이야기를 이어가요
  2. 2. 싸움구슬을 끌어 같은 색을 이어 몬스터를 부숴요
  3. 3. 보상 폭발큰 덩어리·연쇄 콤보일수록 피해가 곱으로 터져요
  4. 4. 강해짐동료·장비가 자라 다음 벽을 넘어요

영웅 카드 수집 B → SSS 등급

  • B보통
  • A귀한
  • S특별
  • SS전설
  • SSS신화

영웅 카드를 모으고 등급을 올려요. SSS(신화)는 전설 각성 끝에 변신으로만 얻어요(뽑기 없음). 카드 시스템은 개발 중입니다.

수익 모델 요약

  • 보상형 광고선택. 시간·편의·소모재만(금화 2배·이어하기 등). 전설·의상은 광고로 주지 않아요
  • 정기권 (30일)제안 4,900원 · 즉시 + 매일 반짝석, 자동결제 아님
  • 시즌 패스 (8주)제안 9,900원 · 무료 줄 + 유료 줄(한정 의상 포함)
  • 의상·패키지겉모습 의상은 능력치 0. 첫 결제·성장 패키지는 상태 기반(압박 문구 없음)

확률 공개·천장·월 결제 상한·만 14세 미만 이용 불가. 금액은 제안 단계이며 제휴 협의로 확정합니다.
