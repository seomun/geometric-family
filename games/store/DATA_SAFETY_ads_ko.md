# Data safety 답안 초안 — 광고 SDK(AdMob) 도입 후 (D19, 2026-10-09)

> 이전 「수집·공유 없음」 답안은 **무효**. 아래로 제출한다. 근거: Google Mobile Ads SDK 공개 문서의 「Play 데이터 보안 섹션 안내」 [확인 필요: 제출 시점의 최신 표 대조]. 앱 자체는 서버가 없고 계정이 없다.

## 공통
| 질문 | 답 |
|---|---|
| 앱이 필수 사용자 데이터를 수집·공유하는가 | 예(광고 SDK 에 의해) |
| 전송 중 암호화 | 예(SDK 는 HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있는가 | 앱 자체 데이터 없음(기기 안만). 광고 데이터는 Google 정책 |
| 계정 생성 | 없음 |

## 수집·공유 항목 (광고·마케팅 목적, Google 과 공유, 필수 — 선택 아님)
| 범주 | 항목 | 성인 7앱 | 유아 3앱 |
|---|---|---|---|
| 기기 또는 기타 ID | 광고 ID(AD_ID) | 예(동의한 이용자만 맞춤) | **아니오 — 권한 제거, 비개인화** |
| 앱 정보·성능 | 비정상 종료 로그·진단 | 예(SDK) | 예(SDK, 비개인) |
| 앱 활동 | 광고 상호작용(노출·클릭) | 예 | 예 |
| 위치 | 대략적 위치(IP 기반) | 예 | 예(아동 대상 처리) |
- **앱이 직접** 수집하는 개인정보: 없음(이름·이메일·사진·정확한 위치·연락처·결제 없음).
- 성인 앱: 유럽 등 필요한 지역에서 UMP 동의 창. 유아 앱: 동의 창 없이 비개인화·TFCD.

## 가족 정책(유아 ①④⑩)
- Play 앱 콘텐츠 → 「대상 연령」: 만 3~6세 포함 → **Families 프로그램 필수 준수**. 광고는 Google 이 인증한 SDK(AdMob)만, 아동 대상 처리 on, 광고 등급 G. 홈·지도에만 배너(놀이 중 광고 없음).
- 앱이 아이에게 무엇을 요구하지 않음, 광고 클릭 → 앱 밖 이동은 SDK 동작(방침 §3 명시).

## 작가가 할 일
1. AdMob 가입 → 앱 10개 등록(패키지 `com.geometricfamily.*`) → 광고 단위(배너·전면·보상형; 유아는 배너만) ID 를 `~/.gradle/gradle.properties` 의 `GF_ADMOB_*_<FLAVOR>` 로(`16_ADS_RND.md` D19).
2. AdMob 앱 설정에서 유아 3앱을 「아동 대상 앱」으로 지정, 성인 7앱은 **차단 카테고리**: 사행성·도박, 정치, 주류(+ 선정성) 켜기, 최대 등급 PG.
3. `app-ads.txt` 를 개발자 웹사이트 도메인 루트에 게시(도메인은 작가).
4. Play Console 앱 콘텐츠 → 광고 포함 「예」, Data safety 위 표로, 대상 연령 신고.
