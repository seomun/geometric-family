「기하학 가족」(이하 「운영자」)은 웹툰·영상·게임 앱·웹사이트를 운영하면서 이용자의 개인정보를 「개인정보 보호법」 등 관련 법령에 따라 처리합니다. 이 방침은 아래 적용 대상 모두에 적용됩니다.

한눈에 보기
  • 게임 앱 11종(놀이터·색칠북·하루·식탁·합치기 등): 이름·연락처·사진·위치를 받지 않고 계정이 없습니다. 진행 기록은 기기 안에만 저장됩니다. 광고는 Google AdMob 이 보여 줍니다.
  • 기하학 원정대: 이름 없는 익명 계정과 서버 저장이 있습니다. 생년월(나이대 판정용)·진행 기록·구매 기록을 저장하며, 앱과 웹에서 계정 삭제를 요청할 수 있습니다.
  • 어린이 앱(놀이터·막둥이 색칠북·막둥이의 하루)은 아동 대상 광고 설정·비개인화 광고만 쓰고 광고 식별자를 쓰지 않습니다.
  • 운영자는 개인정보를 판매하지 않고, 광고 목적으로 제3자에게 제공하지 않습니다.

2. 처리하는 개인정보 항목·목적·보유 기간

2-1. 게임 앱 11종 (기하학 원정대 제외)

  • 앱이 직접 수집하는 개인정보는 없습니다. 이름·연락처·사진·음성·위치·사용 기록 분석 정보를 받지 않으며, 회원 가입·로그인이 없습니다. 분석 SDK(Firebase 등)도 쓰지 않습니다.
  • 기기 안에만 저장되는 것: 깬 단계·별·모은 가구와 놓은 위치·소리 설정 같은 진행 기록. 외부로 전송되지 않으며 앱의 「진행 지우기」(어린이 앱은 보호자 메뉴) 또는 앱 삭제로 모두 지워집니다.
  • 같은 기기의 형제 앱 공유: 같은 운영자의 앱이 한 기기에 함께 설치돼 있으면 「우리 집」(얻은 아이템 번호와 놓은 위치)을 서로 읽어 보여 줍니다. 같은 서명의 앱 사이, 같은 기기 안에서만 이뤄지고(어린이 앱끼리, 일반 앱끼리), 서버·계정이 없으며 다른 앱이나 제3자는 읽을 수 없습니다.
  • 사진첩 저장(당신은 어느 도형?): 이용자가 「이미지 저장」을 눌렀을 때만 결과 카드 그림 한 장을 기기 사진첩에 저장합니다. 저장소 권한을 요청하지 않으며 앱이 이를 외부로 보내지 않습니다.
  • 광고와 결제에서 처리되는 정보는 §4를 보세요.

2-3. 웹사이트

  • 회원 가입이 없고, 방문 분석 도구(Google Analytics 등)를 쓰지 않습니다.
  • 사이트는 GitHub Pages 로 제공되며, 서버 운영을 위해 GitHub 가 접속 IP 주소 등 기술 기록을 처리할 수 있습니다. 글꼴은 Google Fonts 에서 불러옵니다.
  • 영상은 이용자가 재생을 누를 때만 YouTube(개인정보 보호 강화 모드, youtube-nocookie.com)가 열립니다. 웹툰 댓글(giscus)은 GitHub 로그인을 한 경우에만 GitHub 를 통해 남겨집니다.
  • 웹 체험판의 진행 기록은 이용자 브라우저(localStorage)에만 저장되고 운영자에게 전송되지 않습니다.
  • 이메일로 문의하면 회신을 위해 이메일 주소와 문의 내용을 받으며, 처리 후 1년 뒤 지웁니다(분쟁이 있으면 끝날 때까지).

3. 어린이와 청소년

  • 어린이 앱(놀이터·막둥이 색칠북·막둥이의 하루)은 만 3~6세를 위해 만들었습니다. 앱이 직접 수집하는 개인정보가 없고, 결제·알림·외부 링크가 없습니다. 광고는 홈·지도 화면 아래 배너에만 나오며 아동 대상 처리(TFCD)·최대 등급 G·비개인화 광고를 적용하고 광고 식별자(AD_ID) 권한을 제거했습니다. 놀이 중과 보호자 메뉴(덧셈 잠금 뒤)에는 광고가 없습니다. Google Play 가족 정책을 따릅니다.
  • 일반 앱은 만 13세 이상을 전제로 하며, 수집하는 개인정보가 없어 연령 확인 절차가 없습니다.
  • 기하학 원정대는 만 15세 이상 이용 서비스입니다. 만 15세 미만은 가입할 수 없으므로 만 14세 미만 아동의 개인정보를 처리하지 않습니다. 만 15~18세는 월 7만 원, 만 19세 이상은 월 20만 원의 결제 한도가 서버에서 적용되고, 이용자가 더 낮은 한도를 직접 정할 수 있습니다.
  • 만 14세 미만 아동의 개인정보가 처리된 사실을 알게 되면 법정대리인 동의 없이 지체 없이 파기합니다. 보호자는 문의처로 확인·삭제를 요청할 수 있습니다.

4. 제3자 제공·처리 위탁·국외 이전

운영자는 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 다만 서비스 제공을 위해 아래 회사가 정보를 처리합니다.

  • 광고: 일반 앱은 홈·지도 하단 배너, 판 결과 뒤 전면 광고(횟수 상한 있음), 이용자가 눌러 보는 보상형 광고를 보여 줍니다. 필요한 지역에서는 처음 실행할 때 동의 안내(UMP)를 띄우고 이용자가 고른 범위에서만 맞춤 광고를 씁니다. 기하학 원정대는 이용자가 선택해서 보는 보상형 광고만 있으며 비개인화로 설정합니다. 처리 방식은 Google 개인정보처리방침과 Google 파트너 사이트 데이터 사용을 따릅니다.
  • 결제: 앱을 받은 스토어의 결제를 씁니다. 운영자와 원정대 서버는 카드 정보를 받지 않고 주문 번호·상품·금액·상태만 받아 검증합니다. 어린이 앱에는 결제가 없습니다.
  • 국외 이전: 위 표의 정보는 서비스 이용 시점에 네트워크를 통해 전송됩니다. 국외 이전을 원하지 않으면 해당 앱을 쓰지 않거나 원정대 계정을 삭제할 수 있으나, 이 경우 서비스 이용이 제한됩니다.

6. 이용자의 권리와 행사 방법

  • 이용자(만 14세 미만은 법정대리인)는 언제든 개인정보 열람·정정·삭제·처리 정지를 요구할 수 있습니다. 문의처로 요청하면 10일 안에 처리 결과를 알려 드립니다.
  • 기하학 원정대 계정 삭제: 앱의 상점 화면 아래 「계정·데이터 삭제 요청」. 앱을 쓸 수 없으면 계정 삭제 요청 페이지를 보세요. 삭제하면 진행·동료·재화 장부·모집 기록·기기 구분값·요청 기록을 지우고 생년월을 비웁니다. 법정 보존 대상인 구매 기록은 보존 기간 동안 남습니다.
  • 다른 게임 앱: 운영자가 가진 정보가 없으므로 앱의 「진행 지우기」 또는 앱 삭제로 기기 안 기록이 모두 지워집니다.
  • 광고 설정: 기기 설정에서 광고 ID 를 재설정·삭제하거나 맞춤 광고를 끌 수 있습니다.

7. 파기 절차와 방법

보유 기간이 끝나거나 목적을 이룬 정보는 지체 없이 파기합니다. 서버 데이터는 복구할 수 없는 방법으로 지우고, 법령에 따라 보존할 정보(구매 기록)는 다른 정보와 분리해 보관한 뒤 기간이 끝나면 지웁니다.

8. 안전성 확보 조치

  • 서버 통신은 모두 암호화(HTTPS)합니다. 서버 접근 권한은 운영자 1인으로 제한합니다.
  • 계정은 이름·이메일 없는 임의 번호로 만들어, 유출되더라도 개인을 알아보기 어렵게 설계했습니다.
  • 접근 키는 공개 저장소에 두지 않고 운영자 기기에만 보관합니다.

9. 업로드 도구 「기하학가족 업로더」 (Google API)

「기하학가족 업로더」는 운영자가 자기 YouTube 채널에 직접 만든 영상을 올리기 위해 쓰는 내부 도구입니다. 일반 이용자에게 배포하거나 로그인하게 하지 않습니다.

  • 접근 범위: YouTube Data API v3 의 youtube.upload, youtube 범위. 운영자 채널에 영상 업로드, 제목·설명·태그·공개 상태·썸네일 지정, 재생목록 추가, 처리 상태 확인에만 씁니다.
  • 저장: 로그인 토큰은 운영자 컴퓨터 안 비공개 폴더에만 저장하며, 서버나 제3자에게 보내지 않습니다. 다른 사람의 Google 계정 정보·시청 기록·구독자 정보를 읽거나 저장하지 않습니다.
  • 공유: Google 사용자 데이터를 판매·제3자 제공·광고에 쓰지 않으며, 사람이 열람하지 않습니다.
